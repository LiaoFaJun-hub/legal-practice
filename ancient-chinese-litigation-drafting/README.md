## 一、这是什么

按朝代（秦／汉／隋／唐／宋／元／明／清）生成**可直接投递官府**的古代诉讼文书，附逐段白话译文与术语／称谓／律条释义。

**输出契约只有两块**：`【一】文书正文` ＋ `【二】白话附录`。不夹带分析、创作说明、自评。

## 二、目录结构（三层架构）

```
ancient-chinese-litigation-drafting/     ← 古代讼师文书撰写
├── SKILL.md                        ← 主入口（十段式）：路由/schema/校验/禁用词/伦理
├── README.md                       ← 本文件
├── references/                     ← 知识层（10 份，均为用户提供素材，原样归档）
│   ├── 00_法源总纲.md               四级证据分级 · 引用标注模板 · 校验规则→法源映射
│   ├── spec_秦汉隋.md               官吏记录体：爰书/告/劾/辞/传爰书/录状
│   ├── spec_唐宋.md                 陈情体：辞/牒/状，书铺与保识
│   ├── spec_元明.md                 吏牍体＋十段锦：词状/告状/诉状/和息/结状
│   ├── spec_清.md                   双模式：标准状/刀笔状，戳记与抱告
│   └── 01~04_法源_*.md              四朝法源分册（条文原文、版本、待核事项）
├── scripts/                        ← 计算层（零依赖，stdin→stdout JSON）
│   ├── validate.py                  12 类校验＋20 例自检（含 17 反例）
│   └── acceptance.py                九份样张回归验收台
├── assets/
│   └── 禁用词表.md                  由 validate.py --write-md 自动生成，请勿手改
└── output/样张/                     ← 九份验收样张＋验收报告
```

**三层分工**：知识层（references）供检索取材；计算层（scripts）**只判不算**——把体式规则变成机器可判定的阻断；解释层（Agent）负责路由判断与撰写，**不做运算**。

## 四、校验器用法

```bash
python scripts/validate.py --selftest             # 自检（20 例，含反例）——改规则后必跑
python scripts/validate.py < case.json            # 校验，读 JSON 的 verdict 字段
python scripts/validate.py --dump-rules           # 导出全部规则 JSON
python scripts/validate.py --write-md assets/禁用词表.md   # 由规则重生成本表
python scripts/acceptance.py                      # 九份样张回归验收
```

**12 类校验**：跨朝禁用词黑名单（73 条）／必含词白名单（8 朝）／必填字段（8 朝，含字段别名兼容）／身份禁告矩阵／程序闸门（隋逐级·宋书铺保识·明里老·清越诉）／抱告六类（清）／字数（宋明清，管"字格内呈控事由"）／人数（明清）／证据随状（案由近义词归一）／增减情罪检测／戳记占位／元代无头圆状。

**四条工程纪律**：
1. **阻断与预警分离**——`verdict` 取 `BLOCK / WARN / PASS`，BLOCK 时一个字的正文都不写。
2. **跳过 ≠ 通过**——未适用的检查项单列 `assertions_skipped` 并附原因（如宋代投白纸豁免书铺、元代甘结无须被告）。
3. **空分母不判满分**——输入为空时结论记 `unknown`（`LENGTH_UNKNOWN` / `EMPTY_DENOMINATOR`），不记 PASS。
4. **匹配前必须归一化**——繁简、异体、插空格、标点一律归一后再比对，否则「朱 语」可绕过黑名单、合规的繁体「謹狀」又会被误判缺收束语。**用户值不得放宽制度上限**（`length_limit` 取与制度档的较小者）。

## 五、已知边界（重要，勿越界使用）

**史料缺口（不可补）**
- **隋代**：《开皇律》全佚，传世司法文书格式为零。只能做**程序级**复原，输出首行强制标注【据隋制推定 · 暂无确证】。**不得为隋代生成当事人自书状纸。**
- **元代**：无统一律典，《大元通制》散佚，只能引《元典章》官修政书（**非律文**）。**元代无朱语库——这是史料空白，不是遗漏。**
- **唐代无"抱告"制度**：老幼笃疾是"不得告"（限制诉权），不是"由他人代告"（代理）。**不得虚构抱告人字段。**
- **宋代无"官代书戳记"**：宋代只有书铺印子，戳记是清代制度。

**层级不可外推**
- 清代附例必须标年份（雍正七年／乾隆七年／嘉庆二十二年）；混用不同年份的例等于串改法源。
- 黄岩档案状式条例仅对**台州府黄岩县同治十三年至光绪十五年**生效；冕宁"原告过三者"仅见乾隆四年一例。**外推即过度推断。**

**证据分级（贯穿输出）**
A 律典/出土实物/档案原件 → 可作阻断依据；B 政书/官箴 → 程序级与格式级；C 辑佚 → 仅制度叙述，**不可作阻断依据**；D 秘本技艺/已佚 → **不可作法源**，只能作风格参照。**讼师秘本为 D 级，清代且为查禁物**（乾隆七年例：刻印者杖一百流三千里）。

**待核事项**
各法源分册末尾均附「待核事项清单」（`references/01_法源_秦汉隋.md`、`02_法源_唐宋.md`、`03_法源_元明.md`、`04_法源_清.md`）。素材中标注"待核""待补"的条目，**入库前须以原书复核**，不得直接用于生成。本技能引用的原文均为现代标点与转引格式，正式输出时应以中华书局点校本核校。

## 六、伦理框架（千年红线）

**八朝一以贯之的红线是"不得加增"，不是"不得代写"。**
唐律356条"为人作辞牒加增其状"笞五十 → 宋承唐 → 明"增减情罪与犯人同罪" → 清"照本人情词据实誊写"。**代写本身合法，违法点在动了情罪。**

- 标准状（据实体）：默认输出，合法性来自"罪无增减"这一但书。
- 刀笔状（讼师体）：**须用户显式选择**，每次生成必附伦理声明，且三重硬拒绝——①无证据支撑却要求重罪朱语 ②"把小事写大""务必准理" ③伪造契券伤单中证。
