# 古代讼师文书撰写（ancient-chinese-litigation-drafting）

## 一、这是什么（定位与设计哲学）

**不是"文言文翻译器"，是「跨朝文书体式发动机 + 千年红线守门人」。**

这个技能解决一个别处解决不了的问题：让同一桩纠纷，在八个朝代的制度框架下分别成立。用户给出朝代、案由、当事人、经过与诉求，技能产出一份**在那个朝代真的能被官府收下**的文书，附白话附录，让当代人看懂"这事在古代是什么光景"。

### 承重设计判断（三条，决定一切下游）

**判断一：路由的第一道分叉不是案情，而是"谁执笔"。**
八朝文书最本质的差异不在格式繁简，而在**书写主体决定人称、语域与责任归属**。这一步错了后面全错——把秦代爰书写成当事人自述口吻，或把元代词状套上明代四字朱语，都是硬错误。

| 书写主体类型 | 朝代 | 人称 | 语域 |
|---|---|---|---|
| 官吏记录（官为当事人书） | 秦、汉、隋 | 第三人称记录 | 勘验笔录体，冷峻、逐项罗列 |
| 当事人自陈 + 代笔 | 唐、宋 | 第一人称陈情 | 谨辞／谨状的公文上行体 |
| 官选吏员独掌 | 元 | 当事人陈述，吏牍包装 | 平实吏牍体，不尚文采 |
| 官代书／讼师双轨 | 明、清 | 第一人称，两种笔法可选 | 官代书体（据实）／讼师体（渲染） |

**判断二：穿越八朝的红线是"不得加增"，不是"不得代写"。**
唐律356条"为人作辞牒加增其状"笞五十 → 宋承唐 → 明"增减情罪与犯人同罪" → 清附例"照本人情词据实誊写"。**八朝一以贯之的是"不得加增"，而非"不得代写"。** 这是本技能的伦理锚点，也是标准状／刀笔状两种输出模式的唯一分水岭。代写本身在唐即合法，在宋元明清是受管制的合法职业；**违法点永远在"动了情罪"。**

**判断三：史料层级必须进入产出本体，不能只写在设计文档里。**
【律】／【地方条例】／【秘本成例】／【据×制推定·暂无确证】四档标注随文输出。隋代《开皇律》全佚，只能给程序提示；元《大元通制》散佚，只能引《元典章》条格；清代附例必须标年份。**把 D 级技艺文本（讼师秘本）与 A 级律典等量呈现，是本技能最严重的失格。**

## 二、调用者（谁在何时调用）

- **直接用户**：想了解"这案子在古代会怎样"的当代人；做跨朝文书对照的写作者、研究者、教学者。
- **上游技能**：法律史教学类技能（要一份某朝文书作教具）、可视化技能（要文书实物文本再转图）。
- **不适用**：现代法律文书起草、纯文言翻译、学术论文写作——一律不接，见第十段铁律。

## 三、SOP 总览（六步）

```
S1 路由定位   → 定 dynasty，再定 scribe_identity / voice / document_type
S2 前置闸门   → 身份禁告矩阵 + 程序闸门 + 必填字段；不通过不生成（硬停）
S3 加载朝代包 → 读 references/spec_<朝组>.md 的格式规格 + 措辞库 + 硬约束
S4 生成正文   → 按该朝字段顺序填充，缺失输入标「拟补」，史料缺口标【据×制推定】
S5 机器校验   → python scripts/validate.py < case.json ，BLOCK 则回 S4 修
S6 白话附录   → 逐段译文 + 术语/称谓/律条释义；输出（只含正文与附录）
```

**S2 是硬停点**：前置闸门不通过时，**一个字的正文都不写**，改为向用户说明"在X朝此路不通"及其法源依据。这是本技能与"有求必应的作文机器"的根本区别。

## 四、输入（八朝超集 Schema，按朝代激活字段）

```yaml
dynasty: 秦|汉|隋|唐|宋|元|明|清        # ★ 决定加载哪套体式与措辞库
document_type: auto|<该朝文书名>          # auto=由 S1 路由
output_mode: standard|daobi               # 仅明清：官代书据实体 / 讼师刀笔体，默认 standard
year_label: "<年号+年份>"                 # 清必填（光绪十年）；各朝落款纪年都需要

parties:
  initiator: {name★, age, gender, li_jurisdiction★, social_rank, client_of, master}
  defendant: {name★, residence, kinship}      # kinship 是身份禁告校验的钥匙
  baogao_person:                              # 抱告。清必判；明为地方状式惯例（明律诉讼门十二条中无抱告条，
                                            #   属地方层级，切勿当作明律条文引用）；唐宋无此制，禁止生成

facts:
  case_type★: 田土|钱债|斗殴|婚姻|继承|人命|盗贼|户役|奸情|…
  event_time★: 精确到日（唐"明注年月"；秦需年月朔日时）
  place★: narrative★                          # narrative 是"增减情罪"校验的比对基准
  injury: {position, count, length_cun, width_cun, shape, weapon}   # 人命类必填
  stolen_list:                                # 盗案必填

procedure:
  receiving_organ★: 县司|州司|府|省|登闻鼓院|…
  procedure_history: {county, commandery, prefecture, secretariat}  # 隋必填
  via_shupu: bool                             # 宋代：民户必经书铺，false 则阻断
  baoshi_name:                                # 宋代：保识人（茶食人），空则阻断
  writing_person_name:                        # 明清：写状人姓名，空则"不准"

request★: 谒杀|乞治|请给公验|准理|验伤|拘究|追给|…
evidence: {witnesses: [], physical: []}       # 干证与物证；明清有随状证据门槛
```

**字段别名（校验器双向兼容，不必强改 Schema）**：本 Schema 用 `li_jurisdiction`（籍贯）、`social_rank`（身份）、`gender`（性别）、`witnesses`（干证）；校验器历史上用 `li`、`rank`、`sex`、`ganzheng`。二者已做**双向别名兼容**，按任一侧命名都能通过。若你另行扩展了字段，请同步登记到 `scripts/validate.py` 的 `_ALIAS_KEYS`，否则该字段会被当作缺失。

**缺失输入的处理分两类，绝不可混**：- **输入要素缺失**（用户没给姓名、籍贯等）→ 按该朝通例补全，并在正文中用 `〔拟补〕` 标注。
- **史料缺口**（该朝本就没有这种制度/文本）→ **不补**，标【据×制推定·暂无确证】或直接说明该制不存在。例：唐无"抱告"，不得为老幼妇女虚构代告人字段；隋无传世状式，不得从唐以后补写。

## 五、输出（契约：只含两块）

```
【一】文书正文
     〔朝代·文书名·书写主体〕 ←— 一行身份标记
     （按该朝体式逐字段落定；年号纪年；署名画押；【】层级标注；〔拟补〕标记）
【二】白话附录
     逐段白话译文（一段原文对一段白话，不合并、不概括）
     ├ 术语释义：状式/朱语/爰书/甘结等
     ├ 称谓释义：士伍、威公、生监、抱告等
     ├ 律条释义：所引律条的现代含义与法源定位（标 A/B/C/D 级）
     └ 制度背景：这条规矩为什么存在、当时怎么执行
```

**除此之外不加任何段落**——不写"分析"、不写"创作说明"、不写"我为什么这么写"。用户要看的是文书本身，不是技师的检修记录。

**三类过程性内容一律并入白话附录，不得另立段落**（否则与"只含两块"自相矛盾）：

| 过程性内容 | 落在何处 |
|---|---|
| S2 闸门未通过的说明（"此路不通"及其法源） | **不产出正文**；此时只输出该说明，作为唯一交付 |
| 史料层级标注（【律】/【地方条例】/【秘本成例】/【据×制推定】） | 附录「律条释义」各条的层级标记内 |
| S5 校验器的 WARN（越诉风险、增减情罪风险、篇幅预警） | 附录「制度背景」末条，标 `【校验提示】` |
| 刀笔状模式的伦理声明 | 附录**首条**，不可省略、不可下沉 |
| 〔拟补〕标记 | **正文内联**，不另作说明 |

## 六、详细步骤

### S1 路由定位

**先定朝代，再定谁执笔，最后才是案情。**

```
dynasty → scribe_identity → voice → document_type
```

> **本表只列每朝最常发的文书，不是全集。** 各朝文书全集以 `references/spec_*.md` 的「文书清单（路由表）」为权威——本表未列者（如清代的公呈、哀状、辩状、供状、保状、领状、验伤结状、催状、恳状、投状、拦词、遵断状、缴结状、领结状、离异状；元代的招伏、取状、辞状、责状、承管状、责领状；宋代的投白纸、投匦文书、不理状），**一律先查该 spec 的清单再定，不得自行发明文体名，也不得默认套用本表的"常发"文书**。

**朝代 → 文书角色对照表（先查此表，勿凭印象）**

| 朝 | 常发文书 | 关键判断 | 读哪一节 |
|---|---|---|---|
| 秦 | 告／爰书／封守／劾／乞鞫 | 告与爰书**必须分轨**：告是当事人陈述，爰书是官吏笔录 | `spec_秦汉隋.md` 模块1-2 |
| 汉 | 告／劾／辞／传爰书／自告／乞鞫 | **告属下、劾属上**；先做身份资格审查 | `spec_秦汉隋.md` 模块1-2 |
| 隋 | 录状／逐级申诉状 | **唯一硬约束是逐级**：县→郡→州→省→诣阙→登闻鼓 | `spec_秦汉隋.md` 模块1-2 |
| 唐 | 辞／牒／辞辩／告人罪辞 | 庶人用**辞**，品官杂任用**牒**；唐代无"告状"这一文体名 | `spec_唐宋.md` 模块一 |
| 宋 | 状／投白纸／投匦文书 | 民户必经书铺；官人进士僧道公人可自书 | `spec_唐宋.md` 模块一 |
| 元 | 词状／招伏／取状／甘结 | 一律命名"词状"；文末署官选书状人吏 | `spec_元明.md` 一 |
| 明 | 告状／诉状／禀状／呈状／和息状／结状 | 户婚田土斗殴须先经里老理断 | `spec_元明.md` 二、三 |
| 清 | 告状／禀词／公呈／诉状／哀状／供状／甘结／和息状 | 五段式；生监用**禀词**不用告状 | `spec_清.md` 一、二 |

### S2 前置闸门（硬停点）

依次跑四道闸门，**任一不过即停，改为说明为什么不写**：

1. **身份禁告矩阵** — 输入 `parties.defendant.kinship`：
   - 子告父母／妇告威公／奴婢告主 → 秦汉"勿听而弃告者市"，唐"绞"，明清干名犯义
   - 告期亲尊长、外祖父母、夫、夫之祖父母 → 唐"虽得实徒二年"
2. **程序闸门** —
   - 隋：`procedure_history` 缺县/郡/州/省任一级 → 越级不成立
   - 宋：民户 `via_shupu=false` → 不经书铺不受；`baoshi_name` 空 → 状无保识不受
   - 明：户婚田土钱债斗殴等首审未经里老 → **提示"径告者不问虚实先杖六十"**（仍可出具备用告状，但必须告知）
   - 清：收受机关是府/司而无本管州县前审 → 越诉，"即实亦笞五十"
3. **必填字段** — 元代缺被告姓名即"无头圆状"不予受理；明清缺写状人姓名即"不准"；人命案缺伤痕凶器、盗案缺清单、婚田钱债缺随状证据 → 按状式条例标"不准"
4. **跨朝用语** — 跑 `validate.py` 的黑名单；明清用语倒推到唐以前一律阻断

### S3 加载朝代包

**只加载命中该朝的包**，这是防止跨朝辞库互借的机制保障。

| 朝代 | 加载文件 | 重点读哪几节 |
|---|---|---|
| 秦/汉/隋 | `references/spec_秦汉隋.md` | 模块1路由表 · 模块2模板 · 模块3硬约束 · 模块4措辞库 |
| 唐/宋 | `references/spec_唐宋.md` | 模块一清单 · 模块二模板 · 模块三红线 · 模块四措辞库 |
| 元/明 | `references/spec_元明.md` | **元**：模块一元制 + **模块七 Skill 规格（元代输出骨架在"七"节内，模块二至六均为明代，不可套用）**；**明**：模块二至六 |
| 清 | `references/spec_清.md` | 一清单 · 二模板 · 三硬约束 · 四措辞库 · 六规格 |

> **元代没有独立模板模块**（审计发现）：`spec_元明.md` 的模块三「格式规格」、模块四「硬约束」、模块五「措辞库」**全部是明代内容**。元代的文书骨架与字段要求集中在**模块七「Skill 规格建议」的"元代输出"一节**。误把明代模板当元代模板，是本技能最容易犯的跨代错误。

**引用核验时**再读 `references/00_法源总纲.md`（四级证据分级、引用标注模板、校验规则→法源映射表），以及与该朝对应的法源分册：秦/汉/隋 → `references/01_法源_秦汉隋.md`；唐/宋 → `references/02_法源_唐宋.md`；元/明 → `references/03_法源_元明.md`；清 → `references/04_法源_清.md`。每册末尾均附**待核事项清单**，其中标注"待核"的条目须以原书复核后方可用于生成。

### S4 生成正文

按该朝**字段顺序**填充（顺序不可颠倒，详见各包模板）：

- **秦**：爰书起首"爰书："不可省 → 时间（年月朔日时）→ 发告人身份（须写全 `某里士伍甲`）→ 告辞（引号内第一人称）→ 官吏受命与行动（第三人称）→ 勘验（尺寸逐项）→ 讯问与"辞曰"→ 处置与回报
- **汉**：告／劾分流决定人称与收束语（自诉"乞×治，为报"，劾"当论，敢言之"）
- **隋**：首行强制标【据隋制推定 · 暂无确证】→ 逐级层级 → 枉屈事实 → 录状由有司执笔
- **唐**：年月日 → 身份姓名（逐项单列，奴婢牲口列明）→ 辞 → 受诉机构（须实名）→ 所请事项 →"请裁，谨辞"
- **宋**：乡里→耆长→户等→姓名→住处距县衙里数→客户归属→年龄→疾荫/妇女娠孕→堪任杖责→系第几状→所诉某事→"伏乞县司施行，谨状"
- **元**：状首（含**户计**）→"状告为（直述事由）事"→指陈实事（被告姓名居址、年月、经过）→证据（经官验过）→甘结"所供前词是的实并无虚诳"→书状人吏署名
- **明**：状首→"状告为（朱语）事"→十段锦十槽位（可裁剪）→被告干证→"伏乞老爷台下…上告"→年月日→**写状人**＋歇家
- **清**：状首（含歇家/保戳/做状人/写状人/戳记占位）→前批留白→"为（直书事由／朱语）事"→正文→被证→"伏乞大老爷台前恩准……施行。上告。如虚坐诬。"→年月日→画押

**事由句是全文第一个格式节点，也是两种模式的分水岭**：清标准状必须直书（"为婚姻事""为田土事"），黄岩状式条例明确"如敢不遵，仍前做造注语者，提代书重处"；刀笔状才用四字朱语。

### S5 机器校验

把 S4 成稿组织为 JSON，喂给校验器：

```bash
python scripts/validate.py < case.json
```

结论读 `verdict` 字段：`BLOCK`（回 S4 修）/ `WARN`（可交付但须在附录披露风险）/ `PASS`。
`assertions_skipped` 与 `LENGTH_UNKNOWN` 等"空分母"项**不等于通过**，须如实披露为 unknown。

### S6 白话附录

- **逐段对齐**：一段原文对一段白话，不合并段落、不概括转述。
- **术语/称谓/律条三层释义**：如"爰书"要说明它不是诉状而是官吏司法笔录；"威公"指丈夫的父亲；"教唆词讼"条的免责出口是"教令得实"与"罪无增减"。
- **律条释义必带法源定位与证据级别**：A（律典/出土实物/档案原件）／B（政书/官箴）／C（辑佚）／D（秘本技艺/已佚）。
- **如实交代边界**：该朝存在哪些史料缺口、哪些地方条例不能外推，一并写进附录。

## 七、错误处理

| 触发 | 处置 |
|---|---|
| 输入未指定朝代 | **不得默认任何朝代**。八朝优先级不可互换，必须追问（用选择题卡片，见第九段） |
| 输入朝代不存在（如"南北朝""五代"） | 说明本技能覆盖秦—清八朝，列出可选项；不臆造格式 |
| 用户要求"隋代状纸格式" | 说明《开皇律》全佚、传世状式为零，只能给程序级复原；建议转向唐以后模板 |
| 用户要求给唐代老幼妇女加"抱告" | **拒绝**：唐代无此制，老幼笃疾是"不得告"而非"由他人代告" |
| 用户要求把田土纠纷写成"打死人命" | **拒绝并解释**：构成增减情罪，唐笞五十、明清与犯人同罪。免责出口仅"教令得实""罪无增减" |
| 用户要求伪造契券／伤单／中证 | **拒绝**：伪证属律文明示犯罪构成 |
| 用户要求"务必准理""把小事写大" | **拒绝切换到刀笔状**，并说明理由与法源 |
| 明清用户选刀笔模式但案情无证据支撑重罪朱语 | **拒绝**；有证据支撑则放行，但每次生成必附伦理声明 |
| 校验器报 `CHECKER_ERROR` | 校验器自身抛错，须人工复核该项，不得当作通过 |
| 输入要素缺失 | 按该朝通例补全并标〔拟补〕；**史料缺口不补**，标【据×制推定】或说明该制不存在 |
| 案情涉及真实在世当事人 | PII 处理：姓名可保留（用户提供），但要求脱敏时以「某甲/某乙」化名并说明 |

## 八、Gotchas（附 Why）

1. **不能给隋代写"状"。** Why：《开皇律》全佚，传世隋代司法文书格式为零；且隋制是"有司录状奏之"，当事人不得自书鼓状。写了就是纯虚构。
2. **不能给汉代写"起诉状""原告""被告"。** Why：汉代文书名是告、劾、辞、传爰书、自告、乞鞫。"诉状"最早见于宋代语境。
3. **"抱告"是清代制度，唐宋绝不可有。** Why：唐律对老幼笃疾是"不得告"（限制），不是"由他人代告"（代理）；宋代只有"投白纸"的雏形性放宽，仍非抱告术语。
4. **明清用语最容易倒推。** Why：明清讼学史料最丰富（朱语、珥语、十段锦、官代书戳记、状式条例），调用顺手，因而最危险。校验器黑名单是本技能的核心防线。
5. **元代没有朱语库，这不是遗漏。** Why：《元典章》与黑水城文卷均为平实吏牍体，未留下与《萧曹遗笔》相当的四字珠语体系。史料空白就写空白，**不虚构**。
6. **"不得加增"≠"不得代写"。** Why：唐律356条的疏议明言"为人雇倩作辞牒"，即代写合法，违法点在"加增其状"。把红线设在"禁止代写"上是历史误读，会误伤标准状模式。
7. **附例必须标年份，地方条例不可外推。** Why：清律文自乾隆五年基本不变但例逐年增修，混用不同年份的例等于串改法源；黄岩档案年代跨度仅 16 年，冕宁"原告过三者"仅见乾隆四年一例，外推至整个清代属过度推断。
8. **讼师秘本是 D 级且清代被明令查禁。** Why：乾隆七年附例"坊肆所刊讼师秘本……尽行查禁销毁"，刻印者杖一百流三千里。刀笔模式的伦理声明必须点明这一层，而不只是"不得用于实际诉讼"。
9. **字数、人数限制都是地方层级，不是全国法。** Why："每状不过三行每行不过五十字"出于明人官箴，"每呈不得过二百字"出于康熙《天台治略》县示。默认按地方档处理并标注，不得上升为全国律典。
10. **一条从不失败的检查等于没有检查。** Why：本技能的校验器自带 `--selftest`，覆盖 20 例含 17 例反例，并断言 16 个检查码**每个都至少被反例激活过一次**；未激活即判自检失败。
11. **空分母不得判满分。** Why：字数/字段检查在输入为空时分母为 0，此时结论必须是 `unknown`（记为 `LENGTH_UNKNOWN`／`EMPTY_DENOMINATOR`），不得记 PASS。
12. **输出不加"创作说明"。** Why：用户要的是文书本身。把检修记录混进交付物，是信息密度最低的一种失败。
13. **二百字管的是"字格里的呈控事由"，不是整张纸。** Why：《福惠全书》卷十一"状刊**格眼**三行，以一百四十四字为率"；淡新档案"第二、三折为呈控事由（印成方格共 720 格）"。状首身份栏、被证栏、官代书戳记都是**版刻**，不占字格。校验器据此只阻断正文超限，全文超 1.5 倍则另发软预警。**但请把实质事实写进正文**——塞进套语或附记栏既不会被字数检查拦下，也会让官府无从核验。
14. **校验器不覆盖唐代人命的伤单凶器。** Why：随状证据门槛（证据随状）是宋明清的地方状式／官箴层级，唐律对此无同等要求——唐律第355条只要求"明注年月，指陈实事"。故唐人命辞**不查伤单**是刻意的范围限定，不是遗漏；此时须由 S4/S6 人工把关伤情凶器是否写明。

## 九、协作技能

| 情形 | 交给谁 | 交接物 |
|---|---|---|
| 输入模糊、朝代/案由/身份全无 | 用 `AskUserQuestion` 卡片追问（朝代用选项、案由用选项、身份用选项），**不臆测** | 结构化输入 |
| 需要把文书转成图（流程/关系/时间轴） | 可视化能力 | 文书正文 + 字段结构 |
| 需要核验引用的律条是否现行/版本 | 法源核验路径（读 `references/00_法源总纲.md` §六「校验规则→法源映射表」与对应法源分册的「待核事项清单」） | 条文号 + 版本 + 核验结论 |
| 需要跨朝对照（同一案情八朝各一份） | 本技能循环调用（每朝走一遍 S1—S6） | 八份文书 + 差异说明 |

**追问规范**：朝代必须给选项卡片（秦/汉/隋/唐/宋/元/明/清），案由给选项（田土/钱债/斗殴/婚姻/继承/人命/盗贼/户役/奸情/其他），当事人身份给选项（庶民/生监/有职/老幼/妇女/奴婢/僧道）。每轮最多三题，选择题优先，每题后用英文括号标注提问目的。

## 十、铁律

1. **先定"谁执笔"，再定案情。** 路由根节点是书写主体，不是案由。
2. **跨朝用语一律阻断。** 明清用语不得倒推唐以前；校验器黑名单为强制闸门。
3. **红线是"不得加增"。** 代写可，增罪不可。删改加重即落"与犯人同罪"，无一朝例外。
4. **史料层级随文标注。** 【律】／【地方条例】／【秘本成例】／【据×制推定·暂无确证】，四档不得混同。
5. **秘本不是法源。** D 级技艺文本不得与律典等量呈现；清代且为查禁物。
6. **史料缺口不补。** 输入要素缺失可〔拟补〕，制度/文本缺失绝不可编。
7. **前置闸门不过，一字不写。** 改为说明"此路不通"及其法源。
8. **引用必标核验状态。** `[已核验]` 或 `[须核验]`；未核验的法律结论不得作为阻断依据。
9. **不伪造实物。** 官代书戳记一律输出占位符（`［此处加盖官代书戳记：代书某某］`），不模拟官印。
10. **不承诺胜诉。** 只产出文书，不预测判决；涉及当代真人真事时明确本技能产出为历史形态演示，不构成法律意见。
11. **输出只含正文与白话附录。** 不夹带分析、说明、自评。
