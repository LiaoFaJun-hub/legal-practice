# 样张一 · 秦 · 爰书

> **统一案情**：某甲有祖遗田廿亩，同里某乙私移田界（秦律称"盗徙封"），侵甲田廿步；甲往争，乙不与。
> **本朝路由**：秦代"告"是当事人告诉行为，"爰书"是官吏据此制作的司法笔录。**二者必须分轨**——爰书一律第三人称官吏行文体，不得写成当事人自述。本件取"告发类爰书"。

---

## 【一】文书正文

**【秦 · 爰书 · 县令史笔录】〔体式据《睡虎地秦墓竹简·封诊式》告发类爰书复原〕**

```
爰书：廿六年三月朔壬寅，某里士伍甲告曰：
「〔拟补〕士伍甲，居某里。同里士伍乙盗徙封，侵甲田廿步。谒执乙，诊田封。」

即令令史某往诊。令史某与牢隶臣某即甲、乙田所诊封。
故封在某所，东西袤廿步，南北广十步。今封徙西十步，土新穿，迹类人足。甲田见侵廿步。

丞某讯乙，辞曰：「〔拟补〕乙诚徙封，毋它坐罪。」

诊典某、甲伍公士某，皆言曰：「封故在某所，今徙西十步，甲田见侵廿步，毋它异。」

当腾，腾皆为报，敢告主。
```

## 【二】白话附录

### 逐段白话译文

**「爰书：廿六年三月朔壬寅，某里士伍甲告曰……」**
爰书：秦王政二十六年三月初一壬寅日，某里的士伍（无爵的成年男子）甲前来告发说：

**「士伍甲，居某里。同里士伍乙盗徙封，侵甲田廿步。谒执乙，诊田封。」**
我是士伍甲，住在某里。同里的士伍乙私自移动了田界，侵占我的田二十步。请拘执乙，并勘验田界。

**「即令令史某往诊……」至「甲田见侵廿步。」**
（官府受理后）当即命令令史某前往勘验。令史某与牢隶臣某一起到甲、乙的田地处勘验田界。旧田界原在某处，东西长二十步，南北宽十步。现在田界向西移动了十步，移界处的泥土是新挖开的，痕迹像人的脚印。甲的田被侵占二十步。

**「丞某讯乙，辞曰：『乙诚徙封，毋它坐罪。』」**
县丞某讯问乙，乙的供辞说：我确实移动了田界，没有其他罪。

**「诊典某、甲伍公士某，皆言曰……」**
查验里典某与甲同伍的公士某，二人都说：田界本来在某处，现在向西移了，甲的田被侵占二十步，没有别的异常。

**「当腾，腾皆为报，敢告主。」**
应当移送的文书，都移送回报，谨此禀告主官。

### 术语释义

| 术语 | 释义 |
|---|---|
| **爰书** | 秦代官吏在勘验、讯问、封守、执捕等环节制作的司法笔录。**它不是当事人提交的诉状**，而是官府办案的记录。本件中"告"（甲的告诉）只是爰书里被引用的一段，文书主体仍是官吏的第三人称记录。 |
| **朔** | 农历每月初一。"三月朔壬寅"即三月初一、干支为壬寅，秦代纪时须精确到朔日与时刻（本件仅系日，属〔拟补〕）。 |
| **辞曰** | 供辞的开头标记，后接被讯问人的原话。 |
| **诊** | 勘验、查验。此处指实地丈量田界。 |
| **腾** | 移送上呈。"当腾，腾皆为报"即应当移送的文书一律移送回报。 |
| **毋它坐罪** | "没有其他应当论罪的罪行"，是秦汉口供的标准结语。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **士伍** | 秦代无爵位的成年男子，军爵序列中最基础的身份。"某里士伍甲"是秦代文书对平民的标准写法——**爵级＋里籍＋姓名缺一不可**。 |
| **公士** | 秦二十等爵的第一级。此处"甲伍公士某"指与甲同伍（五家为伍）的证人，因其有爵一级而书"公士"。 |
| **令史** | 县廷属吏，负责勘验、拘执、制作文书。 |
| **牢隶臣** | 官府掌握的一种刑徒，常随令史承担执捕、勘验等杂役。 |
| **丞** | 县丞，县令的副手，主掌审讯。"丞某讯乙"即由县丞主持讯问。 |
| **里典** | 里的负责人，相当于后世里正，负责基层纠举与见证。 |

### 所引律条与制度背景

- **盗徙封**：《睡虎地秦墓竹简·法律答问》："盗徙封，赎耐。可（何）如为'封'？'封'即田千（阡）佰（陌）顷半（畔）'封'殹（也），且非是而盗徙之，赎耐。"——**私自移动田界，处"赎耐"**（以财物赎免耐刑）。这是本件罪名的直接法律依据，也是"田土纠纷"在秦代最精确的法律落点：秦代没有后世的"侵占田产"民事之诉，只有"盗徙封"这样的罪名化处理。
  > **〔待核〕独立审计提示**：本条**未见于本技能 `references/01_法源_秦汉隋.md`**——该分册只收录了《法律答问》的「非公室告」「以乞鞫」两条。条文本身出自真实秦简整理本，但**在本技能的法源基准内没有可对照的登记**。按「未核验不引用」的纪律，正式使用本件前应回查《睡虎地秦墓竹简》整理本原书，并把该条补入法源分册。**在此之前，本件应视为「基准缺口」，而非「已核验」。**
- **裁判方式**：秦代田界纠纷由官府勘验定界，而非依契券确权。本件中"契券"未被提及，正是因为秦代土地制度以国家授田与田界登记为主，**契券尚未成为民事确权的核心凭证**——这与明清"田土须附契券方可准理"恰成对照。
- **身份禁告**：《法律答问》："子告父母，臣妾告主，非公室告，勿听。"——本件为同里平民间争讼，属"公室告"，不受此限。若改为子告父、奴告主，则秦代直接"勿听"，本技能也不得为其生成文书。
- **史料边界**：凡涉及未确证事项（如本案具体年月的干支），本件标注〔拟补〕。《封诊式》原简中的爰书多不载具体年月，此处按秦代"必载年月朔日"的硬约束补入，属**体式推定**而非原简实有。

> **史料层级**：本件所依《睡虎地秦墓竹简·封诊式》《法律答问》属出土实物（A 级证据），可支撑条文级校验；但"年月朔日"的补入属体式推定，须与原件区分看待。
