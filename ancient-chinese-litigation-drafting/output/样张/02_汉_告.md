# 样张二 · 汉 · 告

> **统一案情**：某甲有祖遗田廿亩，同里某乙私移田界，侵甲田廿步；甲往争，乙不予。
> **本朝路由**：汉代首要分支是 **告属下、劾属上**——被害人或亲属自下而上发端走"告"，官吏主动纠举走"劾"。本件为平民自诉，取"告"。汉代**没有代写职业的法律地位**，故无写状人字段。

---

## 【一】文书正文

**【汉 · 告 · 当事人自诉】〔体式据张家山汉简《二年律令·告律》及汉简告辞体例复原〕**

```
〔拟补〕孝文十二年四月丙寅，某县某乡某里士伍甲告曰：
「居某里。同里士伍乙盗徙田封，侵甲田廿亩。甲执田券往争，乙不与，反詈甲。
甲自以其罪告，乞县治，为报。」

干证：里典某、伍人公士某。
```

## 【二】白话附录

### 逐段白话译文

**「孝文十二年四月丙寅，某县某乡某里士伍甲告曰：」**
汉文帝十二年四月丙寅日，某县某乡某里的士伍甲前来告发说：

**「居某里。同里士伍乙盗徙田封，侵甲田廿亩。」**
我住在某里。同里的士伍乙私自移动田界，侵占我的田二十亩。

**「甲执田券往争，乙不与，反詈甲。」**
我拿着田契前去理论，乙不肯还田，反而辱骂我。

**「甲自以其罪告，乞县治，为报。」**
我以自己的名义就此事提出告诉，请求县廷受理审断，并批复回报。

**「干证：里典某、伍人公士某。」**
人证：里典某、同伍的公士某。

### 术语释义

| 术语 | 释义 |
|---|---|
| **告** | 汉代诉讼的第一类发端方式，指当事人或亲属自下而上向官府告诉。审理时**以告诉所指控的罪行为限**，超出范围即"鞫狱故不直"。 |
| **劾** | 与"告"相对的官吏纠举，属官吏法定职责。本件为平民自诉，故用"告"。 |
| **乞县治，为报** | "请求县廷审断，并批复回报"——汉代告辞的标准收束语。"为报"是请求回复的固定用语，后世的"请求依法处理"与之最接近。 |
| **自以其罪告** | 以本人的名义、就此事提出告诉。此语与"自告"（自首）不同，须区分。 |
| **田券** | 田契。汉代土地买卖与持有已有券书，但**券书尚未成为受理的强制随状证据**——这是与明清"田土无契券不准"的关键差别。 |
| **詈** | 辱骂。汉律中"詈"本身可构成罪名（如殴詈父母）。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **士伍** | 秦汉均有无爵成年男子的"士伍"身份。汉代文书承秦制，仍以"爵／身份＋县乡里＋姓名"标注当事人。 |
| **里典** | 里的负责人。汉代基层纠举与见证的核心人物。 |
| **伍人** | 同伍（五家为伍）之人。汉代基层连坐与举证的法定单位。 |
| **公士** | 二十等爵第一级。汉代告律规定"年未盈十岁及癃者、城旦舂、鬼薪白粲告人，皆勿听"，故干证须为有完全资格者，书其爵以示身份。 |

### 所引律条与制度背景

- **告劾为限**：《二年律令·具律》："治狱者，各以其告劾治之，敢放讯杜雅，求其它罪，及人毋告劾而擅覆治之，皆以鞫狱故不直论。"——审理不得超出告诉所指的罪行，亦不得无告劾而擅自追究。**这是汉代文书写作最重要的边界：告什么就审什么。**
- **诬告反坐**：《二年律令·告律》："诬告人以死罪，黥为城旦舂；它各反其罪。"——告诉不实的后果由告者承担。本件文书末尾虽无明清式的"如虚坐诬"四字（该语为明清状式套语），但反坐责任同样存在。
- **身份禁告（汉代最严）**：《告律》："子告父母，妇告威公，奴婢告主、主父母妻子，勿听而弃告者市。"——子告父母、媳告公婆、奴婢告主人及主人父母妻子，一律不受理，且**把告者本人处死并暴尸于市**。本件系同里平民互告，不受此限。
- **不孝须"三环之"**：《告律》："年七十以上告子不孝，必三环之。三环之各不同日而尚告，乃听之。"——七十岁以上者告子不孝，须三次退回、隔日再来仍坚持，才予受理。这是汉代对尊长诉权的程序性缓冲。
- **史料边界**：汉代**未见全国统一的状式、字数限制与代书署名制度**。现存居延、敦煌汉简所见告诉、辩辞、爰书、证词，只能说明基层司法书面实践丰富，**不能据此断言全国已行统一状式**。本件字段顺序属体式复原。

> **史料层级**：《张家山汉墓竹简·二年律令》告律、具律、贼律属出土实物（A 级证据），可支撑简号级校验；本件所补年月干支为体式推定（标〔拟补〕）。
