# 样张三 · 隋 · 录状

> **统一案情**：某甲有祖遗田廿亩，同里某乙私移田界，侵甲田廿步；甲逐级陈诉，县、郡、州、省皆不理，遂诣阙申诉。
> **本朝路由**：隋代唯一可确证的硬约束是**逐级申诉**——县→郡→州→省→诣阙→挝登闻鼓，**越一级都不成立**。且隋制是"有司录状奏之"，**当事人不得自书鼓状**，故本件由有司执笔。
> **史料缺口声明**：《开皇律》本文散佚，传世隋代司法文书格式为零，本件全篇为程序级复原。

## 【二】白话附录

### 逐段白话译文

**「开皇十七年某月某日，某州某县民某甲状称：」**
开皇十七年某月某日，某州某县百姓某甲具状陈述说：

**「籍系某县某乡，年肆拾。」**
我的籍贯在某某县某某乡，年纪四十岁。

**「某年某月，同县民某乙盗移田封，侵甲田廿步。甲执田契往争，乙不与。」**
某年某月，同县的百姓某乙私自移动田界，侵占我的田二十步。我拿着田契前去理论，乙不肯还田。

**「甲于某年某月某日陈诉本县，县不理；……省仍不理。」**
我先后于某年某月某日向本县陈诉，县不予受理；某年某月某日按次序向本郡陈诉，郡不予受理；某年某月某日按次序经本州陈诉，州仍不予受理；某年某月某日按次序经省陈诉，省仍不予受理。

**「伏请录状奏闻，乞赐矜察。」**
恳请将本状记录上奏，请求予以怜察。

**「有司录状奏之。」**
主管官署记录此状并上奏。

### 术语释义

| 术语 | 释义 |
|---|---|
| **录状** | 隋代唯一可确证的文书行为名词。据《隋书·刑法志》"有司录状奏之"，指**由官府记录当事人陈诉的内容并上奏**。它是官府行为，不是当事人提交的文书——**这正是隋代不能生成"当事人自书状纸"的制度原因**。 |
| **枉屈** | 冤屈、有理而不得申。隋代逐级申诉的启动条件是"有枉屈县不理者"，即须确有冤抑且下级不受理。 |
| **以次** | 按次序、逐级。"令以次经郡及州"即必须一级一级往上走。 |
| **诣阙** | 亲赴朝廷宫阙申诉。是省仍不理之后的救济途径。 |
| **挝登闻鼓** | 击打登闻鼓鸣冤。隋代此制为**最后的救济**，条件是"有所未惬"（对省的处置仍不满意）。 |
| **矜察** | 怜察、体恤审察。〔拟补〕用词，属体式推定。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **有司** | 主管官署。隋代录状的主体，非当事人。 |
| **大理** | 大理寺，隋代中央审判机关。死刑须"悉移大理案覆"。 |
| **民** | 〔拟补〕的当事人标注。隋代文书中的自称格式无确证材料，此处仅为占位。 |

### 所引律条与制度背景

- **唯一确证的条文原文**（《隋书》卷二十五《刑法志》）：
  > "有枉屈县不理者，令以次经郡及州，至省仍不理，乃诣阙申诉。有所未惬，听挝登闻鼓，有司录状奏之。"
- **程序结构**：县 → 郡 → 州 → 省 → 诣阙 → 挝登闻鼓。四个层级缺一不可，**越级陈诉在隋制中不成立**——本技能遇越级输入时不得生成文书，只能说明"此路径在隋制中不成立"。
- **不能引用的东西**：隋代**没有任何一条确证条文**涉及文书格式、套语或当事人自称。因此：
  - 不得为隋代写"状式""状首""写状人"；
  - 不得使用唐以后的"谨辞""谨牒"，更不得使用明清的"伏乞青天""所结是实""朱语""十段锦""官代书戳记"；
  - 唐代的"越诉笞四十"**是唐律规定，不得倒推为隋制**。
- **罚则的空白**：本次检索未取得隋代关于越诉或不实陈述的具体罚则原文。本件因此**不列罚则**——史料空白处写空白，不以推测填充。
- **史料层级最弱的一朝**：八朝之中，隋代法源强度最低。秦汉靠出土简牍能做到简号级精确，隋代则跌入**律文全佚的谷底**，只能做程序级校验。这是本技能必须坦承的能力边界。

> **史料层级**：本件所依《隋书》卷二十五《刑法志》属传世史籍（**B 级证据**），仅可支撑程序级与格式级叙述；《开皇律》本文已佚（**D 级**），无原文可引。全篇字段名为工程推定，**不得作为隋代文书格式的实证**。
