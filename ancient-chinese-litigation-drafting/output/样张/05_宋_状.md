# 样张五 · 宋 · 状

> **统一案情**：某甲有祖遗田廿亩，同村某乙私移田界，侵甲田廿步；甲执契往争，乙不与。
> **本朝路由**：宋代"状"已是诉讼文书主称。**民户必经书铺、须经茶食人保识**，否则"不经书铺不受、状无保识不受"。状首字段顺序固定不可颠倒，正文限二百字、一状只诉一事。
> **本件限定**：具状人为民户，经书铺依式书状，保识人已具。正文控制在二百字以内。

---

## 【一】文书正文

**【宋 · 状 · 民户经书铺投陈】〔体式据李元弼《作邑自箴》卷八状式与朱熹《约束榜》复原〕**

```
〔拟补〕元祐五年三月二十日
某州某县某乡某里某村
耆长某甲　　户等第三等
某甲（年四十），无疾荫，合为状首，堪任杖责，系第壹状，
住本村，去县衙一十里，
经由某书铺依式书状
被论人某乙，住本村，去县衙一十里
右某甲，今为田土事，元祐五年二月初三日，同村人某乙盗移田封，侵某甲田廿步。某甲执契券往争，某乙不与。契券见在，粮仍某甲输纳。
委不是代名虚妄、无理越诉、隐匿前状，如违，甘伏断罪号令。
伏乞县司施行，谨状。
某甲，押。
```

## 【二】白话附录

### 逐段白话译文

**「元祐五年三月二十日　某州某县某乡某里某村」**
元祐五年三月二十日，某某州某某县某某乡某某里某某村。

**「耆长某甲　　户等第三等」**
本村耆长（乡村负责教化与催督的长者）为某甲；本户户等为第三等。

**「某甲（年四十），无疾荫，合为状首，堪任杖责，系第壹状，住本村，去县衙一十里」**
我某甲，年四十岁，无残疾、无荫赎，可以充当状首、能够承受杖责（即自认可负反坐之责）；本次是第一次投状；住本村，距县衙十里。

**「经由某书铺依式书状」**
本状经由某某书铺依照官颁状式书写。

**「被论人某乙，住本村，去县衙一十里」**
被诉人某乙，住本村，距县衙十里。

**「右某甲，今为田土事……」**
具状人某甲，现就田土一事陈诉：元祐五年二月初三日，同村人某乙私自移动田界，侵占我田二十步。我拿契券前去争论，乙不肯还田。契券现在仍在，税粮仍由我输纳。

**「委不是代名虚妄、无理越诉、隐匿前状，如违，甘伏断罪号令。」**
确实不是冒名虚告、不是无理越诉、也未隐匿以前的状纸；如有违反，甘愿接受断罪处置。

**「伏乞县司施行，谨状。」**
恳请县司施行。谨具状。

### 术语释义

| 术语 | 释义 |
|---|---|
| **状** | 宋代州县第一审起诉的主载体。宋代的"告状""诉状"是"状"的通俗称谓，**非法定文体专名**。 |
| **合为状首，堪任杖责** | 宋代特有字段，意为"可以充任状首、能够承受杖责"。具状人以此**自认可负反坐后果**——这是宋代独有的自我责任声明，唐代无此表述。 |
| **系第几状** | 本次是初状还是第几次投状。须如实填写，不得隐匿前状。 |
| **委是（不是）代名虚妄** | "确实不是（冒名虚告）"。朱熹《约束榜》状式末段的固定自证语。 |
| **甘伏断罪号令** | 甘愿接受断罪处分。宋代状尾保证语。 |
| **谨状** | 宋代结尾套语。**不可写作"谨辞"——那是唐代语。** |
| **耆长** | 宋代乡村基层负责人，状首须列其名以明所辖。 |
| **户等** | 宋代按资产划分的民户等级（一至五等），是差役与赋税的依据，也是身份定位字段。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **民户** | 与"客户"相对，指有田产、独立立户的百姓。**宋代民户必经书铺写状**；官人、进士、僧道、公人四类可自书。 |
| **客户** | 无田产、依附于主户的佃客。若是客户，状首须注明"系某人客户"——这是**身份依附关系的法定披露**。 |
| **茶食人** | 保识人的俗称。状须经其开雕、印子、保识，方听下状；若所诉虚妄，书铺与茶食人一例科罪。 |
| **书铺** | 官府系籍的代书机构。每名须召土著三人保识，并须无犯罪、非勒停吏人配军、非老疾不任科决及有荫赎之人、与本县典史非亲戚。**这是八朝之中最早的"代书准入制度"。** |

### 所引律条与制度背景

- **不经书铺不受、状无保识不受、状过二百字不受、一状诉两事不受**（黄震《词讼约束》，《黄氏日抄》卷七十八）
  四项硬性受理门槛。本件正文约 90 字（不含状首字段与落款），符合二百字之限；全篇只诉田土一事，符合"一状一事"。**关于二百字的计数口径**：史料未明是否包含状首身份字段，本件按"仅计正文字数"处理并在此披露该口径假设。
- **书铺准入**（《作邑自箴》卷八"写状钞书铺户约束"）
  > "写状钞书铺户，每名召土著人三名保识。自来有行止，不曾犯徒刑，即不是吏人勒停、配军拣放、老疾不任科决，及有荫赎之人，与本县典史不是亲戚。勘会得实，置簿并保人姓名籍定，各用木牌书状式并约束事件，挂门首。"
- **代写署名责任的最早依据**（《宋会要辑稿·刑法三》，**C 级辑佚**）
  > 咸平六年诏："代写状人不得增加词理，仍于状后著名，违者勘罪。"
  景德四年诏："令代笔人为状即不得增添情理。"

  这两条诏令是宋代代书责任化的最早依据，也是"不得加增"这条千年红线在宋代的落点。**注意：此二诏出自后人辑佚的《宋会要辑稿》，引用时须标注"辑佚"，不得径写"《宋会要》云"。**
- **越诉与逐级**（《宋刑统》卷二十四）
  > "今后诸色词讼及讼灾沴，并须先经本县，次诣本州、本府，仍是逐处不与申理及断遣不平，方得次第陈状及诣台省、经匦进状。其有蓦越词讼者，所由司不得与理，本犯人准律文科罪。"
  本件为州县第一审，尚未涉及越诉。若改为控府状，则须在状内**明注"某年月日经县陈诉、已经几日本县不结绝"**，否则人户与书铺一并收坐，并毁劈书铺名印。
- **宋代没有的东西**：无"官代书戳记"（那是清代制度，宋代只有书铺印子）；无"状式条例"（宋代对应"约束""榜"）；无明清式四字朱语珈语体系——**宋代措辞以直述为宗**。
- **共同禁令**（唐宋两朝）：状内不得称"上命"及"与民作主"之类言语，徽宗政和四年中书省言，此类状"并勿受理，令别承状"。

> **史料层级**：黄震《词讼约束》、朱熹《约束榜》、《作邑自箴》属官箴（**B 级证据**），可支撑程序级与格式级校验；《宋刑统》属律典（**A 级**）；《宋会要辑稿》所载两诏属辑佚（**C 级**），仅可支撑制度叙述，不作阻断依据。本件状首字段的复原依据为《作邑自箴》卷八与《约束榜》。
