# 样张六 · 元 · 词状

> **统一案情**：某甲有祖遗田廿亩，同里某乙私移田界，侵甲田廿步；甲执契往争，乙不与。
> **本朝路由**：元代把代书权收归**官选书状人吏**——"于籍记吏员内，遴选行止谨慎、吏事熟娴者，轮差一名专管书状"。民间书铺合法空间被挤压。故元代文书语域是**平实吏牍体**：指陈明确、有征验、不炫文采、不丑化对方、**不套明代四字朱语**。
> **本件限定**：民户某甲，由官选书状人吏代书，文末署其姓名并注明"籍记吏员"。

## 【一】文书正文

**【元 · 词状 · 官选书状人吏代书】〔体式据《元典章》卷五十三"诉讼·书状"及元代词状实例复原〕**

```
〔拟补〕大德十一年三月某日
告状人某甲，年四十岁，无疾，系某路某州某县某都某里人氏，为户计民户。
状告为田土事。

元贞元年二月初三日，同里民某乙盗移田封，侵某甲祖遗田廿步。某甲执契往争，某乙不与。
契一纸，经官验过。里正某丙见之。

有某丙为证，有前契为凭。

所供前词是的实并无虚诳，对问不实甘当诳官重罪不词。

大德十一年三月　日　　告状人某甲（押）
　　　　　　　　　　　书状人吏某丁（籍记吏员）
```

## 【二】白话附录

### 逐段白话译文

**「大德十一年三月某日　告状人某甲，年四十岁，无疾，系某路某州某县某都某里人氏，为户计民户。」**
大德十一年三月某日。告状人某甲，年四十岁，身体健康无疾病，是某路某州某县某都某里的居民，户籍为民户。

**「状告为田土事。」**
具状控告田土一事。

**「元贞元年二月初三日，同里民某乙盗移田封，侵某甲祖遗田廿步。某甲执契往争，某乙不与。」**
元贞元年二月初三日，同里的百姓某乙私自移动田界，侵占我祖遗的田二十步。我拿着契书前去理论，某乙不肯还田。

**「契一纸，经官验过。里正某丙见之。」**
有契书一纸，已经官府查验。里正某丙亲眼见到此事。

**「有某丙为证，有前契为凭。」**
有某丙作为人证，有前述契书作为凭据。

**「所供前词是的实并无虚诳，对问不实甘当诳官重罪不词。」**
以上所供全部属实，并无虚假；若经讯问与事实不符，甘愿承担欺官重罪，绝无推辞。

**「大德十一年三月　日　　告状人某甲（押）／书状人吏某丁（籍记吏员）」**
落款年月日，告状人某甲画押；由官选书状人吏某丁代书，注明其候补吏员身份。

### 术语释义

| 术语 | 释义 |
|---|---|
| **词状** | 元代百姓向官府提交的告诉文书，民刑皆用。**元代官府的自身公文则称"文状"**，二者不可混称。本技能在元代语境下把用户提交的文书一律命名为"词状"，不另造文体名。 |
| **状告为某某事** | 元代词状的起首格式。注意：**此处直述事由，不加四字套语**。 |
| **指陈明确、有征验** | 元代词状的核心内容要求：被告姓名居址、事情年月、凭据（契约、干证）须写清，不许含糊称疑。 |
| **所供前词是的实并无虚诳** | 元代具结语，意为"以上所供全部属实、并无虚假"。 |
| **对问不实甘当诳官重罪不词** | 元代具结语的后半，意为"若经讯问不实，甘愿承担欺官重罪、绝不推辞"。**这是元代词状的担保结构**，与明清"如虚坐诬"功能相近而用语不同。 |
| **户计** | 元代按职业与身份划分的户籍类别（民户、军户、匠户、驱口等）。**这是元代词状特有的身份字段**，明代文书不得出现"户计""驱口"等语。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **书状人吏** | 元代官选代书人。从"籍记吏员"（候补吏员名册）中遴选，标准是"行止谨慎、吏事熟娴"，**轮差一名专管书状**，任期一年。其身份是官府系统内的吏员，不是民间从业者。 |
| **籍记吏员** | 已登记在册的候补吏员。书状人吏的**唯一来源**，署款时须注明此身份。 |
| **里正** | 元代基层职役，负责催督赋役与基层纠举，此处充任见证。 |
| **告状人** | 元代对提起诉讼者的称谓。 |

### 所引条格与制度背景

- **书状权收归官选吏员**（《元典章·刑部·籍记吏书状》）
  > "今后令有司于籍记吏员内遴选行止谨慎、吏事熟娴者，轮差一名专管书状。"
  > （异文说明：部分引本作「举会有司」，`references/00_法源总纲.md` 已出「令」字校记。本件从「令」，标异文备查。）
  制度含义三层：人选来自"籍记吏员"名册、须经"遴选"而非招募；标准为"行止谨慎"（操守）与"吏事熟娴"（业务）；"轮差一名"为定额专任、定期轮换，目的在于**把代书行为纳入可追责的吏员管理链条**。
- **状铺之设的本意**（《元典章》，大德十一年五月）
  > "各处状铺之设，本欲书写有理词状，使知应告、不应告之例，庶革泛滥陈词之弊，亦使官府词讼静简，易于杜绝。"
  > "每呈词状到铺，依例书写，当日须要了毕，不许有留多余书写人等在铺。"
  这构成元代文书最直接的形式约束：**当日成稿、不冗长、先判断是否应予受理**。书状人吏若虚造情节、歪曲事实，当事人可禀官，情节严重者罢免。
- **无头圆状与私约文字**：元代"无头圆状"指无明确被告、头绪含糊的状纸，"私约文字"指未经官验的民间私约。二者均不予受理或令另行具状。**故元代词状必须强制出现"被告某人、住某处"与"凭据某契（经官验过）"两处**——本件中"契一纸，经官验过"即为此项。
- **元代没有的东西**：**没有与明代《萧曹遗笔》相当的四字朱语体系**。《元典章》与黑水城文卷所见均为平实吏牍体。本技能**不虚构元代朱语库**，也不把明代"虎豪吞业""豪强奸娶"等套语下推至元代——**这是史料空白，不是遗漏**。
- **法源性质的特殊性**：元代**没有一部可称"律典"的统一法典**。《大元通制》整体散佚，仅条格部分以《通制条格》残卷传世；《至正条格》2002 年才在韩国庆州发现元刊残本。因此元代只能引《元典章》这类**官修政书**（非律典），其条文性质是"条格断例"而非律文。**元代是八朝之中唯一不能做条文级律典校验的朝代。**

> **史料层级**：《元典章》卷五十三属官修政书（**B 级证据**），可支撑程序级与格式级校验，但**非律文**；《大元通制》已佚（**D 级**）。本件中"某甲""某乙"等具体人物、年月为〔拟补〕；"户计民户""书状人吏（籍记吏员）"等字段则属元代实有制度。
