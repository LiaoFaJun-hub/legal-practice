# 样张八 · 清 · 告状（标准状／官代书据实体）

> **统一案情**：某甲有祖遗田廿亩，同图某乙私移田界，侵甲田廿步；甲执契往争，乙不与。
> **本朝路由**：清代一纸文书由**状首—前批—正文—被证—官衔（状尾条例）**五段构成。**状尾无官代书戳记不准收受**（雍正七年例）。**output_mode = standard（官代书据实誊写）**，事由须直书，不得"做造注语"。
> **本件限定**：具状人民户某甲，男，四十岁，非抱告六类，故不设抱告人。

---

## 【一】文书正文

**【清 · 告状 · 官代书据实誊写（standard）】〔体式据黄岩诉讼档案状式与《大清律例》雍正七年例复原〕**

```
光绪十年三月初五日

状首：告状人某甲，年四十岁，系浙江台州府黄岩县三都二图籍，
　　　歇家某辛店，
　　　保戳某壬，
　　　做状人某癸，住三都二图，
　　　写状人某子，
　　　［此处加盖官代书戳记：代书某丑］

前批：（留白，俟州县官批语）

正文：为田土事。
　　　光绪十年二月初三日，同图某乙盗移田封，侵某甲祖遗田廿步。
　　　某甲执契券往争，某乙不与。契券见在，粮仍某甲输纳。

被证：被某乙，住三都三图；
　　　证某丙，住三都二图；
　　　中证某己。

官衔：（状式版刻，不填）

伏乞大老爷台前，恩准勘验追还施行。
上告。如虚坐诬。

光绪十年三月初五日　　　　　　告状人某甲（押）
```

## 【二】白话附录

### 逐段白话译文

**「状首：告状人某甲，年四十岁，系浙江台州府黄岩县三都二图籍」**
状首：告状人某甲，年四十岁，籍属浙江台州府黄岩县三都二图。

**「歇家某辛店，保戳某壬，做状人某癸，住三都二图，写状人某子」**
歇家（具保的旅店）为某辛的店铺；保戳（保人印记）为某壬；做状人（构思起草状稿者）为某癸，住三都二图；写状人（誊抄至状式者）为某子。

**「［此处加盖官代书戳记：代书某丑］」**
此处应加盖官代书戳记——由经考试录取的官代书某丑盖印。**无此戳记，状纸不准收受。**

**「前批：（留白，俟州县官批语）」**
前批：状纸中部的留白处，供州县官书写批语。**"不录前批者不准"**——若是再次投递的状纸，须将历次批语另纸粘附。

**「正文：为田土事。」**
正文：事由为田土纠纷。**注意此处直书"为田土事"**，黄岩状式条例明确规定："词讼如为婚姻，只应直写为婚姻事；倘如田土、钱债、店账，及命盗、为奸拐等事皆仿此；如敢不遵，仍前做造注语者，提代书重处。"——**标准状模式必须直书事由，不得做造"虎豪吞业"之类的朱语注语。**

**「光绪十年二月初三日，同图某乙盗移田封，侵某甲祖遗田廿步。某甲执契券往争，某乙不与。契券见在，粮仍某甲输纳。」**
光绪十年二月初三日，同图的某乙私自移动田界，侵占我祖遗的田二十步。我拿着契券前去理论，某乙不肯还田。契券现在仍在，税粮仍由我输纳。——据实直叙：年月、地点、对方姓名、事实经过、损失，一事实一线索，**不加渲染**。

**「被证：被某乙，住三都三图；证某丙……中证某己。」**
被告与干证：被告某乙，住三都三图；干证某丙，住三都二图；地邻某戊；中证某己。

**「伏乞大老爷台前，恩准勘验追还施行。上告。如虚坐诬。」**
恳请大老爷阁下，恩准勘验并追还田土、予以施行。上告。**如有虚诬，甘坐诬告之罪。**——"如虚坐诬"四字**不得删除**，它是具状人自负反坐责任的声明。

**「光绪十年三月初五日　告状人某甲（押）」**
落款年月日与署名画押。画押（花押、指印或"十"字符号）是州县官核验身份的最后一道关，不可省略。

### 术语释义

| 术语 | 释义 |
|---|---|
| **状首** | 状纸第一段，含告状人姓名、年岁、籍贯里图、歇家、保戳、做状人、写状人、官代书戳记。**顺序不可颠倒。** |
| **前批** | 状纸中部留白处，供州县官书写批语。不录前批者不准。 |
| **做状人／写状人** | 黄岩状式的制作者信息分三栏：官代书戳记、**做状人**（构思起草状稿者）、**写状人**（誊抄至状式者）。同治十三年至光绪九年只印"做状人"，**光绪十年起增印"写状人"**——本件设为光绪十年，故二者兼具。 |
| **歇家** | 具保的旅店或铺户。歇家住址必须实填，捏写者代书记责。 |
| **保戳** | 保人印记。 |
| **官代书戳记** | 官府颁发的印记，是**受理的准入门槛而非装饰**。落戳表示状纸已通过核查。本技能一律输出**占位符**，不模拟官印实物。 |
| **如虚坐诬** | 状尾保证语。与《大清律例》诬告条的反坐罚则相呼应。 |

### 称谓释义

| 称谓 | 释义 |
|---|---|
| **大老爷** | 对州县官的称谓。按审级与场合变体：州县称"大老爷""正堂老爷"，府称"太老爷""宪台"，道司称"大人""宪台"。**称谓须与受诉机关匹配。** |
| **都／图** | 清代县以下的行政区划单位。黄岩状式为"系某都某图某里籍"。 |
| **抱告** | 老幼废疾妇女生监有职人员**不能亲自出告时**，由同居亲属代告。**抱告人须为"同居亲属、深知本末、通知所告事理"者**，不同居之亲属亦不得为抱告。本件具状人为壮年男子，非抱告六类，故不设。 |

### 所引律例与制度背景

- **教唆词讼律**（《大清律例·刑律·诉讼》第340条，全国全期通行）
  > "凡教唆词讼，及为人作词状，增减情罪，诬告人者，与犯人同罪……其见人愚而不能伸冤，教令得实，及为人书写词状而罪无增减者，勿论。"
  **标准状模式的合法性正来自"罪无增减"这一但书**：官代书据实誊写完全合法。
- **雍正七年定例（1729）**
  > "内外刑名衙门，务择里民中之诚实识字者，考取代书。凡有呈状，皆令其照本人情词，据实代写，呈后登记代书姓名，该衙门验明，方许收受。如无代书姓名，即严行查究。其有教唆增减者，照律治罪。"
  此条把代书制度从道德劝导变成国家强制：**须考试选拔、须据实代写、须登记姓名、须验明方许收受**。
- **嘉庆二十二年定例（1817）**
  > "凡有控告事件者，其呈词俱责令自作。不能自作者，准其口诉，令书吏及官代书，据其口诉之词，从实书写，如有增减情节者，将代书之人，照例治罪。"
  > 同一上谕："在问刑衙门呈控事件者，令于呈尾将代作之人注明姓名、籍贯、住址，一并传案详讯……若呈内不将代作姓名、住址开载，不准收理。"
  诉权归本人，**代书退为"记录者"而非"创作者"**。故标准状呈现的应是"本人口诉、官代书据实书写"的记录稿。
- **黄岩状式条例的九条官代书要求**（同治十三年—光绪十五年实物）
  可提炼为九项校验：来稿须注做状人；事由须直书（不得做造注语）；假托控告书役为由不用戳记者不准；不遵状式并双行叠写、无代书戳记、副状不填新旧字样、不粘历次批语者不准；字涉违碍须更改；歇家与功名须实填；名号须确查注明、不得只用混名；字画须端楷；旧案须注经差姓名。
- **越诉律**（顺治三年入律）
  > "凡军民词讼，皆须自下而上陈告。若越本管官司，辄赴上司称诉者，（即实，亦）笞五十。"
  本件为向本管黄岩县首告，不涉越诉。**若用户直接要求写控府、控司的状词，须先追问"是否已向本管州县呈控、是否被受理或受理而亏枉"**，否则加注越诉风险。
- **抱告例**（《大清律例·刑律·诉讼》**第339条「见禁囚不得告举他事」律文本身**，其下另附一条抱告例；此处两条并引）
  > "其年八十以上，十岁以下，及笃疾者，若妇人，除谋反、叛逆、子孙不孝，或己身及同居之内为人盗诈，侵夺财产及杀伤之类，听告，余并不得告。"
  > 附例："年老及笃疾之人，除告谋反、叛逆，及子孙不孝，听自赴官陈告外，其余公事，许令同居亲属，通知所告事理的实之人代告。诬告者，罪坐代告之人。"
- **证据随状**（地方状式，须按府县与年份加载）
  同治年间黄岩："告婚姻，无媒妁、聘书；田土无粮号、印串、契券；钱债无票约、中证者，不准。"本件为田土，故须"粮号、印串、契券"齐备。
- **地方条例不可外推**：清代律文自乾隆五年基本不变但**例逐年增修**，引用附例必须标年份；地方状式条例的年代跨度更短（黄岩仅 16 年），**将其外推至整个清代或整个府县属过度推断**。本件未指定更细的府县年份，故仅启用全国律例档与《福惠全书》档。

> **史料层级**：《大清律例》卷30第340条及雍正七年、嘉庆二十二年附例属现行律例（**A 级证据**），可支撑"律条＋附例年份"二级定位；黄岩诉讼档案属司法档案原件（**A 级**），但其状式条例**仅对台州府黄岩县同治十三年至光绪十五年生效**；《福惠全书》属官箴（**B 级**）。三层效力与适用范围均不相同，**任何跨层混用都会造成"格式看似合规、实则拒收"**。本件具体人名与歇家为〔拟补〕。
