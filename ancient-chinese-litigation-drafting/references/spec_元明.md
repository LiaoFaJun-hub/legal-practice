# 元、明两朝诉讼文书写作规格说明书

## 摘要

本规格的承重判断有三条。第一，元代把代书权收归官选书状人吏，大德年间起"于籍记吏员内遴选行止谨慎、吏事熟娴者，轮差一名专管书状"，民间书状人及铺户由此失去合法执业空间；这决定了元代词状的输出语域应是**平实、指陈明确、有征验**的吏牍体，而非渲染性四字套语——后者是明代讼师秘本的发明，不得倒灌元代。第二，明代呈状同时受两条线约束：一条是《大明律》"教唆词讼"律的免责边界，即"见人愚而不能申冤，教令得实"及"为人书写词状而罪无增减者，勿论"，反之"增减情罪诬告人者与犯人同罪"；另一条是地方状式条例的"不准"清单，如牵告多人、牵告妇女、无写状人姓名、无歇家姓名等，此类条款属**地方官箴层级**，并非全国一律。第三，明代呈状的实用骨架可直接采用《萧曹遗笔》《折狱明珠》的"十段锦"（硃书—缘由—期由—计由—成败—得失—证由—截语—结尾—事释），但必须把它当作可裁剪的结构模板而非必填字段：府县用"闭门状"，上司用"开门状"，截语不得写成密不透风的反诉漏洞。

## 一、元代（1271—1368）：官选书状人吏独掌词状与民刑双轨的分流

**元代文书体系的核心不是"文体丰富"，而是"书写权被官府垄断"。** 元代诉讼文书中，"词状"指百姓向官府提交的告诉文书（民刑皆用），《元典章》实例可见熊瑞告诚德库案中"熊瑞状告"云云；"文状"则是官府自身发出的上行、下行或平行公文，二者不可混称。这一区别与元代公文的运行关系一致：《元典章》所收文书以汉文吏牍体和蒙文直译体为主，分为下行、上行、平行及复合四类。由此，本规格要求 Skill 在元代语境下把用户提交的"文书"一律命名为"词状"，除《元典章》明确称名的招伏、辞状、取状、甘结、责状、承管状、责领状外，不另造文体名。

**书状人吏制度是元代模块的开关。** 《元典章·刑部·籍记吏书状》载："今后举会有司于籍记吏员内遴选行止谨慎、吏事熟娴者，轮差一名专管书状。"其制度含义有三层：一是人选来自"籍记吏员"这一候补吏员名册，须经"遴选"而非招募；二是标准为"行止谨慎、吏事熟娴"两项，前者管操守，后者管业务能力；三是"轮差一名专管"，为定额专任、定期轮换，目的在于把代书行为纳入可追责的吏员管理链条。大德五年（1301）左右形成定制，县衙、录事司各置一人，多由官员的梯己人充任，任期一年。这一设置直到明初仍被延续：《大明令》规定"凡诉讼之人，有司置立口告文簿一扇，选设书状人吏一名"，《大明律》颁行后这一设置方不复存在。因此，元代输出必须在文末或行间明确"由官选书状人吏某某代书"的署名，且语体上要能看出是官府系统内的吏员口吻——不炫文采、不引用律典炫耀、不把对方写成"虎豪""鳄亲"。

**状铺是这一制度的过渡形态与组织载体。** "状铺"为元代官方设置的代写诉状机构，其前身为宋代经官府审核的书铺；南宋朱熹《约束榜》已细化书铺书写诉状要求。元代沿用并改由吏人专职代写，至大德年间后逐渐转为官派吏人负责。状铺之设的本意是"书写有理词状，使知应告、不应告之例，庶革泛滥陈词之弊，亦使官府词讼静简，公事易于杜绝"；制度要求"每呈词状到铺，依例书写，当日须要了毕，不许有留多余书写人等在铺"。这构成元代输出最直接的形式约束：词状须当日成稿、不冗长、先判断是否应予告。

**"无头圆状"与"私约文字"的处置指向词状的受理门槛。** 元代所谓"无头圆状"指无明确被告、无头绪的匿名或含糊状纸；"私约文字"指未经官验、民间私相约定的契约文书。二者均非正规词状，官府处置是不受理或令另行具状。这一点的操作含义是：元代输出必须强制出现"被告某人、住某处"和"凭据某契/某约（经官验过）"两处，缺一则按"无头圆状"或"私约文字不受"标注风险，而不是强行补全。

**元代文书清单（路由表）**

| 文书名称 | 用途 | 提交人 | 适用案情 |
|---|---|---|---|
| 词状 | 民刑告诉，请求官府受理查问 | 当事人（老弱病残可令家人亲属代告，妇人一般不许代诉） | 钱债、田宅、婚户、斗殴、盗贼、人命等一切有冤抑者 |
| 文状 | 官府公文（上行申状、下行帖、平行关等） | 有司、吏员 | 官府间往来与案件处理，非百姓提交，Skill 不应替用户生成 |
| 招伏（招状） | 被告供认所犯，作为定罪依据 | 被取问人 | 审讯中被告认罪，须与告状词状相核 |
| 取状 | 官府取问当事人或证人的记录，由吏员书写、当事人画押 | 取状吏（官府） | 案件审理中的口供笔录，属审案记录 |
| 辞状 | 当事人陈词、申辩之辞 | 当事人 | 一般诉讼、申辩、自白 |
| 甘结（结状、责状） | 书面保证，如有虚诳甘愿受罚 | 当事人或具结人 | 保证所告所供属实；官员上任亦用 |
| 责状 | 具结的一种，兼含施行刑罚之意 | 应干人 | 结案保证、放监手续，"应干人责状并放监" |
| 承管状 | 看管人保证随叫随到 | 承管人 | 看守被告、证人 |
| 责领状 | 委托牢房等机构看管 | 牢房人员 | 收监看管手续 |
| 状铺文书 | 状铺内书状人依例书写的词状及登记 | 书状人吏 | 经由状铺代书的一切民刑词状 |
| 无头圆状 | 不规范文书，无明确被告、头绪含糊 | 当事人 | 不受／不予受理，须另具正规词状 |
| 私约文字 | 民间私相约定，未经官验 | 当事人 | 不受为证据，须另行官验或具状 |

需说明：元代词状实例可见"告人某某年若干岁、系某处人氏、状告为某事"，其字段含告状人姓名、年龄、健康状况、住址与户籍，并须列被告姓名居址与干证；黑水城《失林婚书案文卷》所存取状还出现"驱妇"等驱口户计信息，说明元代词状比明代多出"户计"这一特有字段，涉及驱口、军户等身份时必须标明。元代措辞材料可靠性不足：《元典章》与黑水城文献所见均为平实吏牍体，没有与明代《萧曹遗笔》相当的"四字珠语"体系流传下来。因此本规格不虚构元代朱语库，也不把明代"虎豪吞业""豪强奸娶"等套语下推至元代——这是史料空白，不是遗漏。

## 二、明代（1368—1644）：状式标准化与讼师秘本的双轨共生

**明代的代书权经历了"官设—取消—民间复归"的转折。** 明初《大明令》仍设书状人吏与口告文簿，洪武以后《大明律》体系不再保留这一官设职位，代书行为复归民间；与此同时，讼师以"包写词状"为名行"唆讼""包讼串诈"之实，成为官府治理狱讼的头等难题。这两条线并行不悖：官方在形式上不承认民间代书的合法资格（律有"教唆词讼"专条治之），实务上却依赖状式、状板、代书人来管理词状。因此明代输出既要能写出符合状式的形式，又要在内容上保持"罪无增减"的安全边界。

**明代文书清单（路由表）**

| 文书名称 | 用途 | 提交人 | 适用案情 |
|---|---|---|---|
| 告状 | 原告初告，请求受理 | 原告本人 | 一切初发词讼；须先经里甲老人理断者不得径告 |
| 诉状 | 被告答辩、反诉原告 | 被告本人 | 已准理之案，答辩及指控原告诬陷 |
| 禀状 | 下级或当事人向长官陈事、请示 | 属官或当事人 | 陈报、请示、复控等，语体较恭敬 |
| 呈状 | 向上司呈报案情 | 州县官或尸属等 | 命盗重案向上司呈报，如《谋杀人命呈式》 |
| 和息状 | 双方和解、请求销案 | 两造联名或一方 | 经调处达成和解后销案 |
| 结状（甘结） | 具结保证所告所供属实 | 当事人 | 与元代同，作结案手续 |
| 保状 | 他人为当事人作保 | 保人 | 保其随传随到，或保其具结真实 |
| 验伤结状 | 验伤后具结 | 伤者与见证 | 斗殴、人命案的伤情与验看结果 |
| 供状 | 审讯中供述 | 被告、干证 | 堂审口供，由吏记录 |
| 口告（口告文簿） | 不识字者口陈，由书状人吏记录 | 不识字的告诉人 | 《大明令》置口告文簿一扇，选设书状人吏一名代书 |
| 执照 | 官府或当事人出具的凭证 | 有司或当事人 | 田宅、钱债、身份等事项的凭证，作为干证附呈 |

**《教民榜文》决定了明代呈状的"前置路由"。** 洪武三十一年（1398）《教民榜文》规定："民间户婚、田土、斗殴相争，一切小事，不许辄便告官，务要经由本管里甲、老人理断。若不经由者，不问虚实，先将告人杖断六十，仍发回里甲老人处断。"其受理范围含户婚、田土、斗殴、争占、失火、窃盗、骂詈、钱债、赌博、擅食田园瓜果、私宰耕牛、弃毁器物稼穑、畜产咬杀人、卑幼私擅用财、亵渎神明、子孙违犯教令、师巫邪术、六畜践食禾稼、均分水利等。例外是"奸盗、诈伪、人命重事，方许赴官陈告"；又规定"老人、里甲与乡里人民，居住相接，田土相邻，平日是非善恶，无不周知"，故先由里老剖断。由此，Skill 在接到户婚、田土、钱债、赌博等案时，应首先输出"依《教民榜文》须先经本里老人、里甲理断"的提示，而不是直接生成告状——这是明代特有的程序性前置，元代无此要求。

**字数约束是地方官箴，不是全国法。** "每状不过三行，每行不过五十字"见于明人官箴书如佘自强《居官必要为政便览》，其文为"照依格式每状不过三行每行不过五十字年月后无写状人姓名住址者不准一状牵告二事者不准"。另有崇祯年间《璞山蒋公政训》状板规定"状式不许过三行"。这类规定在不同地方官的书箴、告示中反复出现，属于**地方州县为控制词讼量而自定的状式规则**，并非《大明律》《大明令》的全国条文。Skill 应把它设为"地方状式层级的可选校验"，而非强制字段，并在输出时标注"此系某地方官箴，非全国统一法"。

## 三、明代格式规格：可直接套用的逐字段模板

**明代状式的字段顺序由状首、事由、正文、被告与干证、结尾套语、年月日、署名构成。** 徽州文书与黄岩档案的前身可见两类形制：一是白状（白纸手写），二是板状（印板格状）。成化五年（1469）祁门县谢玉清告状即属白状；崇祯《璞山蒋公政训》所载为板状，其式如"状式如争田者：告状人某人，年若干岁，系某都里长某人下籍，状告为某事。某年某月某日凭中某人用价若干买到某里户口……收户，今被占种，具状上告。年月日 告状人某人"。实物中状式开头"状人"二字为版刻，前面填入"报、告、诉、投、禀"等，接着为告状人姓名；"为……事"为版刻，中间双行叠写硃语。

**【告状模板】**

```
告状人（姓名），年（若干）岁，系（某县）（某都）（某图/里）（某籍/某户）人氏。
状告为（四字硃语）事。

（正文中段，按十段锦展开）

被（告人姓名），同都（里）人／住（某处）；
干证（某人）、（某人）（契约文书亦列入干证）。

（结尾套语：伏乞）老爷台下，俯赐（准理／验伤／拘究／追给），（续以具体诉求，如"上告"）。

（年号）　年　月　日　　　　告状人（姓名）（押）
写状人（姓名）　　　　住（某处）　　　　歇家（姓名）
```

**【诉状模板】**

```
诉状人（姓名），年（若干）岁，系（某都某里）人氏。
诉为（四字硃语，如"诬陷架害"）事。

（答辩正文：先驳原告不实之处，再陈己方实情，须与原告状词逐点相应，不得另起一事）

原告诉（某），今查（某年月日事）实系（如实陈述），有（某人、某契）可证。
原告诉（某）系属虚捏，伏乞详察。

干证（某人）。

（结尾套语）

（年号）　年　月　日　　　　诉状人（姓名）（押）
写状人（姓名）
```

**【禀状模板】**

```
禀状人（姓名），年（若干）岁，系（某都某里）人氏。
禀为（四字硃语）事。

（陈述事实，语体较告状为恭，多用"蚁民""切思""伏惟"）

伏乞（某老爷）恩准（某事），感激上禀。

（年号）　年　月　日　　　　禀状人（姓名）（押）
```

**【和息状模板】**

```
立和息状人（甲姓名）、（乙姓名），同系（某都某里）人。
因（某事）互控到官，今蒙（某老爷）剖断／凭（某人）调处，两造情愿息讼，
此后各守本分，不再翻控。如有反悔，甘罪无辞。

干证／保人（某人）。

（年号）　年　月　日　　　　甲（姓名）（押）　乙（姓名）（押）
```

**关键署名要求："状内无写状人姓名者不准"。** 地方状式条例反复规定"年月后无写状人姓名住址者不准""状中无写状人、歇家姓名不准"。这意味着写状人姓名不是可选项，而是准理与否的形式要件。Skill 输出时必须单独留出"写状人""歇家"两栏，并在校验环节强制检查。须特别说明：此处"写状人"是明代地方状式所称的实际代书者，与《大明令》"书状人吏"是不同制度层级的两个概念——明初为官方设置，中后叶则为民间代书人。本规格不挪用清代"官代书""代书戳记"制度：清代"考取代书""无代书戳记不阅"均属清代法制，明代部分不得出现。

## 四、写作硬约束：两条线的罚则与免责边界

**《大明律·刑律·诉讼》"教唆词讼"条是明代模块的法源总纲，其原文为：**

> "凡教唆词讼，及为人作词状增减情罪诬告人者，与犯人同罪。（至死者，减一等。）若受雇诬告人者，与自诬告同。（至死者，不减等。）受财者，计赃以枉法从重论。其见人愚而不能申冤，教令得实，及为人书写词状而罪无增减者，勿论。（奸夫教令奸妇诬告其子不孝，依谋杀人造意律。）"

这条律文的承重结构是一个"三分式免责出口"：其一，"增减情罪诬告人者，与犯人同罪"——只要动了情罪、致其变重，即与诬告者同坐；其二，"至死者减一等"——若所诬为死罪，书写者减一等处罚，而受雇者"与自诬告同，至死者不减等"，二者轻重不同；其三，也是 Skill 必须抓住的出口——"见人愚而不能申冤，教令得实"与"为人书写词状而罪无增减者，勿论"。这意味着"教令得实"和"罪无增减"是两个独立免责事由：前者要求所教所令与事实相符，后者要求书写内容未改变情罪轻重。反过来说，Skill 若据用户陈述添入"打死""强奸""谋杀"等加重罪名，即构成"增减情罪"，不属于免责出口。

**《大明律·刑律·诉讼》"诬告"条的罚则构成前述条款的量刑基准。** 原文规定："凡诬告人笞罪者，加所诬罪二等；流、徒、杖罪，加所诬罪三等；各罪止杖一百，流三千里。"又规定致死随行有服亲属一人者绞，将犯人财产一半断付被诬之人；至死罪所诬之人已决者反坐以死，未决者杖一百、流三千里、加役三年。告二事以上，重事实轻事虚或诬轻为重者，皆反坐所剩；告二人以上但有一人不实者，罪虽轻犹以诬告论。这套罚则是"教唆词讼"条"与犯人同罪"的具体量刑参照，Skill 的校验器应据此计算风险等级。

**《大明令》口告文簿的制度含义是"不识字者不得因不会写字而失去告诉权"。** 其文为"凡诉讼之人，有司置立口告文簿一扇，选设书状人吏一名"。操作上由书状人吏据告诉人口述记录于簿，再据此成状。这对应 Skill 的一个输入分支：当用户勾选"不识字／口告"时，输出应转成第三人称的吏员记录语体（"据某人状告称……"），而非第一人称状词。

**地方状式的"不准"事项是高频校验清单。** 明代天启四年（1624）圣旨碑载："有男子可告，不许告及妇女；告词须真正乡贯，不许冒籍匿名；一词只告一事，不许变幻多情，牵告多人；一人止告，一词不许更名希准，多插党为证；原告不出，即便立案，不许躲闪拖累；一事已经结，不许听唆，希图翻案。"同碑又载"人命自有正法，不许移尸抢财；盗情未入监即审，不许攀及良善"。综合各地方状式，不准事项可归纳为：

| 不准事项 | 处置 |
|---|---|
| 牵告多人、多插党为证 | 不准；应摘唤主要被告 |
| 牵告妇女（有男子可告时） | 不准 |
| 一状牵告二事以上 | 不准；一事一状 |
| 无写状人姓名、住址 | 不准 |
| 无歇家姓名 | 不准 |
| 冒籍、匿名 | 不准；须真正乡贯 |
| 牵扯远年及不干己事 | 痛治；枷号示众 |
| 状式不合式 | 代书人重责枷号，所告不许准理 |
| 经里甲老人理断而不由 | 不问虚实，先杖六十，仍发回理断 |
| 攀及良善（盗情） | 不许 |
| 移尸抢财（人命） | 不许 |
| 更名希准 | 不许 |
| 已结案件听唆翻案 | 不许 |
| 过三行、每行过五十字 | 依地方状式驳回（地方层级，非全国统一） |

这里必须区分史料层级："人命不许移尸抢财""盗情不许攀及良善"属天启圣旨碑所载地方榜文；"每状不过三行每行不过五十字"属地方官箴状式；"一事已经结不许翻案"属地方碑文；而"教民榜文先经里老理断""教唆词讼""诬告"属全国法典。Skill 在校验时应把前者标注为"地方条例，效力因时因地而异"，不可与全国律文等量齐观。

**元代的硬约束是书状人吏不得勒索、留难、增删事实。** 状铺条例要求"每呈词状到铺，依例书写，当日须要了毕，不许有留多余书写人等在铺"，即不得借故拖延、留难；其初衷在"革泛滥陈词之弊"，故书状人吏如虚造情节、歪曲事实，当事人可禀官，情节严重者罢免。元代词状的另一约束是"指陈明确、有征验"：词状须把被告姓名居址、事情年月、证据（契约、干证）写清，不许含糊称疑。元代《大元通制》今已散佚，无法引其原文，故本规格不以转引或传闻补充其条文；今幸赖《元典章》存世，方足以参考。这是史料局限的如实说明。

## 五、明代措辞库：十段锦与朱语／珥语体系

**"十段锦"是明代讼师秘本共有的结构共识，而非某一本书的私创。** 万历年间清波逸叟编《折狱明珠》、竹林子编《萧曹遗笔》（署"锦水竹林浪叟辑"，作者今不可考）及《萧曹致君术》等均有"做状十段锦"或"法门箴规十段锦"。《萧曹致君术》主张"凡作状，先须观其事理情势轻重大小缓急，而后用其律意，该合某条，乃从某条上，拣其紧要字眼"，并提出"十不可紧要箴规"：一不可混沌不洁，二不可繁枝乱叶，三不可妄空招回，四不可中间断节，五不可错用字眼，六不可状后无结，七不可失律主意，八不可言无紧切，九不可搜罗杂砌，十不可妄空扯拽。《霹雳手笔》所载"法门箴规十段锦"文字大体相同。这"十不可"应直接转化为 Skill 的负面校验规则。

**十段结构与各段写法要点**

| 段 | 名称 | 写法要点 |
|---|---|---|
| 一 | 硃书（朱语、主意） | 须将事情起止前后精细议论明白，按事而立；或依律或借意，须与第八段截语相应 |
| 二 | 缘由 | 陈迹之根源，务与第四段计由、第五段成败相应，不可脱节繁多 |
| 三 | 期由 | 事从某年某月某日而成，阐明时间背景 |
| 四 | 计由 | 显迹从何而起，为入罪之路；须与第六段得失相应，不可繁杂含糊 |
| 五 | 成败 | 论计由之后或成或败之故，亦为入罪之门；一状之主宰，奥妙精微皆在于此 |
| 六 | 得失 | 坐实对方弱点或自证无罪；可置证由前或后，惟作者善用之 |
| 七 | 证由 | 成败得失之后必有见证，恐偏护辩论不一，须量人用之 |
| 八 | 截语 | 一状总断，句句合律字字惊奇言语壮丽；有此段名"闭门状"，府县易决断；无此名"开门状"，人犯易辨变 |
| 九 | 结尾 | 先尊奉有司，后说明律法 |
| 十 | 事释 | 惟用二三四字，如剪害安民、超贫杜骗、正伦敦俗、舍冤彰法 |

这段体系的关键分寸在第八段截语：府县用"闭门状"是要求证据与诉求环环相扣，但"都中之状不可闭门，恐上司难辨"——上报上司时反而要留可辩余地。这意味着 Skill 必须依受理层级调整第八段的封闭程度，不能一律写成密不透风的定案语气。

**《萧曹遗笔》"词稿文锋"的门类分类是分案路由的另一张表。** 万历乙未刊本《萧曹遗笔》卷一至卷三载《词稿文锋》分为十五类：盗贼、坟山、人命、争占、骗害、婚姻、债负、户役、斗殴、继立、奸情、脱罪、执照、呈状、说帖；《廉明公案》承袭其中十三类，不取"呈状""说帖"。明刊本所见门类还包括衙门一类。各门类的状式有专门命名：人命告辜式、人命告检式、告辩盗状式、告地土状式、告婚状式、告赌博状式、告财产状式、告钱债状式、告奸情状式等——明末吕坤任官山西时曾据不同案情设计二十余种标准化状式，要求"各府州县受词衙门责令代书人等俱照后式填写，如不合式者将代书人重责枷号，所告不许准理"。这为 Skill 的"案情类型→状式"分支提供了直接依据。

**朱语／珥语是按案情门类调用的四字套语库。** 《新锲萧曹遗笔》"吏条朱语"有：贪官孽民、虐官害民、势宦吞民、玉官殃民、权吏殃民、奸吏侮法、罢吏罔法、贿弊沉案、奸书侮弊、积书殃民、诈官吓骗、指官诓骗、伪官制骗、瞒官侵骗、嘱官枉法、违例勒骗。"户条朱语"有：扰侵欺钱粮、侵克官银、擅盗官物、欺隐国赋、霸占官田、诡寄钱粮、脱漏户口、欺隐成丁、逃避差役、奸拐民妻、透拐人口、丢粮叠累、拒差累骗、抄家灭寡、夺妻大冤、势占产业、移军坑民、飞粮谄民、压良为贱、逐婿嫁女。"刑条朱语"有：灭彝大恶、逆天大变、打死人命、锁勒死命、谋财害命、焚劫杀命、杀命大冤、发冢丢骸、盗葬伤命、强奸闺女、奸妻杀命、欺奸兄嫂、欺奸弟妇、欺奸叔婶、纵妻卖奸、局妻为娼、弑主大变、侮法害命、朋谋脱骗、伪牌吓骗。"诉条殊语"（被告方用）有：唆陷仇随、唆诬仇诬、谮害嫁害暗害、嫁殃移祸、电豁涤冤、恳宥恤孤怜寡、乘拔孀、豁命超累、苏累拔冤杜害、飞冤黑陷、仇唆诬陷、仇毒攀害、电烛黑冤、叩天苏民、乞超移陷、号天镜拔、恳天辨枉。"衙门类"有：酷官、虐官、孽官、酷吏、鳄吏、污吏、罢吏、奸书、弊书、积书、奸弁、积快、虎隶、县毒、县蠹、县虎、县霸、驲害、驲蠹、驲虎。

**脸谱化称谓是"先声夺人"的策略，也是最容易踩线之处。** 《萧曹遗笔》所列为：亲戚类"孽亲、枭亲、兽亲、鳄亲、虎亲、歪亲"；尊长类"鳄伯、虎伯（叔同）、孽兄、毒兄、虎兄"；卑幼类"逆男、悖男、恶侄、孽侄、悖孙、虎孙、枭甥、孽甥、悖妾、泼媳、枭弟、恶婿、强奴、凶奴"；族人类"族鳄、族孽、族害、族恶、族蠹"；僧道术人类"妖僧、孽僧、奸僧、妖道、孽术"；乡宦类"势要、势宦、宦孽、宦淫、宦玉官"；大户类"势豪、鳄豪、枭豪、孽豪、奸豪、虎豪、焰豪、土豪、淫豪、豪恶"；平人类"翼虎、翅虎、奸恶、枭恶、虿恶、恶恶、焰恶、凶恶、乡恶、乡霸、乡害"；生员类"学霸、学害、歪儒、学蠹"；衙门类中吏书类"贪官、虐官、孽官、酷吏、鳄吏"等。这些称谓属于丑化性修辞，Skill 调用时必须满足两个条件：一是称谓所指责的行为在用户陈述中有具体事实对应，二是不得凭空把普通亲属升格为"虎伯""孽亲"——后者即"增减情罪"，落入"与犯人同罪"的罚则。

**事释常用语只取二至四字。** 《萧曹遗笔》所见有：剪害安民、超贫杜骗、正伦敦俗、舍冤彰法。其他可酌量使用者，按案情取向选：求准理用"上告""伏乞台察"；求验伤用"伏乞验伤究治"；求追给用"伏乞追给"；求息事用"感激上禀"。切忌清代才出现的"奏""奏闻""敕批""天语"等称法。

**《折狱明珠》《霹雳手笔》《珥笔肯綮》《法家须知》的成例层级不同。** 《折狱明珠》（清波逸叟编）与《萧曹遗笔》同属万历年间讼师秘本，收录"十段锦"并附各类词稿成例，如"告退亲"案中周璁告沈任逼写退婚书遣女另嫁，判词断为"坏法乱纪"。《霹雳手笔》（《新锲订补释注霹雳手笔》）起首载"法门箴规十段锦"，即前述"十不可"。《珥笔肯綮》《法家须知》两书题名在讼学研究中被提及，但本次研究未取得其可核实的原文与成例内容，故本规格不列其具体套语；若日后取得可靠版本，应补充而非臆造。这是史料不足处的明确标注。

**元代措辞材料按可靠性不足处理。** 元代《元典章》词状实例与黑水城文卷均为平实吏牍体，未形成与明代"十段锦""四字珠语"相当的结构化辞库。可确证的元代用语特征仅有：以"状告为某事"起首；以"伏取台旨"作结；具结语用"所供前词是的实并无虚诳""对问不实甘当诳官重罪不词"；告人信息含姓名、年龄、健康状况、住址、户籍、户计。除此之外不虚构元代朱语库。

## 六、法依据原文与罚则汇编

**《元典章·刑部·籍记吏书状》**

> "今后举会有司于籍记吏员内遴选行止谨慎、吏事熟娴者，轮差一名专管书状。"

制度含义：官选书状人吏独掌代书，民间书状人及铺户失去合法执业空间。

**《元典章》状铺条例（大德十一年五月）**

> "各处状铺之设，本欲书写有理词状，使知应告、不应告之例，庶革泛滥陈词之弊，亦使官府词讼静简，易于杜绝。"

> "每呈词状到铺，依例书写，当日须要了毕，不许有留多余书写人等在铺。"

罚则：书状人如虚造情节、歪曲事实，当事人可禀官，情节严重者罢免；借故勒索、留难者依贪赃枉法论处。具体笞杖数本次未取得可靠原文，故不妄列。

**《大明令》诉讼条**

> "凡诉讼之人，有司置立口告文簿一扇，选设书状人吏一名。"

**《大明律·刑律·诉讼》"教唆词讼"条**（全文）

> "凡教唆词讼，及为人作词状增减情罪诬告人者，与犯人同罪。（至死者，减一等。）若受雇诬告人者，与自诬告同。（至死者，不减等。）受财者，计赃以枉法从重论。其见人愚而不能申冤，教令得实，及为人书写词状而罪无增减者，勿论。（奸夫教令奸妇诬告其子不孝，依谋杀人造意律。）"

**《大明律·刑律·诉讼》"诬告"条**（要点）

> "凡诬告人笞罪者，加所诬罪二等；流、徒、杖罪，加所诬罪三等；各罪止杖一百，流三千里。若所诬徒罪人已役，流罪人已配……因而致死随行有服亲属一人者，绞。将犯人财产一半，断付被诬之人。至死罪所诬之人已决者，反坐以死；未决者，杖一百，流三千里，加役三年。"

> "若告二事以上，重事实，轻事虚招，及数事罪等，但一事告实者，皆免罪。若告二事以上，轻事告实，重事招虚，或告一事，诬轻为重者，皆反坐所剩。"

> "若告二人以上，但有一人不实者，罪虽轻，犹以诬告论。"

**《明会典》相关条目**：《大明令》于洪武六年《大明律》颁行后，刑律部分失效，其余行政规范仍有效；正德《明会典》收入其中 61 条，万历《明会典》收入 48 条。本次未取得《明会典》中可核实的状式专条原文，故不引述其条文。

**《教民榜文》第二条**（原文）

> "民间户婚、田土、斗殴相争，一切小事，不许辄便告官，务要经由本管里甲、老人理断。若不经由者，不问虚实，先将告人杖断六十，仍发回里甲老人处断。"

第十一条：

> "今后民间除犯十恶、强盗及杀人，老人不理外，其有犯奸盗、诈伪、人命，非十恶非强盗杀人者，本乡本里内，自能含忍省事不愿告官……止于老人处决断者，听其所以，老人不许推调不理。"

**明代天启四年圣旨碑（地方榜文，非全国律）**

> "人命自有正法，不许移尸抢财；盗情未入监即审，不许攀及良善；有男子可告，不许告及妇女；告词须真正乡贯，不许冒籍匿名；一词只告一事，不许变幻多情，牵告多人；一人止告，一词不许更名希准，多插党为证；原告不出，即便立案，不许躲闪拖累；一事已经结，不许听唆，希图翻案。"

**史料不足与不可引用的边界**：《大元通制》今已散佚，本次未取得其条文，故元代法依据仅列《元典章》；《至正条格》有残卷传世，但其与《元典章》的关系本次未深入核对，故不引；《明会典》状式专条未取得可核实原文；《珥笔肯綮》《法家须知》未取得可核实成例；《折狱明珠》以外的成例仅以"告退亲"一则为据，不宜扩写；所有清代"官代书""考取代书""代书戳记""无代书戳记不阅"制度均严格排除于明代模块之外。

**分支逻辑。** 建议按"朝代 → 前置程序 → 案情门类 → 文书种类 → 状式模板"四层路由：

1. **元代**：一律走词状；先判断是否为老弱病残需代告、是否为妇人（一般不许代诉）；词状正文按"指陈明确、有征验"展开，不套十段锦、不调用朱语库；文末署官选书状人吏姓名。
2. **明代前置判断**：case_category 属于户婚、田土、钱债、赌博、斗殴、争占、窃盗、骂詈等且 is_first_instance 为真 → 输出《教民榜文》提示"须先经本里老人、里甲理断，径告者不问虚实先杖六十"，同时仍生成告状供备用；属于人命、强盗、奸情、诈伪等重事 → 直接进入状式生成。
3. **案情门类路由**：人命 → 告辜式／告检式，须填伤痕与凶器；盗贼 → 告辩盗式，须有地邻见证与被盗清单；地土 → 告地土式，须附契约；婚 → 告婚式，须有媒妁、财礼凭证；奸情 → 告奸情式；债负、钱粮 → 告钱债式；赌博 → 告赌博式；其他按吕坤二十余式类推。
4. **文书种类路由**：初告用告状；答辩用诉状（须与原告诉词逐点相应，不得另起一事）；陈报用禀状；重案上报用呈状；和解用和息状。

**输出结构建议以"十段锦"为明代正文骨架，但设为可裁剪的十个槽位。**

```
【状首】告状人（姓名），年（若干）岁，系（县）（都）（里）（籍）人氏
【事由】状告为（朱语，调用对应门类四字套语）事
【正文】
  一、硃书：（依律或借意，与截语相应）
  二、缘由：（陈迹根源，与计由、成败相应）
  三、期由：（某年某月某日）
  四、计由：（显迹所起，入罪之路，与得失相应）
  五、成败：（或成或败之故，一状主宰）
  六、得失：（坐实对方弱点或自证无罪）
  七、证由：（列契约、干证，量人用之）
  八、截语：（句句合律，府县闭门／上司开门）
  九、结尾：（尊奉有司，说明诉求）
  十、事释：（二至四字，剪害安民等）
【被告】被（姓名），住（某处）
【干证】干证（姓名）、（姓名）
【结尾套语】伏乞老爷台下，俯赐（准理／验伤／拘究／追给），上告。
【署名】年号　年　月　日　告状人（姓名）（押）
　　写状人（姓名）　　歇家（姓名）
```

元代输出不使用此骨架，改为：

```
【状首】告状人（姓名），年（若干）岁，（健康状况），系（路）（州）（县）（都）（里）（村）人氏，为（户计）
【事由】状告为（直述事由，不加四字套语）事
【正文】指陈实事：（含被告姓名居址、事情年月、经过，不作渲染）
【证据】有（某人）为证，有（某契／某约，经官验过）为凭
【甘结】所供前词是的实并无虚诳，对问不实甘当诳官重罪不词
【署名】年号　年　月　日　告状人（姓名）（押）
　　书状人吏（姓名）（籍记吏员）
```

**校验规则。** 建议分三级校验：

1. **硬校验（一票否决，直接阻断输出）**：被告姓名为空 → 标注"无头圆状，不予受理"；干证超过三人 → 提示"牵告多人，不准"并自动裁减；写状人姓名为空 → "无写状人姓名者不准"；案件属于户婚田土等且未经里老理断 → 输出《教民榜文》杖六十提示；人命案缺伤痕与凶器、盗案缺清单与地邻见证、田土钱债案未附契约 → 按状式条例标注"不准理"。
2. **软校验（告警，允许人工确认）**：出现"虎伯""孽亲""鳄豪"等脸谱化称谓时，检查用户陈述中是否有对应事实，无则提示"此称谓无事实支撑，属增减情罪风险"；出现"打死""强奸""谋杀"等加重罪名时，比对用户陈述的事实强度，提示"可能构成增减情罪，与犯人同罪"；"教令得实""罪无增减"两项免责出口是否满足，须逐项标注。
3. **形式校验**：每行字数（仅当地方状式加载时启用，默认关闭）；被告与干证总数不超过三人；不得出现清代"官代书""戳记""奏""敕批""天语"等语；元代输出不得出现十段锦、朱语、珥语；明代输出不得出现元代"户计""驱口"等字段。
4. **层级标注**：所有校验规则须标注史料层级——全国律（《大明律》《大明令》《教民榜文》）用【律】；地方官箴（佘自强、吕坤、《璞山蒋公政训》、天启圣旨碑）用【地方条例】；讼师秘本（《萧曹遗笔》《折狱明珠》《霹雳手笔》）用【秘本成例】。输出文本中不可把三类等量呈现。

**该朝特有写作提示。** 元代要点是"官选书状人吏书写、民间讼师受压制的语域"：词状要像官府系统内的吏员写的，平实、指陈明确、有征验，不炫文采、不引律炫耀、不丑化对方、不加四字套语；必须署书状人吏姓名并注明其"籍记吏员"身份；涉及户计时必须写明；不受理的事项要直说，不可用技巧包装。明代要点是"教唆词讼"律的免责边界：Skill 的全部加工都必须落在"罪无增减"与"教令得实"两个出口之内——添入加重罪名即越界；同时尊重地方状式的形式要求（写状人姓名、歇家姓名、字数、人数），这些形式要件往往直接决定"准"与"不准"。两套制度在同一朝代内并存而张力极大：律要"如实"，状式要"精简"，秘本要"耸听"；Skill 的任务是让三者在不违法的前提下共存，而不是替用户挑出最激进的一路。
