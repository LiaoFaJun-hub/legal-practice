# 古代讼师写文书 AI Skill 写作规格说明书（唐、宋卷）

## 摘要

本规格以唐、宋两朝法定诉讼文书的格式、用语与责任边界为核心，为 Skill 输出可直接落地的结构化文书提供依据。唐代以吐鲁番出土"辞"为实物范本，其"年月日—身份姓名—辞—受诉机构—所请事项—请裁，谨辞"七段结构是可复现的最小完整单元；宋代以《作邑自箴·写状钞书铺户约束》与朱熹《约束榜》为格式基准，须依次落"乡里—耆长—户等—姓名—住处—距县衙里数—客户归属—被论人住址—具状人年龄—疾荫/妇女娠孕—所诉某事—伏乞县司施行，谨状"诸字段。两朝最根本的差异在于：唐代允许雇倩代作辞牒，仅禁"加增其状"（第356条），尚无书铺准入；宋代则把代书行为纳入官设书铺的准公证链条，"不经书铺不受、状无保识不受"成为受理前提，且官人、进士、僧道、公人可自书，其余民户必经书铺。Skill 必须内置"不得称疑"的事实措辞校验、宋代"过二百字"与"一状诉两事"的硬性拦截，并严禁把明清"朱语/珥语""十段锦""官代书戳记""状式条例"倒推至唐宋。

## 模块一：文书清单（路由表）

### 唐代

唐代法典层面的总称是"辞牒"。《唐六典》卷一"尚书都省"条明定六种上行文书："凡下之所以达上，其制亦有六，曰：表、状、笺、启、牒、辞。"[1] 其中等级差异有三层：

- **表、状**：表上于天子，近臣亦为状。属对君主、中枢的上行重器，百姓不得僭用。
- **笺、启**：笺、启上皇太子，"然于其长亦为之，非公文所施"，礼制性大于司法性。
- **牒、辞**："九品已上公文皆曰牒，庶人言曰辞。"[1] 这是诉讼文书的身份分水岭——有品级或一定身份者用"牒"，庶民用"辞"。

因此，"辞牒"是法典对庶民诉讼文书的泛称，不是一种独立于辞、牒之外的文体。实务中三者关系为：辞与牒的内容都可称为"状"，后来"状"普及，辞、牒遂被取代[1]。

| 文书名 | 用途 | 提交人 | 适用案情 |
|---|---|---|---|
| 辞 | 庶民向官府陈述请愿、告言人罪、陈诉纠纷 | 庶人（含客户、奴婢告谋反逆叛） | 请给公验、租佃、赡养、田产、告罪等 |
| 牒 | 有品官或杂任层向官府陈述、答辩 | 九品以上官员、杂任杂职层 | 同上，身份上移则改用牒 |
| 辞辩／牒辩 | 回答官府勘问 | 辞辩用于庶人，牒辩用于官人 | 案卷审理中被告、证人对问 |
| 告人罪辞 | 告发他人犯罪 | 有告诉资格者 | 刑事告发，须明注年月、指陈实事 |
| 上表／上书 | 越级向皇帝、尚书省陈情 | 特定身份或冤屈极重者 | 穷尽逐级申诉后的直诉 |
| 挝登闻鼓／邀车驾／立肺石 | 直诉申冤 | 蒙冤者或家属 | 重大冤屈、非常之事，主司须为受 |

**关键路由判断**：Skill 收到庶民案情时，默认产出"辞"；若用户明示为品官、州县属吏，则改"牒"，结尾由"谨辞"换为"谨牒"。唐代尚无"告状""诉状"作为法定文体名，不可在唐代语境使用这些称谓。

### 宋代

宋代"状"已成为诉讼文书主称，种类因程序层级分化更细。

| 文书名 | 用途 | 提交人 | 适用案情 |
|---|---|---|---|
| 状（词状） | 州县第一审起诉主载体 | 民户（经书铺）、官人进士僧道公人（可自书） | 婚田、债负、斗殴、劫盗、人命等 |
| 告状／诉状 | 状的通俗称谓 | 同上 | 同上，非法定文体专名 |
| 投白纸 | 急切案件不经书铺的临时状 | 贫窭、老病、幼小、寡妇或被劫盗、斗殴杀伤事干人命者 | 初词紧急，事后须补正 |
| 投匦／诣阙文书 | 进状于登闻鼓院、登闻检院、理检院 | 穷尽州县、转运司、提刑司救济者 | 理雪抑屈、朝政阙失、军国重事 |
| 挝登闻鼓／邀车驾 | 登闻鼓院、检院、理检院不受后的复合直诉 | 持有判状者 | 检院不受则许邀车驾，不给判状则诣御史台 |
| 保识文书（保状） | 书铺所写之状的身份与事实担保 | 茶食人（或保识人） | 状内事实的连带保证，无保识不受理 |
| 不理状 | 向上级申诉的凭证 | 不服判决者 | 经县判决不服，请给不理状后逐级上诉 |

**关键路由判断**：普通州县诉讼默认产出"状"，且必须在输出中标注"须经书铺依式书写、经保识人印子"；涉及直诉则路由至"投匦文书"，且须在状内明注"某年月日经县陈诉、已经几日本县不结绝"，否则连书铺一并收坐[2]。

## 模块二：格式规格（可套用模板）

### 唐代：以贞观廿二年米巡职辞为范本

吐鲁番阿斯塔那221号墓出土的《唐贞观廿二年（648）庭州人米巡职辞为请给公验事》，是唐代"辞"的实物标准件。完整录文如下[3]：

> 贞观廿二〔年〕
> 庭州人米巡职辞：
> 米巡职年叁拾，奴哥多弥施年拾伍，婢娑匐年拾贰，驼壹头黄，铁勤敦捌岁，羊拾伍口。
> 州司：巡职今将上件奴婢驼等，望于西州市易，恐所在烽塞，不练来由，请乞公验。请裁，谨辞。

其后为州司判语："巡职庭州根民，任往西州市易，所在烽塞勘放。怀信白。廿一日。"

**结构分析**（七段式）：

1. **年月日**：纪年置于首行，"贞观廿二年"。唐代辞可不写月日于首行（本件首行只署年），但须能确定时间；刑事告发则须"明注年月"。
2. **身份＋姓名**：籍贯（庭州人）＋身份（人）＋姓名（米巡职）＋"辞"字，构成首部。
3. **人、物清册**：年龄逐项列出，奴婢姓名年龄、牲口头数毛色，一一详注。这是"请给公验"类文书的必备要素。
4. **受诉机构**：以"州司"领起，指向受理官司。
5. **事由与所请事项**："今将上件……望于西州市易，恐所在烽塞不练来由，请乞公验"，因果链完整。
6. **请裁**：固定过渡语。
7. **谨辞**：结尾套语，标志文书完成。

**可套用模板**：

```
〔年号＋年〕〔月〕〔日〕
〔州／县〕人〔姓名〕辞：
〔姓名〕年〔年龄〕，〔身份说明：如"妻某氏年若干""奴某年若干""客某名下客户"等〕。
〔受诉机构，如"县司""州司"〕：〔事由：因何事、有何凭据、对方何人、发生年月〕，恐〔顾虑：如"所在不练来由""被某人欺凌无计"〕，请乞〔所请：如"公验""追究""给断"〕。请裁，谨辞。
```

**注意事项**：
- 刑事告发必须"明注年月"，不可只写年号。
- 身份段必须逐项单列，不可并述。
- "请裁，谨辞"四字为结尾固定格式，不可替换为"伏乞施行"。

### 宋代：以《作邑自箴》状式与朱熹《约束榜》为基准

《作邑自箴》卷第八"写状钞书铺户约束"所录状式，是宋代词状首部的标准规格。据《我国起诉状、答辩状文书样式的历史演进》的复原，状式含七部分：标题《状式》、村落与耆长与户等、姓名与住址及距县衙里数、客户归属、被告人信息、当事人健康状况、事实与诉求、固定结尾"谨状"、日期与画押[4]。朱熹知潭州所发《约束榜》进一步细化状首字段顺序为："某县某乡某里；年几岁，有无疾荫，合为状首，堪任杖责，系第几状；所诉某事，合经潭州；即不是代名虚妄、无理越诉，或隐匿前状，如违，甘伏断罪号令。"[5]

**可套用模板**：

```
〔年号＋年＋月＋日〕
〔某县〕〔某乡〕〔某里〕〔某村〕
耆长〔姓名〕　　户等〔第几等〕
〔具状人姓名〕〔年几岁〕，〔有无疾荫；妇女则注"系孀妇／有娠／无娠"〕，
住〔住处〕，去县衙〔若干〕里，
〔若是客户〕系〔某人〕客户
〔若是民户经书铺〕经由〔某书铺〕依式书状
〔被论人〕〔姓名〕，住〔住处〕，去县衙〔若干〕里
右〔具状人姓名〕，今为〔所诉某事〕，〔事实：年月日、人、地、物、因由，直述，不繁词〕，
委是（不是）代名虚妄、无理越诉、隐匿前状，如违，甘伏断罪号令。
伏乞县司施行，谨状。
〔姓名〕，押。
```

**朱熹《约束榜》变体结尾**（适用于州级上诉状）：

```
须至具状披陈，伏候判府安抚修撰特赐台旨。
〔姓名〕，押。
```

**注意事项**：
- "合为状首，堪任杖责"是宋代特有字段，意即具状人自认可作为状首、能够承受杖责（反坐后果）。唐代无此表述。
- "系第几状"指此次是初状还是第几次投状，须如实填写，不得隐匿前状。
- 客户必须注明"系某人客户"，这是身份依附关系的法定披露。
- 结尾统一"伏乞县司施行，谨状"，不可改作"谨辞"（那是唐代语）。

## 模块三：写作硬约束

### 唐代三条红线

**第一条：告人罪须明注年月，指陈实事，不得称疑。**

《唐律疏议》卷二十四《斗讼律》总第355条："诸告人罪，皆须明注年月，指陈实事，不得称疑。违者，笞五十。官司受而为理者，减所告罪一等。"[6] 此条要求告发者把犯罪发生的时间、地点、人物、行为逐一定位，任何"大约""似乎""想必"式措辞都属"称疑"，直接笞五十。Skill 的输出校验必须把所有表示不确定的副词、情态动词列为禁词。

**第二条：为人作辞牒加增其状。**

《唐律疏议》卷二十四《斗讼律》总第356条："诸为人作辞牒，加增其状，不如所告者，笞五十；若加增罪重，减诬告一等。"[7]

疏议对"加增"的界定与计算逻辑如下[8]：

> "议曰：为人雇倩作辞牒，加增告状者，笞五十；若加增其状，得罪重于笞五十者，减诬告罪一等。假有前人合徒一年，为人作辞牒增状至徒一年半，便是诬半年，减诬告一等，合杖九十之类。"

**计算逻辑还原**：诬告半年本应反坐杖九十（唐律诬告徒一年半反坐徒一年半，诬告半年在笞五十与杖六十之间，按唐律刑罚等次，半年徒的对应反坐为杖九十——此处疏议径以"诬半年合杖九十"为前提），"减诬告一等"即从杖九十减一等得杖八十……但疏议原文结论为"合杖九十"。此处须按原文表述输出，不自行推算。原文例的结论是：增状至徒一年半，按"减诬告一等"处理，合杖九十。Skill 实现时以疏议原文为权威口径，不自行重构刑等。

**"加增"的边界**：疏议的"为人雇倩作辞牒"表明雇倩代作本身合法；违法点在"加增告状"，即在当事人所告事实之外增添情节、或加重所告之罪。纯粹据实誊写、不添不减，不构成此罪。

**第三条：身份与逐级限制。**

- **卑幼告尊长**：告祖父母、父母者绞；告期亲尊长、外祖父母、夫、夫之祖父母，虽得实徒二年[9]。
- **部曲、奴婢告主**：非谋反、谋逆、谋叛者皆绞；告主人期亲及外祖父母者流[9]。
- **老小笃疾**：年八十以上、十岁以下及笃疾者，仅听告谋反、逆、叛、子孙不孝及同居之内为人侵犯，余不得告[9]。
- **越诉**：《斗讼律》"诸越诉及受者，各笞四十。"疏议曰："凡诸辞讼，皆从下始……历经县而越向州、府、省之类，其越诉及官司受者，各笞四十。"[10]
- **直诉例外**：挝登闻鼓、邀车驾、上表申诉者，主司即须为受，不受者有罪。

**关于"抱告"**：唐代尚无"抱告"这一制度名称与术语。老幼笃疾的限制是"不得告"，而非"由他人代告"；妇女诉权在唐律中亦无"抱告"形式的明确规定。因此 Skill 不得在唐代模块虚构"抱告"字段或流程。这是材料不足处，须明确标注。

### 宋代四条红线

**第一条：不经书铺不受。**

朱熹《约束榜》："官人、进士、僧道、公人（谓诉己事，无以次人，听自陈）听亲书状；自余民户并各就书铺写状投陈。"[11] 书铺须由官府系籍：每名召土著人三名保识，须有行止、不曾犯徒刑、非吏人勒停配军拣放老疾不任科决及有荫赎之人、与本县典史非亲戚，勘会得实后置簿籍定，各用木牌书状式并约束事件挂门首[12]。Skill 输出民户词状时，必须在文末或注释中标注"本状须经〔某〕书铺依式书写、加盖印子"。

**第二条：状无保识不受。**

状须经茶食人（保识人）开雕、印子、保识，方听下状。"若人户理涉虚妄，其犯人并书铺、茶食人一例科罪。"[11] 书铺不写本情、非理邀阻者许当厅执覆；告论不干己事，写状书铺与民户一等科罪；书铺违犯约束或用印不实，除科罪外并追毁所给印子[11]。

**第三条：状过二百字不受。**

黄震《词讼约束》与朱熹《约束榜》均以二百字为限[2]。黄震知抚州所发《词讼约束》列"不经书铺不受、状无保识不受、状过二百字不受、一状诉两事不受"四项[2]。

**第四条：一状诉两事不受。**

同一状纸只许状告一事。黄震《词讼约束》与朱熹《约束榜》"状词并直述事情，不得繁词带论二事"[2]。此外黄震榜文尚列"事不干己不受、告讦不受、经县未及月不受、年月姓名不的实不受、披纸枷布枷自毁咆哮故为张皇不受、非单独无子孙孤孀辄以妇女出名不受"等项[2]。

**逐级申诉与越诉**：《宋刑统》卷二十四："今后诸色词讼及讼灾沴，并须先经本县，次诣本州、本府，仍是逐处不与申理及断遣不平，方得次第陈状及诣台省、经匦进状。其有蓦越词讼者，所由司不得与理，本犯人准律文科罪。"[2] 徽宗政和以后及南宋广开越诉之门，凡官吏违法（置杖不如法、擅雇私身发放文字、以威力取乞钱物而监司守令坐视）许民户诣监司、尚书省越诉[10]。Skill 须根据案情性质判断是否适用越诉例外，不得一概禁止。

**身份限制**：宋代妇女出官词讼受严格限制，"非单独无子孙孤孀辄以妇女出名不受"；官人、进士、僧道、公人可自书，民户必经书铺。朱熹允许"贫窭、老病、幼小、寡妇或被劫盗并斗殴杀伤事干人命，初词许于放词状日投白纸"[5]，这是宋代"抱告"制度的雏形性放宽，但仍非明清意义上的"抱告"术语。Skill 对宋代妇女出官应提示"原则上不以妇女出名，特殊情况须投白纸或委保识"。

## 模块四：措辞库

### 唐代

唐代诉讼文书用语体系朴素，以动词性套语为主，尚未形成明清式的四字"朱语/珥语"体系。

| 用语 | 位置 | 用法与限制 |
|---|---|---|
| 辞 | 首部末／结尾 | 庶人自陈的标志词，不可与"牒"混用 |
| 谨辞 | 结尾 | "请裁，谨辞"连用，辞的收束语 |
| 谨牒 | 结尾 | 官员、杂任层所用，代"谨辞" |
| 请裁 | 正文与结尾之间 | 过渡语，意为请官府裁断 |
| 请乞〔某〕 | 所请事项 | 如"请乞公验""请乞追究" |
| 州司／县司／某曹 | 正文起首 | 受诉机构，须实名 |
| 今将上件〔人／物〕 | 引述前文 | 回指身份段所列对象 |
| 恐〔某种顾虑〕 | 事由因果 | 说明请乞的理由 |
| 右〔姓名〕 | 宋代状首（唐少用） | 引下之词，宋代常见 |

**禁用清单（唐代）**：
- 不得写"伏乞县司施行，谨状"——这是宋代套语，唐代用"请裁，谨辞"。
- 不得用"孽亲、枭亲、兽亲"等《萧曹遗笔》式亲缘贬称——这些是明清讼学用语，与唐代无关。
- 不得使用"朱语""珥语""十段锦"等明清状式术语。
- 不得出现"抱告"字段（唐代无此制）。
- 不得用"代书""官代书""状式条例""戳记"等宋以后或清代概念。

### 宋代

宋代套语趋于固定，但仍以朴素陈述为主，未形成明清脸谱化四字体系。

| 用语 | 位置 | 用法 |
|---|---|---|
| 右〔姓名〕 | 状首引下 | 如"右某，年几岁……" |
| 合为状首，堪任杖责 | 身份段末 | 自认可负反坐之责 |
| 系第几状 | 身份段 | 初状或第几次投状 |
| 系〔某人〕客户 | 身份段 | 客户必须注明依附主户 |
| 今为〔某事〕 | 事实段起首 | 直述事由，不用"为……事"四字珠语 |
| 委是（不是）代名虚妄 | 事实段末 | 自证非冒名、非虚告 |
| 伏乞县司施行，谨状 | 结尾 | 州县状标准收束 |
| 须至具状披陈，伏候〔官衔〕特赐台旨 | 州级上诉结尾 | 如"伏候判府安抚修撰特赐台旨" |
| 甘伏断罪号令 | 保证段 | 违式甘受处罚 |
| 经由〔某〕书铺依式书状 | 状首或附注 | 民户必经书铺 |

**禁用清单（宋代）**：
- 不得写"谨辞"——宋代用"谨状"。
- 不得用《萧曹遗笔》"孽亲、枭亲、兽亲"等明清亲缘套语。
- 不得使用"官代书戳记"——清代制度，宋代只有书铺印子。
- 不得使用"状式条例"——明清概念，宋代对应"约束""榜"。
- 宋代亦无明清式"朱语/珥语"四字脸谱套语体系，措辞以直述为宗。

**共同禁用**：两朝均不得出现"上命""与民作主"等语。徽宗政和四年七月四日依中书省言，状内有称"上命"及"与民作主"之类言语者并勿受理，令别承状[2]。

## 模块五：法依据（原文、罚则、编号）

### 《唐律疏议》卷二十四《斗讼律》

**总第355条 告人罪须明注年月**
> "诸告人罪，皆须明注年月，指陈实事，不得称疑。违者，笞五十。官司受而为理者，减所告罪一等。即被杀被盗及水火损败者，亦不得称疑，虽虚皆不反坐。其军府之官，不得辄受告事辞牒。"[6]

疏议释被杀被盗："被杀、被盗，为害特甚，或被人决水、纵火、漂焚财物盗，即不限强窃，漂焚不问多少，告者皆须明注日月，不合称疑；推问虽虚，皆不反坐。若称疑者，官司亦不合受理。即虽受理，官司亦得免科。"[6]

**总第356条 为人作辞牒加增其状**
> "诸为人作辞牒，加增其状，不如所告者，笞五十；若加增罪重，减诬告一等。"[7]

疏议原文：
> "议曰：为人雇倩作辞牒，加增告状者，笞五十；若加增其状，得罪重于笞五十者，减诬告罪一等。假有前人合徒一年，为人作辞牒增状至徒一年半，便是诬半年，减诬告一等，合杖九十之类。若自雇倩受财，得赃重者，同非监临主司因事受财坐赃之罪，如赃重从赃科，赃轻者从减诬告一等法。即受雇诬告人罪者，与自诬告同，赃重者坐赃论加二等，雇者从教令法。若告得实，坐赃论，雇者不坐。"[8]

**越诉条**
> "诸越诉及受者，各笞四十。"疏议曰："凡诸辞讼，皆从下始……其越诉及官司受者，各笞四十。"[10]

**告诉身份限制（卷二十三、二十四相关条）**
> "诸告祖父母、父母者，绞。"[9]
> "诸告期亲尊长、外祖父母、夫、夫之祖父母，虽得实，徒二年。"[9]
> "诸部曲、奴婢告主，非谋反、谋逆、谋叛者，皆绞；告主人之期亲及外祖父母者，流。"[9]
> "即年八十以上、十岁以下及笃疾者，听告谋反、逆、叛、子孙不孝及同居之内为人侵犯者，余并不得告。"[9]

**投匿名书**
> "诸投匿名书告人罪者，流二千里。"[6]

### 《唐六典》卷一"尚书都省"条

> "凡下之所以达上，其制亦有六，曰：表、状、笺、启、牒、辞。（表上于天子，其近臣亦为状。笺、启上皇太子，然于其长亦为之，非公文所施。）九品已上公文皆曰牒。庶人言曰辞。"[1]

**《唐六典》关于辞牒审核**：
> "其辞牒须令详审。"（此条为《唐六典》对辞牒内容须详审的概括要求，具体卷次在各本标引不一，Skill 输出时应以"《唐六典》'其辞牒须令详审'"概引，不擅自加卷次。）[13]

### 《宋刑统》卷二十二／二十四《斗讼律》

> "诸告人罪，皆须明注年月，指陈实事，不得称疑。违者，笞五十。官司受而为理者，减所告罪一等。即被杀被盗及水火损败者，亦不得称疑，虽虚皆不反坐。其军府之官，不得辄受告事辞牒。"（《宋刑统》承唐律，条次在卷二十二"犯罪陈告"门"告人罪不得称疑"条）[6]

> "今后诸色词讼及讼灾沴，并须先经本县，次诣本州、本府，仍是逐处不与申理及断遣不平，方得次第陈状及诣台省、经匦进状。其有蓦越词讼者，所由司不得与理，本犯人准律文科罪。"[2]

> "若应合为受，推抑而不受者，笞五十。"（受理机关应受而不受的罚则）[6]

### 李元弼《作邑自箴》卷第八"写状钞书铺户约束"

《作邑自箴》成书于政和七年（1117），作者李元弼，字持国，曾仕蔡州汝阳县主簿、知浙江余杭，在广陵整理成书[14]。卷第八专设"写状钞书铺户约束"与"公人家状式"，是宋代州县词状格式与书铺管理的第一手官箴文献[14]。

书铺准入原文（转引自《宋代的佣书》）：
> "写状钞书铺户，每名召土著人三名保识。自来有行止，不曾犯徒刑，即不是吏人勒停、配军拣放、老疾不任科决，及有荫赎之人，与本县典史不是亲戚。勘会得实，置簿并保人姓名籍定，各用木牌书状式并约束事件，挂门首。"[12]

### 黄震《词讼约束》（《黄氏日抄》卷七十八）

黄震（1213—1280），字东发，宝祐进士，知抚州时发布《词讼约束》[15]。四项核心规则：

> "不经书铺不受，状无保识不受，状过二百字不受，一状诉两事不受。"[2]

扩展项：
> "事不干己不受，告讦不受，经县未及月不受，年月姓名不的实不受，披纸枷布枷自毁咆哮故为张皇不受，非单独无子孙孤孀辄以妇女出名不受。"[2]

### 朱熹《约束榜》

朱熹知潭州时所发，状首字段与书写资格：

> "一，状式：某县某乡某里；一，年几岁，有无疾荫，合为状首，堪任杖责，系第几状；一，所诉某事，合经潭州；一，即不是代名虚妄，无理越诉，或隐匿前状，如违，甘伏断罪号令。右某……须至具状披陈，伏候判府安抚修撰特赐台旨。"[5]

> "官人、进士、僧道、公人（谓诉己事，无以次人，听自陈）听亲书状；自余民户并各就书铺写状投陈。"[11]

> "今仰民户，经由书铺依式书状，仍于状内分明声说的于某年月日经县陈诉，已经几日本县不结绝，以凭行遣。如不明注经县月日，或不候限满，妄称已过所立日限陈述，致追承行人到州，见得元经月日未及，其人户连书铺并行收坐，仍毁劈书铺名印。"[2]

> "状词并直述事情，不得繁词带论二事。仍言词不得过二百字。"[2]

### 《庆元条法事类》

《庆元条法事类》编纂于庆元四年（1198）重修敕令格式之后，嘉泰二年（1202）成书，嘉泰三年（1203）颁行，原437卷，现存残本约70卷（一说48卷），分16门[16]。其刑狱门收录诉讼相关敕、令、格、式及申明。关于书铺准入与状式的具体条文即见上引《作邑自箴》所载（该书成于北宋，所载准入条件为南宋沿用之制的基础）。《庆元条法事类》卷三十二《财用门三·营缮令》有工匠质量规定，卷内另载《杀畜产》厩库敕"诸故杀官私马牛，徒三年……若伤残不堪用者，依本杀法；三十日内可用者减三等"[6]。

**材料不足标注**：《庆元条法事类》为残本，现存卷次中未见独立成篇的"书铺状式"专条；书铺准入的完整条文主要赖《作邑自箴》保存。Skill 如需引用《庆元条法事类》具体卷页，应提示用户核对中华书局点校本残卷，不宜臆补卷次。

### 校验规则

**规则一：不得称疑（唐律355条）**
- 实现方式：对正文做情态副词扫描，命中"似乎、大约、想必、恐怕、可能、疑似、许是、莫非"等词即报错。
- 同时校验"年月日"字段是否完整：告人罪类必须含年月日，缺一即报"明注年月"缺失。
- 强度：阻断式（blocking），不通过不得输出定稿。

**规则二：加增其状（唐律356条）**
- 实现方式：比对 `event_facts` 与 `body` 的事实陈述，若正文出现输入未提供的人物、行为、罪名的加重表述，报"加增其状"风险。
- 提示语："为人作辞牒加增其状，不如所告者笞五十；加增罪重减诬告一等。"
- 强度：阻断式。

**规则三：过二百字不受（宋代）**
- 实现方式：按汉字计数字符串长度（`len(body)`），超过200字即阻断。
- 注意：二百字指正文字数，不含状首身份字段与落款（需按地方官箴实际口径确认；口径不明时在输出中注明）。
- 强度：阻断式。

**规则四：一状诉两事不受（宋代）**
- 实现方式：要求输入 `case_type` 为单一值；若 `event_facts` 中识别出两个独立案由（不同当事人、不同时间、不同性质），提示拆分为两状。
- 关键词识别：第二个人名＋独立动词短语，或时间、地点显著跳转。
- 强度：阻断式。

**规则五：不经书铺不受（宋代）**
- 实现方式：`via_shupu` 为 false 且 `submitter_status` 为民户时，阻断输出并提示"民户必经书铺依式书状"。
- 例外：急切案件（人命、劫盗、斗殴杀伤、贫窭老病幼小寡妇）允许 `via_shupu=false`，但须在附注标注"投白纸，事后须补正"。
- 强度：阻断式（例外需显式声明）。

**规则六：状无保识不受（宋代）**
- 实现方式：`baoshi_name` 为空时阻断，提示"须经茶食人保识并加盖印子"。
- 强度：阻断式。

**规则七：身份禁告校验**
- 实现方式：建立禁告矩阵——
  - 告祖父母、父母 → 阻断（绞）
  - 告期亲尊长、外祖父母、夫、夫之祖父母 → 阻断（虽得实徒二年）
  - 部曲、奴婢告主（非谋反逆叛）→ 阻断（绞）
  - 年八十以上、十岁以下、笃疾告谋反逆叛／子孙不孝／同居被侵以外之事 → 阻断
- 强度：阻断式，并在附注中提示例外情形。

**规则八：越诉校验**
- 实现方式：若 `previous_petitions` 为空且 `receiving_organ` 非县司，阻断并提示"须先经本县"。
- 例外：谋反逆叛等重罪、邀车驾挝鼓直诉情形。
- 强度：提示式（warning），因宋代后期越诉之门渐开，不宜硬性阻断。

**规则九：妇女出名校验（宋代）**
- 实现方式：`submitter_status` 为妇女且无"单独无子孙孤孀"情形时，提示"非单独无子孙孤孀，辄以妇女出名不受"，建议改用保识或投白纸。
- 强度：提示式。

**规则十：禁词库校验（跨朝通用）**
- 明清倒推禁词："孽亲、枭亲、兽亲、抱告（唐）、官代书、戳记（宋）、状式条例、朱语、珥语、十段锦、为……事（四字珠语，宋代状首用'今为某事'不用'为某某事'珠语）"。
- 命中即报错："该用语属明清讼学体系，不适用于本朝。"
- 强度：阻断式。

### 该朝特有写作提示

**唐代特有提示**
- 结尾一律"请裁，谨辞"（庶人）或"谨牒"（品官），不可出现"谨状"。
- 身份段须逐项单列姓名年龄，奴婢、牲口须列明。
- 雇倩作辞牒本身合法，Skill 必须明确告诉用户"可以代写"，但严禁添枝加叶、加重罪名。
- 唐代无书铺准入制度，不要提示用户找书铺。
- 唐代无"抱告"制度，不要为老幼妇女虚构代告人字段。
- 告人罪必须精确到日；请给凭证类文书可只署年。

**宋代特有提示**
- 民户词状必须经书铺依式书写，书铺须是官府系籍、三名土著保识、非吏人勒停配军拣放老疾不任科决及有荫赎、与本县典史非亲戚者[12]。Skill 输出时应在附注列出此准入条件，提示用户确认书铺合规。
- 状须经茶食人保识并加盖印子，无保识不受理[11]。
- 官人、进士、僧道、公人可自书陈状，其余民户必经书铺[11]。此四类身份在状首不必写"经由某书铺"。
- 状首字段顺序不可颠倒：乡里→耆长→户等→姓名→住处距县衙里数→客户归属→年龄→疾荫/妇女娠孕→堪任杖责→系第几状→所诉某事→合经某衙→非代名虚妄/无理越诉/隐匿前状→甘伏断罪号令[5]。
- 结尾统一"伏乞县司施行，谨状"；州级上诉用"须至具状披陈，伏候〔官衔〕特赐台旨"。
- 字数上限二百字，一状一事，是硬性格式要求。
- 上诉状须明注"某年月日经县陈诉、已经几日本县不结绝"，否则人户与书铺一并收坐并毁劈书铺名印[2]。
- 不得用"上命""与民作主"等语，徽宗政和四年明令此类状不受、令别承状[2]。

### 材料不足与使用限制

- 唐代"抱告"制度未见史料支持，本报告不作推定。
- 《庆元条法事类》为残本，书铺状式的卷次难以精确归属，本报告以《作邑自箴》所载为准。
- 宋代词状"二百字"的计算口径（是否含状首身份字段）史料未明，Skill 实现时可先按正文字数计，并在输出中标注此口径假设。
- 唐宋出土与传世文书的地域差异（西北边州与中原内地）未在本案中展开，Skill 若需支持地域变体，须另行补充敦煌、吐鲁番与中原官箴的对照材料。
- 本报告所引原文均为现代标点和转引格式，Skill 正式输出时应以中华书局点校本核校后再行落文。
