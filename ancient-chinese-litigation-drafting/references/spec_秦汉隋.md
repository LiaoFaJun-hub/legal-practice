# 古代讼师写文书 AI Skill · 秦 / 汉 / 隋 三朝写作规格说明书

## 摘要

三朝不能共用一个"状纸模板"。秦代"告"是当事人（或里典、求盗）的告诉行为，"爰书"是官吏据此作出的司法笔录，二者性质不同，Skill 必须把"当事人告辞"与"官吏爰书"分成两条输出流，爰书一律用第三人称、官吏行文体，不得写成当事人的第一人称自述[1]。汉代告、劾分属上下：告属下（当事人/亲属自诉），劾属上（官吏主动纠举公诉），审理须以告劾所定罪行为限，超范围即"鞫狱故不直"[2]；身份禁告最严，子告父母、妇告威公、奴婢告主及主之父母妻子一律"勿听而弃告者市"[3]。隋代传世司法文书实物与格式缺环严重，《隋书·刑法志》只留下"录状""以次经郡及州""挝登闻鼓"等程序名词，未见可复原的字段顺序与套语，因此隋代模板只能标为"据隋制推定（暂无确证）"，严禁把唐以后状式倒推填充。

## 模块1：文书清单（路由表）

**文书路由的核心不是"案由"，而是"谁向谁发起、处于哪个程序环节"。** 同一桩盗牛案，里典来报是"告"，县令史勘验后记录是"爰书"，嫌疑人自陈是"辞"，官吏自行发端是"劾"，判决后翻案是"乞鞫"，它们的提交者与文种完全不同。

### 秦代：五类文书，告与爰书必须分轨

| 文书名 | 提交者 | 用途与适用案情 | 路由说明 |
|---|---|---|---|
| 告（告辞 / 告诉） | 当事人、亲属、里典、求盗、校长 | 主动向官府陈述被害或发罪，如贼死、经死、穴盗、告子、夺首 | 当事人原话，多以"来告""敢告"结尾；这是告发行为本身，不是官府文书 |
| 爰书 | 县令史、乡吏、牢隶臣等官吏 | 勘验、讯问、封守、捕执、病诊、死伤检验的全程笔录 | 官吏记录口吻，格式固定，占《封诊式》21 篇；是本朝最重要输出形态 |
| 封守文书 | 县丞、乡吏 | 对有鞫者家室、妻、子、臣妾、衣器、畜产查封看守 | 须先有鞫，再封守，不可单独发起 |
| 劾（案 / 劾案） | 官吏 | 官吏主动发端、自劾论罪、纠举盗贼发而不觉 | 官吏职责行为，与"告"相对 |
| 乞鞫 | 当事人或其家属 | 对判决不服请求重审 | 须受时间限制，属复审环节 |

秦代路由判断：`当事人 → 来告 → 官吏受理 → 令史往诊/往执 → 爰书 → 丞讯 → 辞`。任何一步都不能跳过官吏环节直接产出"判决"。

### 汉代：六类，告劾分流是首要分支

| 文书名 | 提交者 | 用途与适用案情 | 路由说明 |
|---|---|---|---|
| 告 | 当事人、亲属、州告者 | 自诉：贼伤、盗、不孝、田宅、钱债、婚姻 | 审理以告所定罪行为限 |
| 劾 | 官吏、二千石、令丞尉、郡守 | 官吏主动纠举盗贼、纠劾不职、自劾论 | 对下之词，类公诉，属官吏法定职责[2] |
| 辞 / 爰书 | 嫌疑人、证人与官吏 | 讯问口供记录，含自告、州告后的供辞 | 常用"辞曰""诚……毋它坐罪"结构 |
| 传爰书 | 官吏、邮传系统 | 跨县、跨郡案件口供与证据的转递、移办 | 含"移""传""报"等移送语 |
| 自告 | 犯罪者本人 | 犯罪后主动自首，依律减等 | 与"被告"对称，须注明自首时点与情节 |
| 乞鞫 / 气（乞）鞫 | 当事人、家属 | 对判决不服请求复审 | 须受时限，覆审文书须注明"不如辞"等复核结论 |

汉代路由首要判断：`告属下、劾属上`。若为官吏发现并纠举，走"劾"分支，当事人告辞仅作附属；若为被害人或亲属发端，走"告"分支，官吏不得无告劾而擅覆治[2]。

### 隋代：三类，且均有史料缺口标记

| 文书名 | 提交者（推定） | 用途与适用案情 | 确证状态 |
|---|---|---|---|
| 录状 | 有司（受理官吏） | 逐级申诉与登闻鼓鸣冤时记录当事人状词并奏闻 | 名词确证（《隋书·刑法志》："有司录状奏之"），字段格式暂无确证 |
| 逐级申诉状 | 枉屈当事人 | 县不理→郡→州→省，逐级陈诉 | 程序确证，文书名称与格式为后世纪称，无隋代原简可复原 |
| 登闻鼓状 | 诣阙当事人 | 省仍不理、有所未惬时的最后救济 | 仅见"听挝登闻鼓，有司录状奏之"，状文样式暂无确证 |

隋代路由为硬性层级链：`县 →（不理）郡 → 州 → 省 →（仍不理）诣阙 →（未惬）挝登闻鼓`。任何越级输入必须提示"此路径在隋制中不成立"，不得直接生成登闻鼓状。

## 模块2：格式规格（可套用模板）

**秦代爰书的字段顺序是"时间—发告人身份—告辞—官吏受命与行动—勘验/执捕结果—讯问—辞—处置与回报"，不可颠倒。** 以下模板逐字段用 `{{ }}` 占位，字段顺序依《封诊式》原文复原。

### 秦代模板 A：告发类爰书（依《告子》《贼死》《经死》《穴盗》）

```
爰书：{{某里 / 某亭}}{{里典 / 求盗 / 士伍}}{{甲}}告曰：
「{{身份：里人士伍 / 某亭求盗}}。{{居某里}}。
{{某室 / 署中某所}}有{{贼死一人 / 经死 / 复衣一乙房内中被穴盗去}}，
{{结发 / 不智（知）何男子一人 / 不智（知）穴者可（何）人、人数}}，
{{不智（知）故}}，来告。」
即令令史{{己}}往{{诊 / 执 / 捕}}。
令史{{己}}爰书：与{{牢隶臣 / 求盗}}{{某}}{{诊 / 执}}{{丙}}，
得{{某室 / 某山}}。{{丞 / 令史}}{{某}}讯{{丙}}，
辞曰：「{{身份}}。{{对告辞的承认或辩解}}。毋（无）它坐罪。」
{{诊（验）结论：伤痕、凶器、物证、位置、尺寸、数量逐件列明。}}
{{处置：收、系、封守、移、报。}}
```

**字段必填顺序与依据**：起首必写"爰书"（官吏笔录标识）；其次告发人完整身份 `某里士伍甲` 或 `某亭求盗甲`；告辞用引号内第一人称保留当事人原话；官吏行动用"即令令史某往……"转第三人称；勘验结果须逐项列尺寸、位置、数量、物证（如"刃痏一所，袤四寸，广一寸""穴上高二尺三寸，下广二尺五寸""索袤丈"）；结尾为处置与回报[1]。

**《告子》原文范本**（睡虎地秦简《封诊式》）[5]：

> 爰书：某里士伍甲告曰：「甲亲子同里士伍丙不孝，谒杀，敢告。」即令令史己往执。令史己爰书：与牢隶臣某执丙，得某室。丞某讯丙，辞曰：「甲亲子，诚不孝甲所，无它坐罪。」

**《贼死》原文范本**[1]：

> 爰书：某亭求盗甲告曰：「署中某所有贼死、结发、不智（知）何男子一人，来告。」即令令史某往诊。……男子死（屍）在某室南首，正偃。某头左角刃痏一所，北（背）二所，皆从（纵）头北（背），袤各四寸，相耎，广各一寸，皆？中类斧……

**《经死》原文范本**[1]：

> 爰书：某里典甲曰：「里人士伍丙经死其室，不智（知）故，来告。」……索袤丈。……舌不出，口鼻不渭（喟）然，索？不郁，索终急不能脱，□死难审（也）。

**《穴盗》原文范本**[1]：

> 爰书：某里士伍乙告曰：「自宵臧（藏）乙复（复）衣一乙房内中，闭其户……今旦起启户取衣，人已穴房内，……不智（知）穴者可（何）人、人数，毋（无）它亡（也），来告。」……穴下齐小堂，上高二尺三寸，下广二尺五寸，上如猪窦状。

**《黥妾》原文范本**[1]：

> 爰书：某里公士甲缚诣大女子丙，告曰：「某里五大夫乙家吏。丙，乙妾（也）。乙使甲曰：丙悍，谒黥劓丙。」……其问如言不然？定名事里，所坐论云可（何），或覆问毋（无）有，以书言。

### 秦代模板 B：有鞫与封守（依《有鞫》《封守》）

```
敢告某县主：男子{{某}}有鞫，辞曰：「{{士伍 / 公士}}，居{{某里}}。」
可定名事里，所坐论云可（何），可（何）罪赦，或覆问毋（无）有，
遣识者以律封守，当腾，腾皆为报，敢告主。
```

```
甲室、人：{{一宇二内，各有户，内室皆瓦盖，木大具}}。
妻曰{{某}}，{{亡 / 在}}，{{会 / 不会}}封。

某等皆言曰：「封具此，毋（无）它当封者。」
即以甲封付{{某等}}，与里人更守之，侍（待）令。[1]
```

### 汉代模板 A：告（自诉）口供记录

```
{{年号 / 某年纪年}}、{{月}}、{{朔日 / 日}}。
{{某县 / 某乡}}{{爵 / 身份}}{{甲}}告曰：
「居{{某里}}。{{被告}}{{乙}}，居{{某里}}，
{{贼杀伤 / 盗 / 殴詈 / 不孝 / 田宅相侵 / 钱债不还}}甲，

```

### 汉代模板 B：劾（官吏纠举）

```
{{某官}}劾曰：
「{{某县 / 某郡}}{{某职}}{{甲}}，坐{{所犯之罪}}，
{{事实：发所、时、赃数、伤者}}。
甲所坐论当{{城旦舂 / 耐 / 罚金若干}}。
{{县 / 郡 / 廷}}当论，敢言之。」[2]
```

### 汉代模板 C：辞 / 爰书 / 传爰书

```
{{令史 / 狱吏}}{{某}}讯{{甲}}。
辞曰：「{{爵 / 士伍}}，居{{某里}}。
{{承认 / 辩解：诚……毋它坐罪；或不服及其解辞}}。」
{{诘}}曰：「{{所疑}}。」
{{甲}}更言曰：「{{……}}。」
{{移 / 传 / 报}}为{{某县 / 某郡}}，敢言之。[2]
```

**汉代原件确证依据**：张家山汉简《二年律令·具律》规定"治狱者，各以其告劾治之，敢放讯杜雅，求其它罪，及人毋告劾而擅覆治之，皆以鞫狱故不直论"[2]；汉初覆狱文书已有"去系亡""已论系城旦""乞鞫不如辞"等固定用语[6]。逮捕须有"诏狱书""系牒"等公文凭证，无文书即逮捕不合法——这意味着 Skill 在生成逮捕执行类文书时必须校验"有无令、牒"。

### 隋代模板（据隋制推定，暂无确证）

```
{{年号 / 开皇×年}}{{月}}{{日}}。
{{县 / 郡 / 州 / 省}}{{枉屈当事人姓名}}状称：
「{{籍贯 / 住某县某乡}}，年{{×}}。
{{所告之事：何县、何官、何判、何故枉屈，逐项陈述}}。
{{曾于×年×月×日经某县、某郡、某州、某省陈诉，
  各官不予理 / 断遣不平，各次日期与批语}}。
伏请{{有司 / 大理 / 尚书省}}录状奏闻，乞赐矜察。」
```

**隋代确证边界**：此模板的字段名、顺序与用语均为 Skill 工程推定，非出土原件。唯一确证的格式性原文只有《隋书·刑法志》两处程序句[4][7]：

> 有枉屈县不理者，令以次经郡及州，至省仍不理，乃诣阙申诉。

> 有所未惬，听挝登闻鼓，有司录状奏之。

> 每既录囚，并先牒明法，定其罪名，然后依断。

因此隋代输出必须在文档首行自动标注【据隋制推定 · 传世文书格式暂无确证】，并在正文下方列出缺失字段（见模块 6 缺口提示）。

## 模块3：写作硬约束

### 秦代硬约束

| 约束项 | 规则 | 违反后果 |
|---|---|---|
| 篇幅 | 暂无字数与页数规定 | 不作限制，但须"先尽听其言而书之"，不得删改告辞原意 |
| 必载时间 | 年、月、朔日、时刻（如"某月中""四月中""自昼"） | 缺时则案不能系年，视为不审 |
| 必载身份 | 爵级（公士、上造、不更、大夫、官大夫、公大夫、五大夫、大夫寡等）+ 里籍 + 士伍/庶人，须写全 `某里士伍甲` | 身份不明则"名事里"不定，不得封守、不得定罪 |
| 必载伤情凶器 | 位置（左角、背、南首、正偃）、数量、尺寸（袤×寸、广×寸）、形状（类斧）、物证（索、履、穴、衣器） | 检验不全则"死难审"，不得擅断 |
| 必载干证 | 里典、伍人、同产、同居、见者、牢隶臣、求盗 | 无证词不得独断 |
| 不得称疑 | 虽不得擅断，但爰书须写明勘验事实与结论；存疑处须写"不智（知）""难审"，不得含糊 | 若以疑似入罪，属不直 |
| 不得告不审 | 故意为诬人，不端为告不审 | 诬人反坐；告不审赀二甲或减等 |
| 不得州告 | 前告不审又以它事告，为州告 | 勿听，论其不审 |
| 身份禁告 | 子告父母、臣妾告主属"非公室告" | 勿听；行告，告者罪；罪已行他人再告亦不当听 |
| 不得刑讯为先 | 讯狱须先尽听其言而书之，不得辄诘、不得先掠 | 以掠得情为下，有恐为败 |

**秦代法依据原文**[3][8]：

> 子告父母，臣妾告主，非公室告，勿听。

> 可（何）谓"非公室告"？主擅杀、刑、髡其子、臣妾，是谓"非公室告"，勿听。而行告，告者辠（罪）。

> 甲告乙盗牛若贼杀人，今乙不盗牛、不杀人，问甲可（何）论？端为，为诬人；不端，为告不审。

> 伍人相告，且以辟罪，不审，以所辟罪罪之。

**秦代罚则原文**[9]：

> 上造甲盗一羊，狱未断，诬人曰盗一猪，论可（何）也？当完城旦。

> 伍人相告，且以辟罪，不审，以所辟罪罪之。

> 葆子狱未断而诬告人，其罪当刑为隶臣妾，勿刑，行其耐，有（又）系城旦六岁。

### 汉代硬约束

| 约束项 | 规则 | 违反后果 |
|---|---|---|
| 篇幅 | 暂无字数与页数规定 | 不作限制，但须以告劾所定罪行为限 |
| 必载时间 | 年号纪年 + 月朔 + 日 | 缺年则不得系于年籍 |
| 必载身份与爵里 | 爵级 + 县乡里 + 身份（庶人、司寇、隶臣妾、城旦舂、鬼薪白粲）；奴婢须明主家 | 名事里不定则不得论 |
| 必载伤情凶器赃物 | 与秦同，须列位置、数量、尺寸、价值 | 赃值直接决定刑等（如盗一钱以上斩左趾又黥为城旦） |
| 必载前审层级 | 申诉须列已历县、郡、州、省各次日期与批语 | 层级不全则不得受理 |
| 不得超告劾治罪 | 治狱者各以其告劾治之 | 求它罪、擅覆治者以"鞫狱故不直"论，死罪斩左趾为城旦 |
| 不得告不审 | 告不审及有罪先自告，各减其罪一等 | 逐级减刑，自告可抵除所得 |
| 不得诬告 | 诬告人以死罪，黥为城旦舂；它各反其罪 | 死罪诬告者黥为城旦舂，余罪反坐 |
| 不得替告 | 年未盈十岁、癃者、城旦舂、鬼薪白粲告人，皆勿听 | 所告不理 |
| 不得替告（特殊） | 奴婢自讼不审 | 斩奴左止，黥婢颜頯，畀其主 |
| 身份禁告（极严） | 子告父母，妇告威公，奴婢告主、主父母妻子 | 勿听而弃告者市 |
| 不孝须三环之 | 年七十以上告子不孝 | 必三环之，各不同日而尚告乃听之 |

### 隋代硬约束

| 约束项 | 规则 | 违反后果 | 确证状态 |
|---|---|---|---|
| 篇幅 | 暂无确证 | 不写限制 | 无确证 |
| 必载前审层级 | 须列县、郡、州、省各次陈诉记录 | 层级不全不得受理、不得挝鼓 | 确证 |

**隋代法依据原文**（《隋书·刑法志》）[4][7][11]：

> 有枉屈县不理者，令以次经郡及州，至省仍不理，乃诣阙申诉。有所未惬，听挝登闻鼓，有司录状奏之。

> 讯囚不得过二百，枷杖大小，咸为之程品，行杖者不得易人。

> 诸州囚有处死，不得驰驿行决。

> 诸曹决事，皆令具写律文断之。

```
  │   ├─ 发端者是当事人且陈述被害 → 告辞（第一人称，"来告""敢告"）
  │   ├─ 已有鞫且须查封 → 封守文书
  │   ├─ 已有判决且不服 → 乞鞫
  │   └─ 官吏主动发端 → 劾（但秦代劾用例少于汉，需提示）
  ├─ 汉
  │   ├─ 当事人/亲属自下而上 → 告（须先做身份资格审查）
  │   ├─ 官吏自上而下主动纠举 → 劾
  │   ├─ 需记录口供 → 辞/爰书（"辞曰""诚……毋它坐罪"）
  │   ├─ 跨县跨郡移转 → 传爰书（"移""传""报"）
  │   ├─ 犯罪者自首 → 自告（触发减刑逻辑）
  │   └─ 对判决不服 → 乞鞫（受时限，须列复审层级）
  └─ 隋
      ├─ 县不理 → 郡 → 州 → 省（逐级，任何越级拒绝生成）
      ├─ 省仍不理 → 诣阙申诉（录状，由有司执笔）
      └─ 有所未惬 → 挝登闻鼓（有司录状奏之，当事人不得自书鼓状）
```

### 6.3 输出结构

每个朝代输出统一六段，但措辞与字段不同：

```
[朝代标记] 【秦/汉/隋】 + 【文书名】 + 【确证等级：确证 / 据×制推定】
[当事人告辞]（仅秦"告"、汉代"告"类；官吏发端文书此处省略）
[官吏受命与行动]（秦爰书必段：即令令史某往×；汉代"敢言之"收束）
[事实与勘验]（时间、身份爵里、伤情凶器赃物尺寸、干证，逐项列明）
[讯问与辞]（辞曰 + 承认/辩解 + 诘 + 更言；秦须写"毋它坐罪"或"死难审"）
[处置与回报]（执、封守、系、移、传、报、腾、待令；隋代加"录状奏之"）
```

### 6.5 三朝特有写作提示

**秦代**：输出必须写成官吏笔录口吻，而非当事人自述。起首"爰书："二字不可省，告辞须用引号内第一人称、官吏叙述用第三人称；伤情、凶器、赃物、洞穴尺寸必须逐件列明，缺项则写"不智（知）"而非臆补；刑讯须入爰书，须写"治（笞）讯某"；身份禁告与公室告/非公室告须优先于案情审查。

**汉代**：先做身份资格审查，再决定文书能否生成——这是汉代最关键的写作前置；告与劾分流决定全文人称与收束语（自诉"乞×治，为报"，劾"当论，敢言之"）；须校验告劾是否覆盖所治之罪，超范围即违法；自告与告不审须触发减等计算；不孝案须判断年龄与三环之程序；移转类文书须含"移""传""报"层级。

**隋代**：首先提示用户"隋代传世司法文书实物与格式不足，本朝文书只能据《隋书·刑法志》程序推定"。输出首行强制标注【据隋制推定 · 暂无确证】；必须严格逐级：县→郡→州→省→诣阙→挝登闻鼓，任何越级均拒绝生成；录状须标注"由有司执笔"，不得生成当事人自书鼓状；不得用"所结是实""伏乞青天"等明清状式套语；用户若要求"隋代状纸格式"，返回史料缺口说明并建议其转向唐以后模板。
