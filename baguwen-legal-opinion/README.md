# 八股体法律意见书生成器 · baguwen-legal-opinion

> 以八股八段状态机约束法律推理，产出零跳跃、可回溯、三清单同屏的《法律分析意见书》。
> 内核是八股，外壳是律师文体——**八股是推理纪律，不是排版格式。**

## 这是什么

面向律师 / 法务 / 法律研究者的 AI 辅助分析技能。它不追求"更聪明的结论"，而是用结构
**强制打断** LLM 的流畅性本能（给确定答案 / 补全缺失 / 顺从提问 / 压缩步骤）——因为这四点恰是法律工作的敌人。

- **能力层级**：L2 八段 Workflow 骨架 + L4 局部对抗（第五/六股）+ 强制 HITL 出口
- **价值指标**：**执业者的人审复核耗时**与**结论可回溯性**，不是"结论正确率"

> 完整运行契约（十段式）见 [SKILL.md](SKILL.md)。

## 核心特性

| 特性 | 作用 |
|---|---|
| **前置澄清门（门0/1/2）** | 开干前先问清"会使结论反转的决定性事实"，避免全篇返工 |
| **八段状态机** | 破题→承题→起讲→入手→起股→中股→后股→束股，不可跳过/合并/倒置 |
| **四态判定** | ✓成立 / ◐部分成立 / ✗不成立 / ?存疑——给模型合法的"不知道"出口 |
| **双轨制** | 推理轨（结构化、机器校验）→ 行文轨（律师文体、交付物） |
| **对抗隔离** | 第六股用子 Agent 隔离，只喂判定符号摘要，防锚定 |
| **fail-closed** | 无检索层时绝不回退模型记忆，法条一律标"待核验" |

## 快速开始（三种路径）

1. **全案生成**：喂案件事实与材料 →【门0 澄清】→ 跑全八段 → 出律师文体意见书。
   先读 [references/intake.md](references/intake.md) 与 [references/protocol.md](references/protocol.md)。
2. **审计已有分析**：粘贴一份法律分析 → 用元指令 LE 做幻觉与遗漏审计 → 按 P0/P1/P2 给出修正建议。
3. **单段深钻**：只深挖某一段（如第六股抗辩），见元指令 LC / LD。

## 成品长什么样（示例片段）

> 节选自《法律分析意见书》正文（行文轨）——注意：这是**律师文体**，非模板表格。

关于第五项至第七项要件，即损失、因果关系及数额。用人单位仅作单方陈述，未提交客观证据。
依"谁主张、谁举证"之一般规则，损失的举证责任在用人单位；现有材料尚不足以达到高度盖然性
的证明标准。故该三项要件目前均处于待证状态（详见附录二 Q1–Q3）。

结论：综上，在以下三项均成立的前提下——①劳动者不处于试用期；②不存在用人单位违法之即时
解除情形；③用人单位不能就实际损失及因果关系补充提交证据——本所倾向于认为：……；反之，
若用人单位后续能就实际损失及因果关系完成举证，则结论可能转为：……

## 前置澄清门（本技能的重点）

> 信条：**返工成本 > 问询成本。**

- **门0（必做，开干前）**：用 AskUserQuestion 问 ≤5 个"会使结论反转的关键事实"，每问含"暂不清楚"选项；
  答不清楚的按**保守假设**推进并显式标注。环境无交互工具时，以文本列出问题并暂停。
- **门1（破题后，条件触发）**：候选争议 ≥2，或用户提问方向 ≠ 决定性问题时，回问确认焦点。
- **门2（入手后，条件触发）**：要件库未命中或属高风险场景时，确认要件框架。

协议与问题设计原则见 [references/intake.md](references/intake.md)。

## 校验脚本

```bash
python scripts/check_redlines.py <推理轨文件>    # R1-R4 + 绝对化词 + S→F + 结论条件化 + 禁确定数值
python scripts/check_dod.py <推理轨文件>          # 逐段 DoD 门禁（含澄清/假设登记弱校验）
python scripts/validate_delivery.py <行文轨文件>  # 内容完整性 + 文体合规 + 三清单同屏
```

输出 `P0/P1/P2` JSON 报告；存在 P0 时退出码为 1。
> 注：【仅用户提供模式】下 `check_redlines` 会稳定报 1 条 `R1-占位`（P1），属预期，非缺陷。

## 模式与场景

- **全八段**：内部研究备忘、诉讼策略、合规审查、需留痕可回溯的分析。
- **精简三段**：普法 / 知识问答（仅保留破题 + 承题 + 束股）。
- **场景特化**：合同审查（第四股改为"条款风险清单遍历"）、类案检索、证据梳理。

五个不可用 / 慎用地带（刑事定罪、胜诉率预测、凭记忆出条文等）见 [references/scenario-fit.md](references/scenario-fit.md)。
