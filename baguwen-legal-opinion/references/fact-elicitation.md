# 当事人侧事实采集协议（门0-B 定向采集 · 门0.5 补访环）

> **定位**：本文件是八股技能对 `lawyer-fact-elicitation` v1.0.4（CC BY-NC-SA 4.0）与委托方方法论文档《问好问题》（要件倒推提问法）的**运行时内化**，供门0 升档与补访环直接调用。
> **底层逻辑**：律师提问不是"采集事实"，是"**按要件做定向检索**"。当事人交付的是"说法"（生活事实），需要的是"要件事实"（能填入构成要件的事实）——先把生活事实翻译成法律关系候选，再由该法律关系的构成要件反推"需要哪些事实"，逐个追问。八股的 F/S/U/E 四态分层，就是采集产物的验收格式：**采集的终点不是"他说了什么"，而是"哪句话能被什么东西证明"**。
> **内化边界**：只收录运行时必需工艺。语音两段式（当场追问＋事后复核）、完整状态信号表、执业伦理边界全文、对非当事人采专家经验——**不在本文件复制**，需要时读原技能对应参考文件（防双处漂移）。

## 一、采集分档与触发矩阵

| 档 | 名称 | 何时用 | 产物 |
|---|---|---|---|
| L0 | 定向澄清（门0-A） | 默认档，每案必做 | ≤5 问决定性事实快照＋假设声明 |
| L1 | 定向采集（门0-B） | 条件触发＋委托人同意（见下） | 四件套（见§六）＋三句话复述 |
| L2 | 补访（门0.5） | 分析中撞上"可问出的事实缺口" | 补访记录＋第三段重分层 |

**门0-B 升档触发（满足其一，且先征得同意）**：
1. 咨询以口头为主、无成套文书；
2. 门0-A 回答中 ≥2 项"暂不清楚"；
3. 争议属高要件复杂度类型（婚姻家事涉财产抚养／建设工程／股权／多主体）；
4. 材料虽多但来源单一、无第三方载体（单方陈述主导）；
5. 委托人明确要求深度采集。

**同意话术**："案情需要一轮定向采集——按法律要件逐项核对事实与证据载体，约多花几分钟，可否？"
**不升档**：材料齐备且有第三方载体／精简三段模式／用户只要快照级方向判断。
**时间预算极短**（如一通电话）：明说产出上限——只采事件骨架，声明"本次只拿到准备好的版本"，验收标准从"要件覆盖"换成"事件骨架完整"，结束时回到要件清单再约第二次。

## 二、问什么：九类采集框架 × 八股槽位映射

> **靶心三层**：**案由层**要件从 [element-library.md](element-library.md) 取；案由说不清 → 先问"你想让对方承担什么后果"反推请求权；连后果也说不清（刚接案/一通电话）→ 走**骨架层**三问起头——谁对谁做了什么／有没有约定过／钱、物、话有没有给出去、交出去、说出来——边采边收敛案由；**抗辩层**（时效、履行、免责、抵销）在要件表成形后补问。

| 类 | 问什么（示例问题锚点） | 落点八股槽位 |
|---|---|---|
| 0 接案自问 | 有无利益冲突？时效/期限是否即将届满？是否在专业范围、能力时间够不够？当事人期望是否合理、成本承受力？ | 第零段强制项；执业事故防线 |
| 1 程序坐标 | 现在什么阶段（未诉/一审/二审/执行/侦查/审查起诉）？有无生效文书、裁决、前案判决？时效、除斥期间、举证期限、上诉期的**届满日**？有无前任律师、为何更换？ | 第零段程序信息表＋承题边界声明＋第七段程序冲突点 |
| 2 目标与底线 | 想要什么结果（用法律语言：确认/给付/变更/免责）？**拿不到第一结果，能接受的第二好结果是什么**？在乎的是钱、时间、名声、关系还是"要个说法"？ | 第一段 L 命题排序＋第八段条件式结论与反转条件 |
| 3 主体与关系 | 谁和谁？主体资格、行为能力、是否存续？有无第三人/共同债务人/担保人/实际权利人/职务行为？谁有权作指示？ | 第四段主体类要件＋第三段事实表 |
| 4 时间轴 | 按时间顺序重建：缔约/行为日 → 履行/交付日 → 违约或损害发生日 → **知道或应当知道之日**（时效起算）→ 催告日 → 最后一次主张权利日 → 今天 | 第三段 F 表（已验证）/S 表（陈述）；断点标 U（写待核） |
| 5 行为与合意 | 约定了什么、实际做了什么、没做什么、对方承诺过什么？"我只是帮忙""钱不是我的"等概括表述拆成具体动作追问 | 第三段分层＋第五段事实依据 |
| 6 金钱与损失 | 金额与计算方式？已付未付？损失范围？**损失如何证明**（常被跳过，往往才是败诉点）？ | 第四段证明标准与举证方＋U 表 |
| 7 证据载体（紧跟每条事实问） | 载体（书面/转账/聊天/录音/邮件/证人/监控）？原件在哪、谁保管、会不会灭失？来源分级：亲历/当事人转述/口头告知/网络查询/个人推测——证明价值完全不同 | U 表"转为已证所需证据"列＋第八段补强建议 |
| 8 不利事实与对方抗辩（最易漏、最致命） | 对我方不利的事实有哪些？己方有无违约、过错、迟延、瑕疵？对方最可能怎么抗辩？我们有没有"答案"？ | **第六段抗辩预置清单（喂给中股子 Agent）**＋第七段反向天平 |
| 9 约束条件 | 预算与时间压力？对方偿付能力与执行可能？保密需求？调解意愿？当事人配合度与心理状态？ | 第八段适用边界＋行文轨策略段 |

**垂直化**：固定业务可把本表固化成 checklist（例：交通事故初次接待＝基本信息 → 事故经过与责任 → 人员伤亡 → 财产损失 → 保险理赔 → 核心诉求，另附"紧急事项速查"：责任认定复核期限、证据调取、财产保全）。

## 三、该不该问：五把筛子（问题入清单前逐项过）

| 筛子 | 检验 | 通不过 |
|---|---|---|
| ① 要件对应性 | 它对应哪个构成要件/抗辩要件/量刑情节？ | 答不上＝闲聊，不问 |
| ② 结论决定性 | 答案不同，法律结论会不会变？ | 不变＝不问（或降级） |
| ③ 可核查性 | 答出来有无独立来源可验证？ | 没有＝标注"待证/存疑"，不得当事实用 |
| ④ 来源可分级 | 这是亲历、转述还是推测？ | 必须当场标注来源 |
| ⑤ 不污染 | 是不是引导性问题？是不是一句话两个问题？ | 两者皆禁 |

**三种禁止问法**：
- 不打断当事人完整叙事（打断会让他漏掉本来会说出口的细节）；
- 不把两个问题捆成一个（"你看了合同并理解了吗？"）；
- 不用"为什么"作主追武器（易触发防御性辩解；改"当时是什么情况让你决定……"）。

**发什么清单**：发**材料清单**（"请把合同、转账记录、微信记录带来"），不发**问题清单**——前者帮他把证据拿来，后者帮他把说法做厚。

## 四、怎么问：T型漏斗 × 状态自适应

**T型漏斗四段**：
1. **开场**：一句开放邀请——"用你自己的话说说怎么回事"，然后闭嘴。前期属于当事人；
2. **中段**：逐主题先开放（"当时你们怎么谈的"）→ 再收窄封闭（"书面解除通知给了吗"）→ **每个主题收尾复述一遍让当事人确认**；
3. **末段**：矛盾核对用非指责框架——"前面你说 X，后面听起来像 Y，帮我核对一下"（当作记忆校准，不是质问）；
4. **收尾必问**："还有什么你觉得我应该知道、但我没问到的？"——不问，他日后就可以说"是你没问"。

**状态自适应**（读当事人，不读 AI 自己的介入量）：

| 当事人状态 | 追问动作 |
|---|---|
| 愿意说、说得准 | **展开**——让他把说法讲完，不打断 |
| 愿意说、说不准 | **打捞**——转数字："哪天／多少／几个人／在哪" |
| 不愿说、绕开 | **回追**——标缝隙换钥匙；话术："这一块对方一定会问，现在先说清楚，庭上才不被动" |
| 情绪化、防御 | **卸下**——先处理情绪，绕路，暂不追问 |

**四条追问铁律**：
1. **问数字**：哪天、多少、几个人、在哪——观点无法证伪，数字可以；"为什么"邀请解释，解释可以现场构造；"多少/几次"邀请交付，可交付的东西才有载体；
2. **问载体**："这事有没有留下什么东西？"（本协议专属，对接§五）；
3. **抓未定义词**：当事人用掉的定性词（借/合伙/投资/分红/押金）未被定义就使用——追问它的定义（转账备注写什么？有没有约定还款时间？"住址"是怎么来的？）。**定性词是采集的起点，不是采集的结论**；
4. **找缝隙**：当事人"停住"的地方、"这个比较复杂"然后跳过去的地方、突然改口"记不清了"的地方——**那就是不利事实所在**。

**估存量四档**：有备而来（带材料/写时间线/问过其他律师）＝厚，重心后移到对抗与证据落地；首次口语化＝中，边听边补时间锚点；**被对方或他人培训过＝极厚——警惕统一口径，对流畅处反向追问**；情绪主导＝薄且乱，先走卸下。
**叙事越流畅越要问载体**——可信感是可制造的，载体才是判据。

## 五、证据落地六问（每个成形断言追一遍）

```
① 载体：这事有没有落在什么东西上？（书证/电子数据/物证/第三方记录/人证）
② 位置：在哪儿？（物理位置／数字位置）
③ 持有人：在谁手里？
④ 可取得性：当事人能拿到吗？拿不到的话，谁能拿到、要什么手续？
⑤ 孤证：就这一份吗？有没有独立来源的第二份？
⑥ 反证：有没有什么东西能证明它不是这样？
```

落地状态四档 → 直写第三段 U 表（与四态对齐）：

| 落地状态 | 四态走向 |
|---|---|
| 已落地 | F 候选（仍须过四态分层复核） |
| 有线索未取得 | U（写取得路径与手续） |
| 无载体 | U（标注"该事实目前仅凭当事人陈述"） |
| 缺口 | U＋第八段补强建议 |

**来源分级与四态对齐**：亲历＋载体验证 → F 候选；单方陈述/转述 → S（标陈述方）；推测无载体 → U；与争议无关联 → E。**当事人陈述与客观证据绝不混列同一格**。
确实无载体时不放过：改问第三人（"当时还有谁在"）、改问间接载体（"你后来跟谁提过这事？有没有微信？"）。

## 六、问够了吗：收口自检 + 三句话复述

**四件套交付物**（门0-B 结束时写入第零段）：
1. **程序信息表**：阶段／期限与届满日（尤其时效）／已生效文书／待办节点；
2. **事实时间线**（两栏）：当事人陈述｜已验证来源——分开成栏，不得混列；
3. **证据线索表**：断言｜载体｜持有人｜取得路径｜灭失风险｜落地状态；
4. **缺口归类清单**：法律争点／事实争点／证据争点（＋暂不下结论的法律与策略问题清单）。

**收口自检（全过才算问完）**：
- 时间轴无断点（关键节点间能解释，说不清的标"待核"）；
- 要件全覆盖或明确标缺口（每个构成要件下有事实支撑，或写明"缺证据、需补 X"）；
- 缺口已归类（法律争点/事实争点/证据争点之一）；
- 不利事实已穷尽（对方主要抗辩已预判并有应对方案）；
- 只剩核实清单（每项有获取路径、责任人和截止时点）。

**三句话复述（终极测试）**：
> "你的问题在法律上是 ______（定性），我能帮你争取的是 ______，现在最大的卡点是 ______ 和 ______。"

说得出三句 → 可开干（或按既有流程续跑）；说不出 → 还在"听故事"阶段，**不得进入破题**，回到漏斗继续采。
**问够了没有的判据**：能不能走完"固定请求 → 找基础规范 → 找抗辩规范 → 拆要件 → 检索主张 → 整理争点 → 证明要件事实"这条链——走不完，就是还没问完。

## 七、与外部技能的分工

- 门0-B／补访环场景：本文件**取代**对 `lawyer-fact-elicitation` 的外调依赖（原技能继续存在，不受影响）；
- 深水区仍指向原技能：语音/录音承载（当场追问＋事后复核两段式）→ 原技能 references/07；完整状态信号表 → references/03；执业伦理边界全文（不得教当事人怎么说、不得统一口径）→ references/04；
- 对**非当事人**采专家经验 → `interview-craft`；采集到一定量后接三维闭环验证 → `fact-finding-3d`；
- 三形态对照：**A**＝生成要件问题清单（准备见当事人）；**B**＝诊断已有谈话记录（用户已见过当事人且手上有记录）；**C**＝AI 直接执行采集（交互提问工具可用时）。语音承载时 C 的当场产出仅为"待复核草稿"，须回录音复核后才成立。
