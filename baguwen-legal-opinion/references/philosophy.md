# 法哲学观与核心取舍

> 这一层决定"你会做出什么样的法律 Agent"。技术可以兜底，但方向错了兜不住。

## 一、六条法哲学观

1. **结论的合法性来自过程的可回溯性，不来自措辞的确信度**
   一份写得斩钉截铁却无法回溯的分析，价值低于一份写满"存疑"但每步可核验的分析。

2. **"不知道"是有效输出，"编一个"是事故**
   系统必须允许、并鼓励输出"本项无法确认"，不得惩罚不确定性表达。

3. **遗漏比错误更危险**
   错误会被对方或复核者抓住；遗漏不会，它直接进入结论。所有机制优先服务于"防遗漏"。

4. **对抗不是可选项，是必要工序**
   单向推理无论如何详尽，都受提问视角的结构性偏见。必须以隔离的第二视角强制攻击。

5. **法条是事实，不是记忆**
   条文号、原文、效力状态必须来自检索层；模型记忆只可用于"定位检索方向"，不可用于"输出依据"。

6. **Agent 的定位是"把律师的复核成本降低"，不是"代替律师下判断"**
   衡量标准是：执业者核验这份分析需要多久。若核验时间 ≥ 自己从头做，则该 Agent 无价值。

## 二、五个判断（为什么这样设计）

**判断一：这不是"换个场景"，而是"层级下移"**
母版里八股是研究者的分析框架（建议性脚手架，可不遵守）；本技能里八股是模型的运行时协议（强制性状态机，不可跳过）。因此需要额外工程：段间门禁、DoD 校验、交接包传递、对抗隔离。**没有这些工程，八股只是段好看的提示词。**

**判断二：八股与法律推理同构，不是比喻**
"代圣贤立言=依规范裁断""破题不许犯题字=禁偷换概念""四股两两对仗=正反对抗校验"——两者共享同一套【权威约束下的对称论证结构】。迁移是结构性的。

**判断三：LLM 的流畅性正是法律工作的敌人**

| LLM 本能 | 法律工作要求 | 冲突 |
|---|---|---|
| 倾向给确定答案 | 显性标注不确定性 | ★★★ |
| 倾向补全缺失（幻觉） | 标注证据缺口 | ★★★ |
| 倾向顺着提问方立场 | 对抗式双向校验 | ★★★ |
| 倾向压缩步骤直奔结论 | 逐步展开不跳跃 | ★★★ |

> **可迁移结论：当模型本能与任务要求相反时，不要靠提示词去"劝"，要靠状态机去"卡"。** 提示词是软约束会被冲掉，状态机是硬约束挡在那里。

**判断四：顺序本身就是防线**
八段不可交换（详见 protocol.md 顺序表）。任何"合并两段以提高效率"的改动都在拆阀。

**判断五：法律场景里"要件"是可结构化资产**
普通 RAG 检索"相似文本"，法律 RAG 应检索**结构化的要件框架**。因为法律最贵的错误不是"说错了"（会被发现），而是"没说到"（不会）——而"没说到"只能靠清单比对检测，不能靠阅读感受检测。这就是必须先检索"框架"再检索"条文"的根本原因。

## 三、五条设计取舍

```
取舍一：可控性 > 自主性    —— L2 骨架 + 局部 L4，LLM 只在段内做局部推理
取舍二：可回溯 > 更聪明    —— 宁可结论保守但每条可点开原文核验
取舍三：留痕 > 简洁        —— 三清单必须与结论同屏，不为"好看"折叠
取舍四：对抗 > 单次深想    —— 隔离双视角 > 同一视角反复思考
取舍五：法条由系统提供 > 由模型记忆 —— 条文必须检索回填
```

> 取舍四的关键：对抗是**结构化分歧**，自我反思是**同一视角的重复**——后者破不了先入为主。这也是为什么第六股必须物理隔离、而非"让同一个模型同时想两面"。

## 四、表达层哲学：内核八股，外壳律师文体

- **八股是推理纪律，不是排版格式。** 读者看到的应当是律师真实在写的文书，不是模板堆砌。
- 校验需要结构（符号、编号、计数），成品需要语感（段落、语域、克制）——二者分离，各司其职。
- 结构化记录（引用索引、存疑清单、自检表）下沉附录；正文保持律师语域。
- **禁止机械符号外泄**：正文不得出现 `A1` / `✓` / `C1` 式编号与符号。

## 五、五个不可用/慎用地带

```
✗ 不可用（硬红线）
  1. 直接生成对外提交的正式文书（起诉状/答辩状/合同）而不经执业者签署
  2. 对个案给出"必然胜诉/败诉"的确定性预测
  3. 涉及人身自由、生命权、重大财产处分的终局判断（刑事定罪、强制措施）
  4. 替代律师-客户之间的保密沟通与利益冲突判断
  5. 凭模型记忆输出法条原文（必须检索回填或用户提供）

⚠ 慎用（需额外约束）
  1. 跨法域分析（大陆法系/普通法系混用、港澳台及外国法）
  2. 新近修改的法律（训练截止后的修法，必须实时检索核验）
  3. 高度依赖地方裁判口径的问题（违约金酌减幅度、精神损害赔偿数额）
  4. 证据真伪判断（Agent 只能标注证据缺口，不能认定真伪）
  5. 涉及专业领域事实（医疗事故、工程质量、知识产权技术比对）的事实认定
```
