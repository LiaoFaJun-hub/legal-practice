# 场景适配与模式选择

## 一、能力档位判定

```
L0 纯规则/模板   固定文书模板填充（标准借条）      ✓ 可用，不用 LLM
L1 检索+结构化   法条检索问答、要素提取            ✓ 可用，主力形态
L2 Workflow      八段协议骨架 + 段内 LLM 推理      ✓ 法律分析 Agent 主形态 ★
L3 自主 Agent    自主决定检索什么、分析什么         ⚠ 仅限内部研究辅助，禁用于对外结论
L4 对抗双 Agent  正/反双角色 + 权衡器              ✓ 在 L2 骨架内的局部升级（第五/六股）
判定：本技能 = L2 骨架 + L4 局部对抗 + 强制 HITL 出口
```

## 二、场景适配表

| 场景 | 八段强度 | 主风险 | 关键调整 | 人审强度 | 采集分档 |
|---|---|---|---|---|---|
| 内部法律研究辅助 | 全八段 | 要件遗漏 | 类案检索加强 | 中（抽检） | 门0-A |
| 合同审查 | 全八段 | 条款遗漏 | 第四股改为"条款风险清单遍历" | 高（逐条） | 门0-A（材料齐备） |
| 案件预判/诉讼策略 | 全八段 | 给出确定胜诉率 | 第八股强化条件式；禁给胜诉概率 | 高（必审） | **口头咨询主导 → 门0-B 候选** |
| 合规检查 | 全八段 | 规范更新滞后 | 闸④强化；法条库时效为王 | 中高 | 门0-A |
| 普法/知识问答 | 精简三段（1,2,8） | 过度严谨影响可用性 | 只保留破题+承题+束股 | 低 | 门0-A 可简化为一问 |
| 类案检索 | 强化第三股+双阶段 | 相似≠相关 | 以"关键事实相同"而非"文本相似"检索 | 中 | 门0-A |
| 证据梳理 | 强化第三股 | 单方材料偏向 | 分层表加"材料来源方"列与偏向声明 | 中高 | 门0-A（材料主导） |
| 文书起草辅助 | 全八段+起草段 | 生成即提交 | 输出固定加"未经执业者签署无效"水印 | 高（必审） | 材料齐备门0-A；仅口头门0-B候选 |

## 三、模式选择

```
全八段     ：内部研究备忘 / 诉讼策略 / 合规审查 / 需留痕可回溯的分析
精简三段   ：普法 / 知识问答（段 1 + 2 + 8）
场景特化   ：见上表"关键调整"列
采集分档   ：门0-A 快照 / 门0-B 深采 / 门0.5 补访——触发矩阵见 [fact-elicitation.md](fact-elicitation.md) §一
```

**精简原则**：严谨度与可用性是交换关系。普法场景用全八段会造成"什么都不可信"的观感。
但**无论多精简，第一股（去模糊）、第二股（边界）、第八股（免责与边界）必须保留**——这三段是法律安全底线，其余五段可合并简写。

## 四、五个不可用 / 慎用地带

```
✗ 不可用（硬红线）
  1. 直接生成对外提交的正式文书（起诉状/答辩状/合同）而不经执业者签署
  2. 对个案给出"必然胜诉/败诉"的确定性预测
  3. 涉及人身自由、生命权、重大财产处分的终局判断
  4. 替代律师-客户之间的保密沟通与利益冲突判断
  5. 凭模型记忆输出法条原文

⚠ 慎用（需额外约束）
  1. 跨法域分析（大陆法系/普通法系混用、港澳台及外国法）
  2. 新近修改的法律（训练截止后的修法，须实时检索核验）
  3. 高度依赖地方裁判口径的问题（违约金酌减、精神损害数额）
  4. 证据真伪判断（只能标注证据缺口，不能认定真伪）
  5. 涉及专业领域事实的事实认定（医疗事故、工程质量、技术比对）
```

## 五、场景特化的元指令变体

**合同审查**：第四股改为"条款风险清单遍历"——逐条款输出[条款摘要][风险类型][规范依据][修改建议]；
第五股逐条款判"可接受/需修改/高风险"；第六股站在相对方立场攻击己方修改建议。

**案件预判/诉讼策略**：第八股禁止输出胜诉概率数字；结论只给"倾向性 + 反转条件 + 补强证据"。
重点读第六股——委托方最需要的常是"对手会打哪里"。

**普法/知识问答**：只走破题（去模糊）+ 承题（边界）+ 束股（结论与免责）；不列要件表、不列抗辩表。
