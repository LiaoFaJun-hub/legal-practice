# 八段执行细则

> 每段统一按：要解决的问题 / 动作清单 / 产出 / DoD / 高频错误 / 陷阱。
> 所有输出禁用"显然、不难看出、毋庸置疑、毫无疑问、必然"等绝对化表述。
> 本细则针对【推理轨】；行文轨改写规则见 [writing-style.md](writing-style.md)。

---

## 第一段 · 破题 · 争议锚定 · 去模糊

**要解决**：把含糊咨询压缩成唯一核心争议，并分离"事实问题"与"法律问题"。
八股"不许犯题字"= 禁止用法律术语空壳代替争议本质（"本案涉及违约责任认定"是空壳）。

**动作**
```
□ 提取所有"双方分歧点"，形成候选争议（不计好坏）
□ 归并：共享同一规范 或 同一事实认定的分歧 → 归为一个争议
□ 排序取"决定性"的那个（其结论决定其他争议是否需讨论）
□ 拆 L（法律命题，由规范判断）/ F（事实命题，由证据认定）
□ 输出排除项清单，每条注明理由（①无法律关联 ②被前置争议吸收）
□ 材料不足以定唯一争议 → 列 2-3 个候选并请求确认，禁止自行假设一个往下走
```
**产出**：核心争议陈述 + L 命题集 + F 命题集 + 排除项清单
**DoD**：争议不含未展开空壳术语 / L 与 F 已分离 / 排除项≥2 带理由 / **★已过门1：候选争议≥2 或用户提问方向≠决定性问题时，已回问确认（见 intake.md）**
**高频错误**：争议过宽；事实/法律混同（"他是不是违约了"是法律评价）；未做归并
**陷阱**：用户提问方向 ≠ 真正争议。须显式标注"决定性问题可能是 X，与提问方向不一致"。
**不检索**：本段不检索法条（过早检索会造成"先有法条后有要件"的倒置）。

---

## 第二段 · 承题 · 概念界定 · 锁边界

**要解决**：钉死概念、适用法条、边界，主动暴露歧义与例外。

**动作**
```
□ 列核心法律概念（3-7 个）：定义 / 来源锚点 / 本案指向
□ 检索并锚定法条：★四元组 [条文号][原文片段][来源标识][核验时间]；未命中写"未检索到，需人工核实"
□ 标注概念歧义点（日常用语/多部门法/新旧法/地方口径差异）
□ 列适用例外清单（≥2）：法条但书 / 司法解释限缩扩张 / 特别法优先
□ 声明边界：法域 / 时点 / 层级 / 不含项
□ 标注效力与时效风险（是否近改、溯及力、征求意见稿）
```
**产出**：概念表 + 法条锚定集 + 歧义清单 + 例外清单 + 边界声明
**DoD**：每概念有来源锚点 / 引用四元组完整 / 歧义≥2 / 例外≥2 / 边界四项齐 / 未命中已显式标注
**高频错误**：凭记忆写条文号（法律幻觉主源）；只写概念不写例外；忽略时间边界
**陷阱**：同名概念跨法域差异（善意/重大过失/损失），须声明所采语境并登记其他解释。

---

## 第三段 · 起讲 · 事实分层 · 分真伪

**要解决**：把材料切成四态（F/S/U/E）。**本段只分层，不做认定**。

**动作**
```
□ 遍历材料切最小信息单元（一句一单元）
□ 每单元打四态标记（标准见 redlines.md 第五节）
□ 防误升级：含"据…称/主张/回忆"且无证据 → 强制 S；标 F 但查无证据来源 → 回退重判
□ 防误降级：双方确认/生效文书/书证物证 → 应标 F，不保守标 U
□ 生成四表；S 表须标陈述方；U 表须写"转为已证所需证据"
□ 本段红线：不得输出任何评价性判断
```
**产出**：F 表 / S 表 / U 表 / E 表 + 材料来源偏向声明（若全来自一方）+ **门0 假设声明落入 U 表**
**DoD**：全信息单元有归属 / S 类标陈述方 / U 类写所需证据 / 无评价性表述 / 无 S→F 误升级、F→U 误降级 / **★门0 的"暂不清楚"项已登记为 U 类且按保守假设标注**
**高频错误**：单方陈述当事实（最高频最致命）；保守过度；分层段就评价
**陷阱**：材料全来自一方 → 大量信息只能 S 类；须在段首声明偏向风险并写入第八股存疑清单。

---

## 第四段 · 入手 · 要件锚定 · 建框架

**要解决**：产出**封闭的要件清单**。防遗漏的枢纽段。

**动作**
```
□ 以争议类型+第二段概念为键检索要件库（命中则用；未命中则法条反推并登记风险）
□ 列规范基础候选（多候选并列，不提前单选）
□ 每个候选罗列全部必备要件，编号 A1..An
□ 每个要件标注：证明标准 / 举证方（含分配依据）/ 要件缺失后果
□ 生成抗辩事由预置清单（供第六股比对，非穷尽结果）
□ 反向检查"应适用但未列入"的规范（逐项写"本案是否可能适用及理由"）
□ 输出要件-事实映射预填表
```
**产出**：规范候选 + 要件清单（编号封闭）+ 证明标准 + 举证分配 + 抗辩预置 + 排除说明
**DoD**：编号连续封闭（R2 基础）/ 每件有证明标准与举证方 / 写明缺失后果 / 多候选并列 / 排除说明≥1
**高频错误**：清单不封闭（防遗漏失效）；提前单选规范；不写举证责任
**陷阱**：要件 ≠ 抗辩。抗辩是独立规范事实，留到第六股，预置清单仅供比对。

---

## 第五段 · 起股 · 正向论证 · 逐一对标

**要解决**：正向遍历全部要件，逐项判定，**禁默认成立、禁跳过**。

**动作**
```
□ 按 A1..An 顺序逐项论证（顺序即防跳）
□ 每项同时给：事实依据（F 类；S 类只能标"据__方陈述，不足以支撑"）+ 规范依据四元组 + 推理说明
□ 判定用四态 ✓◐✗?，禁二态
□ 可拆分要件先拆子要件逐项判定再汇总
□ 禁补事实（只用第三段表内事实；需要表外事实 → 标"需补充材料"）
□ 禁默认成立（不写"其余要件显然满足/不再赘述"）
□ 输出要件覆盖自检（判定条目集合 == 要件清单集合）
```
**产出**：逐要件判定 + 覆盖自检
**DoD**：判定集合 == 要件集合（★R2）/ 每条含事实+规范+推理三要素 / 四态 / 无跳过 / 未引入新事实 / 覆盖自检一致
**高频错误**：默认成立（遗漏风险最大处）；用 S 类支撑；论证中悄悄补事实（幻觉的隐蔽形式）
**陷阱**：正向 Agent 立场污染。指令用中性表述"逐项判定要件是否满足"，并明确"存疑是合格输出，不是失败"。

---

## 第六段 · 中股 · 反向抗辩 · 对抗校验

**要解决**：站在相对方视角**穷尽**抗辩，攻击正向每一环节。**最不可省略的一段**。

**动作**
```
□ ★R3 上下文隔离：只接收 分层事实表 + 要件清单 + 法条锚点 + 第五段判定符号摘要
  （不接收第五段完整推理文本）
□ 按穷尽树五类逐类穷尽（权利障碍/权利消灭/权利阻止/证据抗辩/程序抗辩）
□ 两条补充路径：P1 例外回溯（但书/司法解释逐条转抗辩）；P2 事实反查（逐 F 项问"若不成立/相反，请求权是否动摇"）
□ 对第五段每个 ✓成立 要件至少尝试一次攻击；无可行抗辩须写明"经检索未发现可行抗辩事由"
□ 输出正向论证漏洞清单（≥2），标类型
□ 每条抗辩标：类型 + 规范依据（四元组）+ 支撑事实编号 + 强度 + 影响要件 A_
```
**产出**：五类抗辩 + 漏洞清单 + 逐要件攻击记录 + 反向成立依据汇总
**DoD**：五类均尝试 / 漏洞≥2带类型 / 每个 ✓ 有攻击记录 / 每条抗辩有依据或标"无规范依据，属事实抗辩" / 标注强度 / 已确认上下文隔离
**高频错误**：抗辩不穷尽只列1-2条；抗辩被正向锚定；抗辩无依据（空泛质疑）
**陷阱**：抗辩须落到具体要件编号（"影响要件 A_"），否则第七股无法逐项权衡。

---

## 第七段 · 后股 · 冲突权衡 · 定权重

**要解决**：对正负冲突点做**有依据的**权重判定，而非"我觉得哪边有理"。

**动作**
```
□ 列所有冲突点 C1..Cn（正向判定 vs 反向抗辩交锋处）
□ 每冲突点填天平两侧五项：事实依据 / 规范依据 / 证明标准 / 举证方 / 举证是否完成
□ ★强制走完 7 条优先级规则，写明命中哪条（见 redlines.md 第四节）
□ 逐点判定：正向胜 / 反向胜 / 存疑（存疑须写缺什么）
□ 汇总法律效果判定（成立/部分成立/不成立/真伪不明）
□ 输出留存争议清单
```
**产出**：冲突清单 + 规则适用总表 + 效果判定 + 留存争议清单
**DoD**：每冲突填全天平五项 / 写明命中规则 / 存疑写明缺口 / 有汇总判定 / 留存清单非空或显式声明无
**高频错误**：直觉代替规则序列；忽略举证责任（真伪不明判错方向）；强行消除存疑
**陷阱**：本段只能用第二/三/四段已锚定材料。需新规范 → 回退第二段补充检索，不得临时引入。

---

## 第八段 · 束股 · 结论收敛 · 留风险

**要解决**：收敛结论并**强制显性留痕**。

**动作**
```
□ 回到第一段，逐条回答 L 命题与 F 命题
□ 带限定条件的结论（条件式，禁无条件断言）
□ ★R4 三清单同屏：存疑清单 / 适用边界 / 排除项，与结论同屏不折叠
□ 适用边界≥4：法域 / 规范效力时点 / 不适用情形 / 自由裁量空间
□ 补强建议≥2：需取得什么证据→证明哪要件→取得方式；需核实什么规范→方式
□ 固定尾部三提示：不构成法律意见 / 请核验现行有效原文 / 重大事项请执业者复核
□ 跑最终自检（见 SKILL.md 第九节）
```
**产出**：完整八段分析 + 人审复核清单
**DoD**：结论条件式 / 三清单同屏齐（★R4）/ 边界≥4 / 补强≥2具体 / 已回第一段 / 尾部三提示 / 全篇无绝对化表述
**高频错误**：无条件结论；边界缺失；补强建议空泛（"建议咨询律师"无价值）
**陷阱**：读者常只看最后一段 → 存疑清单放结论紧邻位，结论句首用"倾向于"限定（排版层面的防误读设计）。
