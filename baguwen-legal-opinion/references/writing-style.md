# 律师文体指南（行文轨改写规范）

> 目标：读起来是律师真实在写的文书，不是机器套模板。
> 内核（要件遍历、四态、条件式结论、三清单）一个不少，但以段落式论述承载。
> **八股是推理纪律，不是排版格式。**

## 一、两条铁律

```
1. 机械符号不外泄：正文不得出现 A1 / ✓◐✗? / C1 / D1 / V1 等编号与符号。
   这些只存在于推理轨与附录（自检表）。正文用文字表达。
2. 内容不缩水：行文轨须完整保留推理轨的每项要件、每条抗辩、每个存疑项；
   可由 validate_delivery.py 与人工一致性核对。
```

## 二、八段 → 章法的行文映射

| 八股 | 推理轨形态 | 行文轨形态 |
|---|---|---|
| 破题 | L1-L4 / F-a… | 引言段自然陈述"本案的核心问题在于…" |
| 承题 | 概念/歧义/例外表 | "适用规范与概念界定"段落，歧义与例外用"其一…其二…" |
| 起讲 | F/S/U 三表 | 叙述 + 括注证据强度："经查…（证据一）；未获凭证，尚待证明" |
| 入手 | A1-An 要件表 | "请求权基础与构成要件"分段论述，"第一…第二…" |
| 起股 | 四态判定表 | 逐要件段落论述，四态译为文字 |
| 中股 | 抗辩五类表 | "对方可能主张…对此，我们认为…"对话式 |
| 后股 | C1-C4 命中规则表 | "综合权衡"说理段（讲规则，不列编号） |
| 束股 | 三清单表 | "结论 + 风险提示"，清单律师化但同屏 |

## 三、语域与惯用句库

**开头**
- 受…委托，就…事宜，本所审阅了…等材料，并检索相关现行规范后，出具如下分析意见。

**说理连接**
- 其一…其二…其三… / 就…而言 / 关于… / 综上 / 鉴于此 / 需要指出的是 / 需要提示的是
- 本所倾向于认为… / 在本所看来… / 我们注意到… / 须予查明的是…
- 上述两项均可能使结论反转，须予查明。

**呈现证据强度（替代 F/S/U）**
- F 已证 → "经查，…（证据一）"；"该项可以认定"；"并无疑义"
- S 单方陈述 → "…主张…，然截至本意见出具之日，未提供相应凭证"；"此系单方陈述，尚待证明"
- U 存疑 → "该项目前处于待证状态"；"现有材料尚不足以达到高度盖然性的证明标准"
- E 排除 → "本意见未予涉及"；"与本案争议无法律关联，另案处理"

**四态的文字映射（保证可追溯）**
| 符号 | 行文表达 |
|---|---|
| ✓ 成立 | 可以认定 / 予以认定 / 该要件成立 |
| ◐ 部分成立 | 在…范围内成立 / 部分成立（已满足…未满足…） |
| ✗ 不成立 | 不能成立 / 不能认定 / 该项不符合 |
| ? 存疑 | 尚待证明 / 存在证据缺口 / 暂难认定 / 处于待证状态 |

**结论**
- 综上，在【条件】成立的前提下，本所倾向于认为…。
- 反之/若【条件】不成立，则结论可能转为…。

## 四、段落组织范式

**要件论述段**（一段一要件）：
```
关于第【N】项要件，即【要件名】。【事实依据（叙述）】。【规范依据（正文引 Ref）】。
【推理说明】。故该项【四态文字结论】。
```

**抗辩段**（先敌后我）：
```
其一，关于【争点】。对方完全可以主张：【对方论证】。此点直击【哪项要件】，
构成本案最具威胁的抗辩，本所予以采纳/部分采纳。
（自我审视）须坦率指出，本分析对【要件】只能判为待证，实际未形成有效证明。
```

**权衡段**：
```
综合而言，就【争点一】…；就【争点二】…。二者并不矛盾——【释明】。
基于【强制性规定优于任意性规定 / 举证未完成由该方承担不利后果】之一般原理，
本所倾向于认为…。
```

## 五、引用转位（保住 R1 又不显机械）

- 正文写"（见附录一 Ref-2）"，不堆四元组。
- 四元组、来源、效力核验时间落【附录一 引用索引】表。
- 这样既符合律师文书习惯（注释/附录引用），又保留可核验性。

## 六、禁用清单

```
✗ 机械符号：A1 / ✓ / ◐ / ✗ / ? / C1 / D1 / V1 / Q1（附录交叉引用除外）
   ★ 半角问号 ? 亦属机械符号（四态符号之一），正文一律用全角"？"。
✗ 绝对化表述：显然 / 必然 / 毫无疑问 / 毋庸置疑 / 肯定（软性，慎用）
✗ 无条件结论："本案公司违法"（应："在…前提下，倾向于认为…"）
✗ 确定数值：胜诉率、赔偿 X 元
✗ 空泛建议："建议咨询律师"（应具体到证据名称与取得方式）
✗ 表格堆砌：正文用段落，清单与表格下沉附录
```

## 七、自检（行文轨交付前）

```
□ 通读一遍是否像律师写的（无"模板味"）
□ 机械符号未外泄正文（validate_delivery 会自动查）
□ 三清单（存疑/边界/排除）与结论同屏、律师化呈现
□ 结论条件式，含"倾向于"与反转条件
□ 未丢失推理轨的任何要件、抗辩、存疑项（一致性核对）
□ 引用以"（见附录一 Ref-x）"落地，附录四元组完整
```
