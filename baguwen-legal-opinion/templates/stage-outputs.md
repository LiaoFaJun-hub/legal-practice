# 推理轨产出模板（结构化 · 机器可校验）

> 本模板用于【推理轨】——内部结构，供 check_redlines.py / check_dod.py 解析。
> 它不直接交付给读者；交付物是行文轨（见 [opinion-template.md](opinion-template.md)）。
> 解析约定见 [../references/redlines.md](../references/redlines.md) 第七节。

---

## 第零段 · 澄清（开干前，门0/1/2）

```
[目的说明]：为避免全篇返工，先确认 N 项会使结论反转的关键事实；若不清楚可选"暂不清楚"，
            按保守假设推进并显式标注。

[门0 提问与回答]（编号用「问」以区分第八段存疑清单的 Q）
问1 ____（定性:法律关系性质/效力） ｜ 选项 A/B/C/暂不清楚
   用户回答：____
问2 ____（范围:标的/财产/子女）      ｜ 选项 A/B/C/暂不清楚
   用户回答：____
问3 ____（程序:是否进入诉讼/期限）   ｜ 选项 A/B/C/暂不清楚
   用户回答：____

[门1 焦点确认]（若触发）：核心争议 ____ ｜ 决定性问题 ____ ｜ 用户确认：____
[门2 要件确认]（若触发）：要件框架来源 要件库命中/模型推导 ｜ 用户确认：____

[假设声明]：用户对 问_ 未确认 → 本案按假设 H1（____）推进；
            若实际情形不同，结论将改变。已落入第三段 U 表与第八段存疑清单。
→ 交接包⓪：澄清问答 + 假设声明
```

## 第一段 · 破题

```
1. 核心争议本质（一句话，不含空壳术语）：
2. 待解决的法律命题（L）：
   L1 ____（前置性：____）
   L2 ____
3. 待查明的事实命题（F）：
   F-a ____
   F-b ____
4. 排除项（E，≥2，带理由）：
   E1 ____ —— 排除理由：____
   E2 ____ —— 排除理由：____
→ 交接包①：核心争议 + L 集 + F 集 + E 清单
```

## 第二段 · 承题

```
1. 核心概念释义（3-7）：
   C1 【概念】定义：____；来源：[条文号][原文片段][来源标识][核验时间]；本案指向：____
2. 概念歧义点（≥2）：
   歧义 A1 ____ —— 解释① ____ ② ____ —— 本案采 ____ 理由 ____
3. 适用例外（≥2）：
   例外 X1 ____（来源四元组）
4. 分析边界：法域 ____ ｜ 时点 ____ ｜ 层级 ____ ｜ 不含 ____
5. 效力与时效风险：____
→ 交接包②：概念表 + 法条锚定集 + 歧义清单 + 例外清单 + 边界声明
```

## 第三段 · 起讲

```
★ 本段仅作事实分层，不作任何法律评价。
表一 已证事实（F）：F1 ____ —— 证据来源：____
表二 单方陈述（S）：S1 ____ —— 陈述方：____ —— 支撑证据：____
表三 存疑事实（U）：U1 ____ —— 存疑原因：____ —— 转为已证所需证据：____
表四 排除项（E）：E1 ____ —— 排除理由：____
材料来源偏向声明：____（若材料全来自一方）
→ 交接包③：F/S/U/E 四表
```

## 第四段 · 入手

```
1. 规范基础候选（并列）：Ⅰ ____（四元组）｜ Ⅱ ____（四元组）
2. 要件清单（编号封闭）：
   A1 ____ ｜ 证明标准 ____ ｜ 举证方 ____ ｜ 缺失后果 ____
   A2 ____ …（含消极事实须标注"（消极事实）"）
   举证责任分配依据：____（四元组）
3. 要件-事实映射预填：A1 ← F1/F3 ✓ ；A2 ← 无（缺口 U_）
4. 抗辩事由预置清单（供第六股比对）：D-预1 ____ …
5. 未纳入规范的排除说明（≥1）：____
→ 交接包④：要件清单（封闭）+ 证明标准 + 举证分配 + 抗辩预置
```

## 第五段 · 起股

```
逐要件正向论证（四态：✓成立 / ◐部分成立 / ✗不成立 / ?存疑）：
A1 【要件名】
   事实依据：F_ ｜ 规范依据：[条文号][原文片段][来源标识][核验时间]
   推理说明：____
   判定：✓ 成立
A2 【要件名】 子要件 A2-1 ____ → ____ ；汇总 ◐ 部分成立（已满足 ____ 未满足 ____）
A3 【要件名】 事实依据：仅 S_（据__方陈述）→ 判定 ? 存疑 —— 需补充：____
A4 【要件名】 事实依据：无 → 判定 ✗ 不成立 —— 原因：____

【要件覆盖自检】
要件清单条目数：__ ｜ 本段判定条目数：__ ｜ 是否一致：__（★R2）
→ 交接包⑤：逐要件判定 + 覆盖自检 + 判定符号摘要（A1✓ A2◐ A3? …）
```

## 第六段 · 中股

```

  2 权利消灭：____   3 权利阻止：____（注明是否需当事人主张）
  4 证据抗辩：____   5 程序抗辩：____
  P1 例外回溯：____  P2 事实反查：____
二、正向论证漏洞清单（≥2）：V1 ____ 类型 ____ 影响 A_ ｜ V2 ____

→ 交接包⑥：抗辩清单 + 漏洞清单 + 攻击记录 + 反向依据汇总
```
