# 中国法律沿革比较（chinese-legal-evolution）

## 一、这是什么（定位）

**不是法条检索器，是「同一法律问题在时间轴上的规范状态测绘仪」。**就一个具体案情/法律问题，梳理中国主要朝代（秦·汉·隋·唐·宋·元·明·清 → 民国 → 中国现行法律），  该问题在各朝的法律规定，并按时间轴做法律视角的横向比较。输出：比较范围与判断标准、朝代—法源—核心规定—与前朝差异的对照表（标注沿用/修改/增补/废止/并存）、**规范状态谱系图（纯文本框线图，标关系而非原文，含三句图说）**、趋势与转折点归纳、明文规定与实际执行及学理解释的三分、不确定性清单、以及从法律变迁角度的总结。表达遵循清晰表达规范与文言/白话/现代法三重语域并置。

它回答的不是"这条法文怎么写"，而是——**这个法律问题在中国是怎么一步步变的？变的不是文字，是"什么被禁、什么被放、什么被要求"。**

### 三个承重判断（决定一切下游）

**判断一：存佚决定结论上限。** 每一个朝代节点在开始比较之前，必须先判它"能知道多少"。判档结果直接封顶该朝能得出的结论强度——**这不是谨慎，是数学**：隋代《开皇律》全佚，任何"隋代如何规定"的断言都无材料支撑。

**判断二：「无材料」≠「无规定」。** 这是本技能最容易犯、也最致命的错。史料没有，不等于当时没有规定；只能写"无法判断"。**把材料的沉默当成制度的沉默，是把学术无知包装成历史认知。**

**判断三：史料沉默 ≠ 已废止。** 判"废止"必须有正面依据（修律诏令／律例沿革说明／判例 cessation／官修目录著录，四者之一）。找不到依据时唯一正确的表述是"未见废止依据"——**"未见废止依据"与"已废止"之间隔着一整部学术史。**

### 与 `ancient-chinese-litigation-drafting` 的分工

| | 前技能 | 本技能 |
|---|---|---|
| 回答 | 这个朝代**怎么写**（体式·称谓·收束语） | 这个问题**怎么变**（条文·差异·转折） |
| 产物 | 一份可投递的文书 ＋ 白话附录 | 一条时间轴比较曲线 ＋ 不确定性清单 |
| 场景 | 拟写秦代爰书、清代告状 | 研究"告尊长"历代怎么罚、"亲亲相隐"为何消失 |

两者平级互引：本技能的比较表可为前技能"情理与法理依据"段供给素材；前技能不负责生成条文比较。

## 二、调用者（谁在何时调用）

- **直接用户**：研究法制史/法律史的写作者、要做"古今法比较"专题的人、教学者。
- **上游技能**：`longform-writing-prefight` 类长文前置检查（识别到需要法制史脉络时路由至此）；`legaltech-paper-writing`（论文需法律沿革支撑章节时）。
- **不适用**：现行法律实务、诉讼策略、立法政策建议——一律不接，见第十段铁律。

## 三、SOP 总览（六步）

```
S1 界定问题   → 案情事实、法律部门、判断口径（唐律"坐"/明清"律例并罚"/现行"违法+责任"不可直接对齐）
              → 【本步同时定图型】见下方"图型路由"
S2 存佚判档   → 十个节点逐一判可判断度；判档结果封顶该朝结论强度，并写入输出
S3 检索法源   → 古代走法源底座索引；民国与现行走在线核验（官方源 + 时效性字段）
S4 判差异     → 五态（沿用/修改/增补/废止/并存），判"废止"须正面依据
S5 判转折与动因 → 转折点须双证据；社会动因须有文献，否则入不确定性清单
S6 成表、作图、成清单 → 七段式报告；图按"列节点→连关系→标不确定→写三句图说"四步构造
```

**S1 与 S2 是硬闸门**：问题范围未界定、或存佚未判档之前，**不得开始检索与撰写**。未判档就检索，必然在隋代节点上写出无据之论。

### 图型路由（在 S1 定，不得推迟到 S6）

> **依据**：工作区约定「**呈现形态错会使整份产出返工→是路由层级非输出参数**」。故图型是路由决定，不是收尾时的临时选择。

| 情形 | 图型 |
|---|---|
| 默认（本技能全部产出） | **规范状态谱系图**：节点＝朝代＋判档，箭头＝差异态，标输入输出，1949 画成断链 |
| 用户只要文字不要图 | 先说明"本技能的图是理解结构的一部分"，再依用户意愿省略 |

### 载体分档（S1 与图型同时定）

**图型恒为「规范状态谱系图」；变的只是画法。规模决定载体，不决定图型。**

| 载体 | 节点数 | 说明 |
|---|---|---|
| **T1 纯文本框线图**（默认） | **≤ 12** | 零依赖，读者不装任何东西就能看 |
| **T2 Mermaid** | 13–24 | 仍是纯文本，可被任何 Markdown 渲染器出图 |
| **T3 inline SVG** | > 24 | 演示级成品；**必须另附等价 Mermaid 作为机检基准** |

> **节点 > 12 就画框线图是错的**——密度过高必然错位。降级是义务，不是选项（校验码 `CARRIER_TOO_DENSE`）。
> **换载体不换纪律**：节点单概念、关系须有出处、不确定须标 `[?]`、图说三句，三档一律同标准。
> **降级须在【三】注明载体**，否则读者会误判密度上限不存在（校验码 `CARRIER_NOTE_MISSING`）。

**定图型时须同时定下：语域标注策略**（文言原文／白话译文／现代法是否混排），因为它影响【三】与【四】的区块划分。

## 四、输入

```yaml
problem:
  question: ★              # 要比较的法律问题（一句话，可被检索）
  facts:                    # 案情事实；用户未给时须标〔假设案情〕
  legal_branches: ★        # 涉及法律部门（刑/民/行政/诉讼/婚姻继承/土地/钱债…）
  comparison_scope:         # 比较范围：哪些朝代入轴、哪些只作背景
  judgment_criteria: ★      # 判断口径：何谓"违法"、何谓"责任"、何谓"同类"
  dimension:                # 比较维度：构成要件/法律后果/程序/身份差别/救济

baseline:                   # 可选：已知的起点（如"以唐律为基准")
evidence_policy:            # 证据门槛，默认 A/B 级方可作阻断性结论
modern_law_online: true     # 现行法是否在线核验，默认 true
```

**输入缺失的处理分两类，绝不可混**：
- **问题描述缺失**（用户只说"随便聊聊古代法律"）→ **不得自选题目**。必须用 `AskUserQuestion` 卡片追问（问题类型／法律部门／比较范围），或从候选问题清单中请用户选定。
- **史料缺口**（该朝本就没有材料）→ **不补**，标【无法判断】或【未见依据】。

## 五、输出（契约：七段）

```
【一】比较问题范围与判断标准        ← 用户要求1
    · 案情事实（用户给或〔假设案情〕）
    · 涉及法律部门
    · 判断口径（须显式说明跨朝不可直接对齐之处）
    · 十节点可判断度表（存佚判档结果）
【二】时间轴比较表                  ← 用户要求2、3
    朝代|年份|法源(律/令/格/式/敕/条例)|条文要点|证据层级|差异态|差异依据
【三】规范状态谱系图 ＋ 图说          ← 关系可视化
    · 图：一节点＝一朝代＋判档；箭头＝差异态；1949 画成孤立断点；不确定节点带 [?]
    · 载体按节点数定档：≤12 框线图／13–24 Mermaid／>24 inline SVG（须附等价 Mermaid 基准）
    · 须注明所用载体；降级须写明理由
    · 图说：**恰好三句**（画什么关系／主流程与断点／哪里不确定）
【四】趋势与转折点                  ← 用户要求4
    每条转折点须标：双证据出处 + 是否有文献支撑的社会动因
【五】明文规定 vs 实际执行 vs 学理解释   ← 用户要求5
    三重语域并置：文言原文／白话译文／现代法各占区块，加语域标签
【六】不确定性清单                  ← 用户要求5（硬要求，不得为空占位）
【七】总结：变迁脉络与现行制度取向
```

**除此之外不加任何段落**——不写"我的分析过程"、不写"创作说明"。唯一例外：S1/S2 硬闸门未过时，输出改为缺口说明，此时不产出比较表与图。

**表达遵循 `references/10_清晰表达规范.md`**：一句一要点、概念名恒定、术语首现解释、结论先行、例子紧随、**前提与边界不因求简而删**。

**图遵循 `references/11_线框图规范.md`**：**载体分档**（框线／Mermaid／SVG）由节点数决定，降级须注明；**纪律不随载体变**（节点单概念、关系须有出处、不确定须标、图说三句，三档通用）。

## 六、详细步骤

### S1 界定问题与判断口径

三件事必须先定死：

1. **法律问题要可检索**。"古代对妇女怎么看"不可检索；"妻告夫不孝历代是否受理"可检索。
2. **判断口径要跨朝可对齐，但不可强对齐**。三套口径并存：
   - 唐律式：定罪即"坐"某刑，罪与刑一一对应
   - 明清式：律定罪、**例**可改罪，"律例并罚"
   - 现行式：违法＋责任分离，罪刑法定、罪责刑相适应
   **三者不可直接换算。** 输出中须显式说明"本朝口径与其余朝如何对应、本次未对应之处"。
3. **维度要单一**。一次只比一个维度（构成要件 / 法律后果 / 程序 / 身份差别）。多维混比必然失焦。

### S2 存佚判档（十节点逐一举牌）

| 节点 | 判档 | 依据 |
|---|---|---|
| 秦 | 出土简牍（简号级） | 睡虎地《封诊式》《法律答问》 |
| 汉 | 出土简牍（简号级） | 张家山《二年律令》《奏谳书》 |
| 隋 | **仅史志（仅程序级）** | 《开皇律》全佚 |
| 唐 | 完整律典（条文级） | 《唐律疏议》＋吐鲁番出土辞 |
| 宋 | 律典＋官箴（条文级，残） | 《宋刑统》完整；《庆元条法事类》残本 |
| 元 | **政书条格（门类级）** | 《大元通制》散佚，仅《元典章》可定位 |
| 明 | 完整律典（条文级） | 《大明律》＋《大明令》＋《教民榜文》 |
| 清 | 律＋例双层（条文级，但附例年份多缺） | 《大清律例》＋附例 |
| 民国 | 需在线核验（条文级） | 六法体系，继受清律与日本法 |
| 现行 | 在线核验（条文级＋时效性） | flk.npc.gov.cn 等官方源 |

**判档结果必须写进【一】。** 判为"仅程序级"或"门类级"的朝代，其结论措辞强制降级。

### S3 检索法源与方法论加载

**方法论文件与步骤的对应表（按需加载，不是一股脑读完）**：

| 步骤 | 必读文件 | 读它解决什么问题 |
|---|---|---|
| **S1 界定问题** | `references/10_清晰表达规范.md` | 判断口径怎么跨朝对齐；三重语域要不要并置 |
| **S1 定图型** | `references/11_线框图规范.md` | 图型选哪个、**载体按节点数定档**（框线／Mermaid／SVG）、节点数是否超限 |
| **S2 存佚判档** | `references/02_存佚与可判断度.md` | 四档判准；「无材料」≠「无规定」的三种表述禁令 |
| **S3 检索法源** | `references/00_法源底座索引.md` ＋ `references/01_归一schema.md` | 底座覆盖什么、盲区在哪；字段怎么归一、引注怎么写 |
| **S4 判差异** | `references/03_差异判定规则.md` | 五态判准；判废止的四类正面依据；同源异流禁令 |
| **S5 转折与动因** | `references/04_明文执行学理三分.md` ＋ `references/05_转折点与社会动因.md` | 明文/执行/学理三层怎么分；转折点的双证据判据 |
| **S6 跨断点与成文** | `references/06_断点与近代段.md` ＋ `references/10_清晰表达规范.md` | 1949 等断点怎么处理；总结怎么写；表达纪律 |
| **涉民国段** | `references/90_民法制源指引.md` | 民国法核验路径（**不预录条文**） |
| **涉现行法段** | `references/91_现行法核验指引.md` | 官方源、时效性字段、措辞规范、降级路径 |

**三条硬性提示**

- **古代检索**：底座的覆盖范围只有诉讼／词讼类——若问题落在实体法（户婚/田土/继承/钱债），须走"在线补录"，并在【六】标注"本次为在线补录，未入底座"。
- **民国与现行**：按 `91_现行法核验指引.md` 走官方源，**以"时效性"字段为准**。网络不可用时降级为"本次未能核验时效性"，**不得凭记忆断言现行有效**。
- **表达与呈现贯穿全部步骤**，不是收尾时才读：写任何一段文字**之前**读 `10_清晰表达规范.md`；画图**之前**读 `11_线框图规范.md`。

### S4 判差异（五态）

| 态 | 判据 | 可靠性 |
|---|---|---|
| 沿用 | 承继关系可证；须细分**全沿／文字沿用而实质改造／同名异实** | 中～高 |
| 修改 | 同一规范对象，前后文本可比，改动点可指出 | 需两时点均有可靠文本 |
| 增补 | 新条文出现且旧条文仍在 | 相对可靠 |
| 废止 | **须正面依据**（修律诏令／律例沿革说明／判例 cessation／官修目录著录） | **无依据只能写"未见废止依据"** |
| 并存/分立 | 律与例、法与敕并行 | 须说明适用关系 |

**跨段禁令**：秦汉（出土简牍）与唐宋（传世律典）之间**不构成承继链**，一律标"**同源异流，不可直接称沿用**"。

### S5 判转折点与社会动因

- **转折点须双证据**：条文增改废的正面依据／典制官制变化／司法实践（档案判例）／文献所载立法理由——**至少两类**。仅凭"制度看起来变了"→ 写"疑似转折，证据不足"。
- **社会动因须有文献**：《教民榜文》《大诰》御制说明、律疏议立法理由、诏书。无文献 → 写"通行解释认为…"并**列入【五】**，不写进【三】当断言。

### S6 成表、作图、成清单

- 【三】比较表至少要有下列列，缺列即视为未完成：

```
朝代 | 年份 | 法源（文献·卷次门条） | 条文要点 | 证据层级 | 与前朝差异（五态之一） | 差异依据
```

**七列缺一不可**，其中"差异依据"最常被略去——**而它恰恰是防止"臆断"的那一列**。没有依据的差异态，一律改写为"无法判断"。

- 【三】之后是**图**（新【三】），按四步构造，顺序不可颠倒：

| 步 | 动作 | 依据 |
|---|---|---|
| 1 | **列节点** | 一节点＝一朝代＋其 S2 判档结果（如 `秦·丁`）。节点标签 ≤16 **显示宽度**（输入/输出边界标记 ≤24；1949 断点标记不受限） |
| 2 | **连关系** | 箭头关系词＝S4 判定结果（沿用／修改／增补／无法判断／不适用） |
| 3 | **标不确定** | 凡材料不足的节点加 `[?]`；1949 画成**孤立断点**，不得连线 |
| 4 | **写图说** | **恰好三句**：画什么关系／主流程与断点／哪里不确定 |

- 图的**载体按节点数选档**（≤12 框线／13–24 Mermaid／>24 SVG），并在【三】注明所用载体与降级理由。**详见 `references/11_线框图规范.md` 第二节。**
- 采用 T2／T3 时**关系词、`[?]`、图说一律不得省略**——载体是呈现层，纪律是内容层。
- 【六】不确定性清单**不得为空占位**。若无任何不确定项，须写"本次未发现不确定项"并说明**核验到什么程度**（不是"没有不确定性"，是"核验范围仅 X"）。
- 【七】总结须落在**制度变迁逻辑**上，不得写成道德感慨或今昔对比抒情。

## 七、错误处理

| 触发 | 处置 |
|---|---|
| 用户未指定法律问题 | **不得自选题目**。用 `AskUserQuestion` 卡片追问（问题类型／法律部门／比较范围），或给候选清单请用户选定 |
| 问题落在实体法（底座无数据） | 说明底座只覆盖诉讼/词讼类；走在线补录，并在【五】标注"本次在线补录，未入底座" |
| 要求比较"三国""魏晋南北朝""五代十国" | 说明本技能覆盖秦—清八朝＋民国＋现行；建议缩小到有律典的朝代，或另作专题 |
| 要求给隋代下"有/无规定"的结论 | **拒绝**。《开皇律》全佚，只能写"无法判断"，并说明这是材料限制而非制度空白 |
| 要求判某条"已废止"但无正面依据 | **拒绝**，改写"未见废止依据"，并列出需要何种依据才能判定 |
| 要求把清代律例与民法典画成连续演进曲线 | **拒绝并说明**：1949 为制度断点，1954／1982／2018 为宪制节点，跨断点的连续叙事是历史伪造 |
| 网络不可用且需核验现行法 | 降级为"本次未能核验时效性"，标【须核验】，**不得凭记忆断言** |
| 官方源检索不到某法（疑已废止） | 写"未能核验"，**不得写"不存在"**——检索失败不是制度不存在 |
| 用户要求立法建议／政策评价 | 拒绝——本技能只做历史比较，不产出规范性建议 |
| 图与正文矛盾（关系词在【二】无依据） | **返工重画**。依据校验码 `RELATION_NOT_INVENTED` |
| 图节点里塞了条文原文或多个概念 | 拒绝。节点是概念不是容器；拆分节点或删减，节点标签 ≤16 显示宽度 |
| 图说不满三句或硬凑三句 | 拒绝。三句各有分工（画什么／主流程与断点／哪里不确定），不是句数游戏 |
| 节点数超过 12 | **降级为 Mermaid**（≤24），超过 24 改用 inline SVG 并附等价 Mermaid 基准；在【三】注明载体。**不是"拆两张"**——拆图会丢失跨段的连续关系，而本图正要表达承继与断裂 |
| 用了 Mermaid／SVG 但省略关系词或图说 | 拒绝。**换载体不换纪律**：关系须可核验、图说三句，一项都不能省 |
| SVG 未附等价 Mermaid 基准 | 阻断。四项图示校验会在 SVG 上**静默全部失效**（解析不到节点→各项记 skipped→不报错） |

## 八、Gotchas（附 Why）

1. **不能把"没查到"写成"当时没有"。** Why：这是本技能最致命的失格。材料沉默≠制度沉默。隋代是最常踩的坑——很多人会顺手写"隋代律文已佚，故隋代无此规定"，后半句是错的：正确表述只有"无法判断"。
2. **判"废止"必须有正面依据。** Why：律典残缺（宋残本、元散佚）与附例年份缺失，使得"某条已废止"往往**根本无法判定**。史料沉默不是废止证据。
3. **秦简与唐律之间不是"沿用"。** Why：出土简牍与传世律典之间无承继链证据。凡跨这两段写"沿用"即为造假，须标"同源异流"。
4. **唐律「疏议」不是私人注疏。** Why：疏议是**法定解释**，与条文同具法律效力；把它与后世注疏并列，会把法定解释降格为学说。
5. **律与例必须分列。** Why：清代"律"自乾隆五年基本不变而"例"逐年增修，很多实质变化发生在例里。只引律文会系统性低估清代的变化幅度——而附例年份往往缺失，须逐条标。
6. **"亲亲相隐"这类制度不能讲成连续演进。** Why：从唐律亲相容隐到现行诬告罪，中间隔着 1949 与宪制节点。讲故事式的"演变"最容易在这里伪造连续性。
7. **底座只有诉讼/词讼类，实体法须声明。** Why：底座索引表实际覆盖的是告·诬告·越诉·干名犯义·代书·状式。拿它答"田界侵占历代怎么判"是**超范围使用**——不是说答不了，而是必须走在线补录并声明。
8. **判断口径不可跨朝强对齐。** Why：唐"坐"、明清"律例并罚"、现行"违法＋责任"是三套不同结构。强行换算会制造伪精度。
9. **趋势是从节点里长出来的，不是先有趋势再找节点。** Why：先定"亲属相告逐渐放宽"再去挑条文，是典型的结论先行。每个转折点都要能独立站住。
10. **一次只比一个维度。** Why：构成要件、法律后果、程序、身份差别混在一张表里，读者无法判断"变了"指的是什么。
11. **"现行有效"必须有核验时点。** Why：法律会被修订也会被废止。没有核验时点的"现行有效"是无效断言，输出须写明核验日期与来源。
12. **不确定性清单不得为空占位。** Why：写"无不确定性"而不说核验范围，等于把无知伪装成确定性。正确写法是"核验范围仅 X，故 Y 未及核验"。
13. **框线按字符数画必然错位。** Why：中文在等宽字体下占 **2 个显示宽度**。`len("秦·丁")` 是 4，但实际占 6 格。必须用 `disp_width()`（CJK 计 2、ASCII 计 1）。**这条是通用陷阱，不止本技能。**
14. **这是图谱，不是脑图。** Why：工作区约定「脑图管层级、图谱管关系」。十节点的层级已由【二】比较表承担；图若再去画层级，就是与表格重复且必然冲突。
15. **关系不得自补。** Why：工作区已把「为美观补内容、补关系」列为视觉类头号红线。图上多画一条原文没有的箭头，读者会当成史料结论——**这是把推测伪装成证据**。
16. **三句导读不是凑数。** Why：三句各有一职（画什么关系／主流程与断点／哪里不确定）。把一句话拆成三句虽能过句数检查，但读者仍读不懂这张图。
17. **降级载体 ≠ 可以少画。** Why：换 Mermaid 或 SVG 时最容易顺手省掉关系词注记——因为"反正有箭头"。但**没有注记的箭头无法核验**，四项图示校验里最重的一项（关系不得自补）就此失效。载体是呈现层，纪律在内容层，不随载体变。
18. **SVG 必须附 Mermaid 基准，否则校验形同虚设。** Why：SVG 里的节点与关系无法从标记中机检；若不附基准，四项校验会因"解析不到节点"而全部记为 skipped——**扫描面之外＝没检查**，且**没有任何告警**。这是"看似通过、实则未检"的典型形态。
19. **断点必须真的孤立。** Why：画成 `└──── 1949 ────┘` 这种汇合线，肉眼像是"断开"，实则把清与民国连了起来——**跨断点连线＝宣称法统承继＝历史伪造**。这条纪律此前只写在规范里、没做机检，是本轮新增 `BREAK_NOT_ISOLATED` 的直接动因。

## 十、铁律

1. **先界定问题、先判存佚，再检索。** 未过 S1／S2 不得动笔。
2. **判档结果封顶结论强度。** 判为"仅程序级"的朝代，措辞强制降级。
3. **「无材料」≠「无规定」。** 材料不存时唯一正确表述是"无法判断"。
4. **判「废止」须有正面依据。** 无依据只能写"未见废止依据"。
5. **秦汉与唐宋之间是"同源异流"，不是"沿用"。**
6. **律与例分列；附例须标年份，年份缺失即标缺。**
7. **引注必带证据层级 A/B/C/D。** C 级（辑佚）不可作阻断性结论，D 级（秘本技艺）不可作法源。
8. **转折点须双证据；社会动因须有文献**，否则入不确定性清单。
9. **制度断点必须显式标出**（1949／1954／1982／2018），不得画连续曲线。
10. **现行法"现行有效"须附核验时点与来源**；核验不到就写未能核验，**不凭记忆断言**。
11. **底座未覆盖的领域须声明**，不超范围使用。
12. **只做历史比较，不产出立法建议、不预测结果。**
13. **不确定处不标 `[?]` 不得交付。** 图上的 `[?]` 与【六】清单必须一一对应；把不确定混在确定项里展示，等于隐瞒。
14. **图与正文矛盾即返工重画。** 箭头的每一个关系词都必须能在【二】的差异态或差异依据中找到出处。
15. **呈现形态在 S1 定，不得在 S6 临时改。** 依据工作区约定「呈现形态错会使整份产出返工→是路由层级非输出参数」。
16. **表达不得为求简短删掉边界。** 存佚限定、核验范围、适用边界不是啰嗦，是结论成立的条件。
17. **1949 断点必须孤立，不得与任何节点连线。** 汇合线、跨断点箭头、子图连线都算连线。
18. **载体按节点数降级，且降级须注明。** ≤12 框线／13–24 Mermaid／>24 SVG＋等价 Mermaid 基准。**换载体不换纪律。**
