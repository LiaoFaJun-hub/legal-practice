### 刻意不引用的四份文件（**不是孤儿文件**）

底座目录下还有 `spec_秦汉隋.md` / `spec_唐宋.md` / `spec_元明.md` / `spec_清.md` 四份——它们是**文书体式规格**（体式、称谓、收束语、状式条例），供 `ancient-chinese-litigation-drafting` 生成文书时使用。

**引用纪律**：本技能**引用**底座，不复制、不改写、不"就近取材"。需要新字段时从原表读取，不在转述中加工——**转述即失真的起点**。

## 二、底座实际覆盖的主题（这是硬边界）

底座的条文索引表是围绕**诉讼/词讼**建立的，覆盖：

- 告诉与受理（告、告状、投状、口告、词状）
- 诬告与反坐
- 越诉与逐级申诉
- 身份禁告（干名犯义、告尊长、告主）
- 代书与状式（官代书、书状人吏、书铺、写状人、状式条例）
- 取保、结状、供状类程序的形态要求

**底座基本不覆盖**（据探查，逐条核对过）：

| 法律部门 | 底座状态 |
|---|---|
| 诉讼／词讼 | ✓ 有条文级数据 |
| 行政／官制 | 部分（多为制度叙述，非条文） |
| **户婚·田土·继承** | ✗ **基本缺位** |
| **钱债·契约** | ✗ **基本缺位** |
| **贼盗·人命·财产犯罪** | ✗ **基本缺位** |
| **民国法** | ✗ **完全空白** |
| **中国现行法** | ✗ **完全空白** |

### 由此产生的一条硬纪律

> **底座未覆盖的领域，必须在输出中声明"本次为在线补录，未入底座"。**
>
> 这不是谦辞，是可核查的边界声明。拿底座答"田界侵占历代怎么判"属于**超范围使用**——不是说答不了，而是必须换路径（在线补录原书）并让读者知道走的是另一条路。

## 三、四套字段结构（实测，不可凭印象）

四份分册的索引表**字段不统一、顺序不统一**，这是本技能必须做归一的原因（详见 `01_归一schema.md`）。

| 分册 | 表头（实测原文） |
|---|---|
| 秦汉隋 | `条文编号/简号 \| 文献全称 \| 篇目 \| 原文摘录（所据版本） \| 规范对象 \| 罚则 \| 证据层级` |
| 唐宋 | `条文编号 \| 文献全称 \| 卷次/篇目 \| 原文摘录 \| 规范对象 \| 罚则 \| 证据层级` |
| 元明 | `文献全称 \| 卷次/门/条 \| 条名 \| 原文摘录 \| 规范对象 \| 罚则 \| 证据层级` |
| 清 | `文献全称 \| 卷次/门/条/年份 \| 条名 \| 原文摘录 \| 规范对象 \| 罚则 \| 证据层级` |

**三处结构性差异**：
1. **无"朝代"列**——朝代靠分册区分，跨册检索时会丢失朝代信息。
2. **无"法律问题"分类列**——只有"规范对象"关键词，无法按案情维度检索。
3. **清册把"年份"并入"卷次/门/条/年份"**——附例年份与卷次混在一格，需拆读；且清册多处附例**年份待核**。

## 四、直接继承的四级证据分级（不重新发明）

底座已建立成熟分级，本技能**直接沿用**，其口径与含义照录：

| 级别 | 定义 | 支撑能力 |
|---|---|---|
| **A** | 出土实物／现行律典／司法档案原件 | 可支撑**条文级**校验，可作"不准"的阻断依据 |
| **B** | 传世史籍、政书、官箴、典制 | 可支撑**程序级**与**格式级**校验 |
| **C** | 后人辑佚、类书转引 | **仅可支撑制度叙述，不可作阻断依据** |
| **D** | 已佚仅存目／技艺文本 | **不可作法源**，只能作风格参照或标"无原文" |

**三条引用红线（照录，不改）**：
1. **辑佚不是原文**——《唐令拾遗》《宋会要辑稿》《九朝律考》等须标"辑佚"，不得写成"《某书》云"。
2. **秘本不是法源**——讼师秘本属 D 级技艺文本；清代更被《大清律例》乾隆七年附例明令查禁。
3. **附例须标年份，档案不可外推**——混用不同年份的例等于串改法源；地方档案的年代跨度极短，外推即过度推断。

## 五、底座不是"已核验"数据

底座各分册均设「文献存佚与可靠性评估」节，且**留有未核项**：
- 秦汉隋分册：文末注"待核项须以原书复核，不得直接用于生成"。
- 唐宋分册：设「版本与页码核对清单（待核事项汇总）」——核的是**页码**，非内容。
- 元明分册：内联"待核"标注。
- 清分册：设「待核事项清单」10 条（如附例年份未核）。

**因此**：底座条目**不等于已核验**。本技能引用底座时，**须把底座的待核状态一并传递到输出**——即【五】不确定性清单中须包含"底座自带待核项"这一类。

## 六、检索路径

```
问题落在诉讼/词讼类？
   ├─ 是 → 读 00_法源总纲.md 的"校验规则→法源映射表"定位法源
   │        → 进对应分册的条文索引表（按"规范对象"关键词筛）
   │        → 按 01_归一schema.md 归一字段 → 进 S4 判差异
   └─ 否（实体法/民国/现行）
            → 实体法：在线补录原书，并在【五】标"未入底座"
            → 民国：按 90_民法制源指引.md
            → 现行：按 91_现行法核验指引.md（官方源 + 时效性字段）
```

**筛"规范对象"时的注意**：底座的"规范对象"是**法条自己认定的规制对象**（如"告人罪者""代书"），不是你要比较的案情。**两者之间需要一次人工映射**——例如案情"儿子告父亲不孝"要映射到规范对象"不孝""干名犯义""尊长"三项。这一步没有捷径，也是最容易出错的一步。
