# 01 · 归一 Schema 与引注格式

> 底座四份分册的索引表字段不统一、且无"朝代"列与"法律问题"列。本文件定义**本技能输出所用的归一结构**，并给出与底座的映射。
>
> **归一不是复制数据，是定义映射。** 字段值永远从原表读取，不在本文件里缓存。

---

## 一、归一条目结构（12 字段）

每个"条文条目"在比较表中以如下结构承载：

| # | 字段 | 取值 | 必填 |
|---|---|---|---|
| 1 | `dynasty` | 秦/汉/隋/唐/宋/元/明/清/民国/现行 | ★ |
| 2 | `year` | 年号纪年 或 公元年份 | ★（年份缺失时标〔年份待核〕） |
| 3 | `law_type` | 律／令／格／式／敕／条例／例／司法解释／宪法 | ★ |
| 4 | `source` | 文献全称 | ★ |
| 5 | `locator` | 卷次·门·条号／简号 | ★（无则标〔无篇次〕） |
| 6 | `article_name` | 条名 | ○（无则留空，不臆造） |
| 7 | `text` | 原文摘录 | ★（短于全文时标〔节录〕） |
| 8 | `norm_target` | 规范对象 | ★ |
| 9 | `penalty` | 罚则 | ○（无则留空，**不以"无"填充**） |
| 10 | `evidence_level` | A／B／C／D | ★ |
| 11 | `diff_state` | 沿用／修改／增补／废止／并存／首次／无法判断 | ★ |
| 12 | `diff_basis` | 差异依据（正面依据或"未见依据"） | ★ |

**标 ★ 的九个字段缺任一，该条目不得进入【二】比较表**，须先补齐或标〔待核〕。

## 二、四套字段 → 归一映射

| 归一字段 | 秦汉隋 | 唐宋 | 元明 | 清 |
|---|---|---|---|---|
| `dynasty` | 分册内推定 | 分册内推定 | 分册内推定 | 分册内推定 |
| `year` | 载于条文编号或篇目 | 载于条文编号 | **常缺** | **并入"卷次/门/条/年份"格，须拆读** |
| `law_type` | 由篇目推 | 由卷次推 | 令/格/条格 | 律／例（**须分列**） |
| `source` | 文献全称 | 文献全称 | 文献全称 | 文献全称 |
| `locator` | 篇目 ＋ 简号 | 卷次/篇目 ＋ 条文编号 | 卷次/门/条 | 卷次/门/条（**须拆出年份**） |
| `article_name` | **无此列** | **无此列** | 条名 | 条名 |
| `text` | 原文摘录（所据版本） | 原文摘录 | 原文摘录 | 原文摘录 |
| `norm_target` | 规范对象 | 规范对象 | 规范对象 | 规范对象 |
| `penalty` | 罚则 | 罚则 | 罚则 | 罚则 |
| `evidence_level` | 证据层级 | 证据层级 | 证据层级 | 证据层级 |
| `diff_state` | **底座无，本技能新增** | | | |
| `diff_basis` | **底座无，本技能新增** | | | |

### 三处必须人工处理的情形

1. **秦汉隋／唐宋两册无"条名"列** → `article_name` 留空。**不得据条文内容自行命名**，那会把解释当作条名。
2. **清册"年份"混在 locator 格** → 必须拆读并单独填 `year`；拆不出或底座标"年份待核"时，填〔年份待核〕，**不得用约数**。
3. **元明册常无年份** → `year` 标〔年份不详〕，但 `source` 与 `locator` 必须完整（《元典章》卷次/门/条是可定位的）。

## 三、引注格式（五级定位）

引注必须能回溯到"文献—卷次—门—条—年份"。五级齐者方可作 A 级；缺级即降级。

| 证据级 | 引用模板 | 例 |
|---|---|---|
| A·出土实物 | 《文献名》篇目简号（版本年） | 《二年律令·告律》简126（文物出版社2001年本） |
| A·律典 | 《文献名》卷次·门·第X条 | 《唐律疏议》卷24·斗讼·第356条 |
| A·律典＋附例 | 《文献名》卷次·门·第X条，某朝某年例 | 《大清律例》卷30·刑律诉讼·第340条，雍正七年例 |
| A·档案 | 档案名＋年代＋文书种类 | 黄岩诉讼档案·光绪十年·告状状式条例 |
| B·政书／官箴 | 《文献名》卷次·篇目 | 《元典章》卷53·刑部·诉讼·书状 |
| C·辑佚 | 《文献名》（辑佚，辑者） | 《宋会要辑稿·刑法三》（徐松辑，咸平六年诏） |
| D·技艺／已佚 | 【技艺文本】《文献名》卷次　或　【已佚】《文献名》 | 【技艺文本】《解铃人语》状词十段要诀；【已佚】《开皇律》 |

**民国与现行法的引注另定**（见 `91_现行法核验指引.md`），须额外带**核验时点**与**时效性**。

## 四、`diff_state` 取值判定表（速查）

| 取值 | 一句话判据 |
|---|---|
| 首次 | 该朝首次出现此规定，此前诸朝无对应条文可承 |
| 沿用 | 承继关系可证；**须注明细分**：全沿／文字沿用而实质改造／同名异实 |
| 修改 | 同一规范对象，前后文本可比，改动点可指出 |
| 增补 | 新条文出现且旧条文仍在 |
| 废止 | **须正面依据**（四类：修律诏令／律例沿革说明／判例 cessation／官修目录著录） |
| 并存 | 与另一规范并行（如律与例、法与敕），须说明适用关系 |
| **无法判断** | 材料不足以判差异（**不是"无差异"**） |

## 五、跨代术语黑名单（另建，不照搬前技能）

`ancient-chinese-litigation-drafting` 的 73 条禁用词是针对**文书体式**（朱语、珥语、官代书戳记一类）。本技能针对**法规范用语**，**不能照搬**——照搬会把"牒""式"这类正当法源名词误杀。

本技能的黑名单只收**时代错配的规范用语**，初始条目：

| 用语 | 允许出现于 | 早期朝代误用时的处置 |
|---|---|---|
| 干名犯义 | 明、清 | 唐宋阻断（该名系明代律条名） |
| 律例 | 清（明已有"例"，但"律例"并称系清代） | 唐宋阻断 |
| 六法体系 | 民国 | 清及以前阻断 |
| 亲亲相隐 / 亲属相隐 | 唐宋元明清（**须核具体法源**） | 秦汉阻断（该律名晚出） |
| 诬告陷害罪 | 现行 | 民国及以前阻断（现行为罪名体系） |
| 民法典 / 刑法 | 现行 | 民国及以前阻断 |
| 秋审／朝审 | 清 | 明及以前阻断 |
| 折杖法 | 清 | 明及以前阻断 |
| 服制定 | 明清（有服制图） | 宋元阻断 |

**扩充纪律**：黑名单条目必须**逐条写明依据**，禁止凭语感添加。加入前须确认该用语确为某朝法定名词，且此前诸朝无同义前身。

## 六、比较表的最小可接受形态

【二】比较表至少要有下列列，缺列即视为未完成：

```
朝代 | 年份 | 法源（文献·卷次门条） | 条文要点 | 证据层级 | 与前朝差异（五态之一） | 差异依据
```

**七列缺一不可**，其中"差异依据"最常被略去——**而它恰恰是防止"臆断"的那一列**。没有依据的差异态，一律改写为"无法判断"。
