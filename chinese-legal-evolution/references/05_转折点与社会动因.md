# 05 · 转折点与社会动因（双证据判据）

> 用户要求"归纳各阶段的变化趋势与转折点，说明变化背后的社会动因、统治理念或制度演变逻辑"。
> 这一段最容易从史料比较滑向**历史叙事**。本文件给出可操作的门槛。

---

## 一、趋势是从节点里长出来的

**顺序不可颠倒**：先有逐朝差异，后有趋势归纳。

- ✅ 正确：六个节点的差异态摆出来 → 归纳出"唐至宋在 X 维度由 A 转为 B"
- ✗ 错误：先定"亲属相告历代逐渐放宽" → 再挑条文佐证

后者是**结论先行**，它会让你在史料不合时仍去找"合的"——因为你已经知道要什么了。

---

## 二、转折点的双证据判据

**每个转折点至少须有两类独立证据支撑。** 四类证据任选：

| 类 | 证据形态 |
|---|---|
| **一·条文证据** | 增补／修改的正面依据；或律典在某点上体系性重组 |
| **二·典制证据** | 官制、选官、审判机构、诉讼程序的制度变更 |
| **三·实践证据** | 司法档案、判例中该问题的处理方式出现可辨识的改变 |
| **四·文献证据** | 立法理由的明文记载（诏书、敕、奏议、法典序例、律疏议的立法说明） |

### 门槛

| 证据数 | 允许的表述 |
|---|---|
| ≥2 类 | 「**转折点**」——可作论断 |
| 仅 1 类 | 「**制度在此维度发生变化**」——陈述事实，不称转折 |
| 0 类 | **不得**写"转折"；只能写"疑似转折，证据不足"并列入【五】 |

**"仅凭'制度看起来变了'的直觉"不计入任何一类。**

---

## 三、社会动因：须有文献，否则入清单

社会动因（为什么变）是用户明确要求的，但也是最容易**编故事**的地方。

### 动因的文献来源清单

| 来源类型 | 例 |
|---|---|
| 立法理由的明文 | 《教民榜文》（洪武三十一年）、《大诰》御制按语、诏书 |
| 律疏议的立法说明 | 《唐律疏议》疏议中"所以然"的表述 |
| 法典序例／凡例 | 纂修缘起、删改理由 |
| 奏议 | 修订奏折、监察文书 |
| 官箴中的反思性记述 | 地方官总结治理经验之文 |

### 措辞三档

| 证据状况 | 允许措辞 |
|---|---|
| 有文献明确记载 | 「立法理由见××，称……」 |
| 无直接文献，但有学界通行解释 | 「**通行解释认为**……（未及核验原始文献）」——**且必须列入【五】** |
| 无文献亦无通行解释 | **不写动因**。只描述变化本身，不解释 |

### 禁止的写法

- ✗「之所以如此，是因为古代社会宗族观念浓厚」——无文献支撑的社会学解释
- ✗「这一规定体现了礼法结合的立法传统」——除非能指出哪一条文、哪一段疏议如此表述
- ✗「统治者意在维护……」（推测立法者主观意图而无文献）

**社会动因是本技能最容易失守的地方。** 改动的**原因**与改动**本身**是两件事——材料能证明后者，往往不能证明前者。

---

## 四、"制度演变逻辑"怎么写才不空

"逻辑"不是"越来越完善"这类评价性叙述。合格的演变逻辑应落在**结构关系**上：

| 可用逻辑类型 | 例 |
|---|---|
| **关系重整** | 尊长与卑幼的权限关系重新配置 |
| **程序位移** | 同一问题从实体法处理转为程序法处理（或反之） |
| **主体转换** | 某行为的责任主体在官府/家族/个人之间转移 |
| **入罪／出罪** | 某行为被明确纳入罪刑，或明确移出 |
| **义务扩张／收缩** | 同一主体被要求的事项增减 |

**不合格的逻辑**："从野蛮到文明"、"从落后到进步"、"日益完备"。这类表述无法证伪，因而没有信息量。

---

## 五、【三】转折点小节的书写模板

```
转折点 N：<一句话点明变的是什么>
- 证据：
  · 条文证据：××朝 ××法 ××条 ——（与前朝的具体差异）
  · 实践证据：××档案 ××年 ——（处理方式的可辨识改变）
- 动因：有文献／通行解释（列入【五】）／未及考
- 表述强度：转折点（双证据）／制度变化（单证据）／疑似转折（证据不足）
```

**"表述强度"一栏不得省略**——它强制作者交代这句话有多可靠。

---

## 六、常见的四种滑坡

| 滑坡 | 表现 | 防范 |
|---|---|---|
| **结论先行** | 先定趋势再选证据 | 逐朝差异表完成前不写趋势 |
| **动因脑补** | 用社会学常识解释法律变化 | 无文献即入【五】 |
| **直线化** | 把不连续的变化讲成连续演进 | 标注断点与不确定段 |
| **评价化** | 用"进步/落后"评价古代规定 | 只描述结构关系，不作价值评判 |
