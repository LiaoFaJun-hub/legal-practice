# 06 · 制度断点与近代段（不画连续曲线）

> 用户要求"直到现行法律"。这条尾巴一旦处理不当，整份比较报告的历史可信度会崩塌——**因为它在最容易被叙事化的地方引入了断裂。**

---

## 一、四个必须显式标出的断点

| 年份 | 性质 | 对比较的影响 |
|---|---|---|
| **1949** | 制度更替、法统替换 | 此前为"古代法制"（或"传统法"），此后为**另一法统**。**不得以"沿用/修改/废止"描述1949年前后条文关系** |
| **1954** | 宪法制定（第一部） | 宪制节点 |
| **1982** | 现行宪法制定 | 宪制节点 |
| **2018** | 宪法修正 | 宪制节点 |

**断点处必须换段、换措辞。** 跨越断点的比较，只能写"制度更替／法统断裂"，不能写"废止"——**制度替换不是条文被删**。

---

## 二、民国段：性质与判读

### 六法体系

| 法域 | 主要法典 | 备注 |
|---|---|---|
| 宪法 | 《中华民国宪法》及约法 | 历经多次修订 |
| 民法 | 民法总则、物权、亲属、继承、债编 | 1929—1930年陆续公布，1931年施行 |
| 刑法 | 刑法 | 1928年、1935年两部 |
| 商事 | 公司、保险、票据等单行法 | 继受为主 |
| 民事诉讼 | 民事诉讼法及其实施条例 | |
| 刑事诉讼 | 刑事诉讼法 | |

**判读要点**：
1. **大量继受清律与日本法**。例：民国《民法》第×条的内容常可见于清律例或日本民法。**但"内容相似"不等于"沿用"**——须指出继受来源，不写"承清律"。
2. **亲属编的沿革最复杂**：民国《民法·亲属编》对"尊长""亲权""容隐"作了重新安排，与清律例差异很大，且掺入日本民法与瑞士债法的影响。**这一段不能简化成"从清律到民法的调整"**。
3. **须核验施行日期与后续修改**。民国法多经修订，引用时须标明"某年公布／某年施行／某年修正"。

## 三、现行段：核验而非记忆

### 硬纪律

> **"现行有效"是一个有时间戳的断言，不是属性。**
>
> 没有核验时点与来源的"现行有效"，是无效断言。

### 核验通道

按 `91_现行法核验指引.md` 走官方源，**以"时效性"字段为准**。

| 情形 | 措辞 |
|---|---|
| 核验到且标明现行有效 | 「截至〔核验日期〕，××法 第×条（现行有效，来源：××）」 |
| 核验到且标明已废止 | 「××法已于〔日期〕废止（来源：××）」 |
| **网络不可用** | 「本次**未能核验**时效性，须复核」——**不得凭记忆断言** |
| **官方源检索不到** | 「**未能核验**」——**不得写"不存在"**。检索失败不是制度不存在 |

**最后一条尤其重要**：法已被废止且未在数据库中著录，检索会返回空。此时正确表述是"未能核验"，而不是"已废止"或"不存在"。

## 四、断点处的比较表写法

跨越断点时，【二】比较表的处理：

| 做法 | 正确 |
|---|---|
| 一行贯穿到底，把清律与民法典放在同一行的"沿用"栏 | ✗ |
| 分作两段，断点处显式标注 | ✅ |

**模板**：

| 朝代 | 年份 | 法源 | 条文要点 | 证据层级 | 与前朝差异 | 差异依据 |
|---|---|---|---|---|---|---|
| 清 | 光绪×年 | 《大清律例》×律×条 | …… | 【A】 | —— | —— |
| **—— 1949 制度更替·法统断裂 ——** | | | | | | |
| 现行 | 〔核验日期〕 | 《××法》第×条 | …… | 【A】 | **不适用差异五态** | 另法统，无承继关系 |

**"不适用差异五态"是合法取值**，不是遗漏。

---

## 五、【六】总结的写法：连绵vs断裂

总结须同时说清两件事：

1. **变化的内容**——从什么变成什么（结构关系层面，不作价值评判）
2. **变化的性质**——连续演进 / 断裂 / 断裂后重建

**禁止**：
- 把清代律例与民法典讲成一条连续演进线
- 用"从古至今一路走来"这类未经断点处理的叙述
- 以现行法作价值终点评价古代法（"古代如何如何，现在进步了"）

**允许的叙述结构**：

> 本问题在秦—清构成一条**法统内部**的演进线索（须逐段标明证据与断点处的不确定）；1949 年后属**另一法统**，其规范逻辑与前段不可直接对应；现行制度在〔某要素〕上延续了〔某传统〕，在〔某要素〕上作了重构。**两者之间是断裂与重建，不是演进。**
