# 90 · 民法制源指引（核验路径，不预录条文）

> **本文件不预录任何民国条文。** 理由：民国法条多经修订，且本技能无底座、无 MCP 通道；预录即构成"未核验而断言"，违反本技能第一纪律。
>
> 本文件只提供：**该查哪些法、怎么查、查到什么算够、哪些坑必须避开**。

---

## 一、民国法制的定位（先说清楚它是什么）

| 项 | 说明 |
|---|---|
| 法统 | 继受法域。大量继受**清律**与**日本法**，部分受**瑞士法**（债编）、**英美法**（公司保险）影响 |
| 结构 | "六法体系"：宪法、民法、刑法、商事、民事诉讼、刑事诉讼 |
| 时间跨度 | 约 1912—1949（大陆地区法统终止） |
| 引用风险 | **高**。原因有三：①法条多经修正，须区分公布年与施行年 ②同名法有多个版本（如刑法 1928/1935 两部）③大量"暂行""条例"层级混杂 |

**判读要点**：
> ❌ 不得写"民国承清律"——继受来源须具体指出（清律？日本民法？瑞士债法？）
> ✅ 写法：「民国《民法·亲属编》第×条（某年公布、某年施行）……其内容与清律例×条相近，**然继受路径不直接，且形式法理已采德日体系**。」

**内容相似 ≠ 沿用。** 这是本段最容易犯的错。

## 二、该查哪些法（按问题类型）

| 问题类型 | 主要法源方向 |
|---|---|
| 亲属相告、尊长卑幼 | 民法·亲属编；刑法（不孝、不应为罪相关条文是否存废） |
| 继承、法定继承顺序 | 民法·继承编 |
| 婚姻家庭 | 民法·亲属编 |
| 财产所有、田土 | 民法·物权编；土地法（耕地等特别法） |
| 契约、债 | 民法·债编 |
| 刑事归责、告诉 | 刑法（总则、告诉乃论、诬告） |
| 诉讼程序 | 民事诉讼法、刑事诉讼法 |
| 官制、吏治 | 宪法及宪法相关法（国家机构篇） |

**注意**：本技能底座只覆盖诉讼/词讼类（见 `00`），**民国的"诉讼程序"类仍有部分可与底座接续**（唐宋的告状受理规矩与民国的诉讼构造有可比性），其余领域须另寻来源。

## 三、核验路径

### 优先级

1. **官修法律目录 / 法律公报**：南京国民政府时期的法律公报、历次法典沿革说明
2. **现行有效法律目录的历史版本**：`npc.gov.cn` 有"现行有效法律目录"（如 2023-11-02 版，299 件）——**可参照其体例反推民国法清单**，但**不等于民国法现行有效**
3. **权威工具书的民国法部分**（须标注版本与出版年）
4. **学术专著与论文**（【B/C】级，不可作阻断依据）

### 核验必须记录的四项

| 项 | 为什么必须 |
|---|---|
| **公布日期** | 民国法常"某年公布、某年施行"，两者可能差年 |
| **施行日期** | 比较时间轴时用**施行**而非公布 |
| **修正记录** | 一部法可能改过多次，不记修正年就会引错版本 |
| **是否被取代** | 后法是否废止前法 |

## 四、常见坑（逐条）

| 坑 | 表现 | 防范 |
|---|---|---|
| **把民国当"现行"** | 直接引民国法说"现行规定" | 1949 后属另一法统，详见 `06_断点与近代段.md` |
| **忽略修正** | 引 1929 年《民法》却当作始终有效 | 必查修正记录 |
| **把暂行当正式** | "暂行条例"层级效力与正式法典不同 | 注明文件层级 |
| **同名不同法** | 1928 刑法与 1935 刑法内容差异大 | 引注须带年份 |
| **继受当沿用** | 说"民国承清律" | 指出具体继受来源，标"内容相近"而非"沿用" |
| **用现行目录反推** | 拿今天的法律目录去论证民国 | 目录只反映当下，不反映民国 |

## 五、输出措辞规范

| 情况 | 措辞 |
|---|---|
| 核验到公布/施行/修正 | 「民国《××法》第×条（某年公布、某年施行，某年修正）【B】**本次在线补录，未入底座**」 |
| 只核到公布年 | 「……（某年公布；**施行日期未能核验**）」 |
| 未能核验 | 「**本次未能核验**民国该法条，建议回查〔×〕」 |
| 继受关系 | 「其内容与〔清律例×条／日本民法×条〕相近，**属继受而非沿用**」 |

**凡"未能核验"一律进【五】不确定性清单。**
